# 双区原生地形 v12 · 正面绕序与真实阴影

状态：严格导入、完整headless与唯一GPU Field专项通过，19张实机图审查后**整体视觉仍FAIL，未替换正式地图**。这里的native-pair v12是3072×1024中心—东岸开发样段，不是当前正式世界地图v12。

## 目标与根因

修复v11原生模型投射影为空及地面受光偏暗，不以调高环境亮度或补程序圆影掩盖。最小、实际网格过渡和index-only对照先确认两条失败路径：相机排除caster图层会让此后端投影消失；地形原三角绕序与Godot原生PlaneMesh相反，仅反转index就恢复真实接影。定位过程及原图见 `docs/world-map-native-shadow-capability-v12-20261001.md`。

## 变更边界

- 新renderer显式继承v10，克隆v11必要实现并将所有输出改为独立native-pair v12前缀，不调用旧build/save静态hook。
- 实际网格只反转每三角第二／第三索引，engine packed vertex／UV／normal保持逐字节一致。高度源ROI、拓扑和几何位置不因绕序修复改变。
- 同一viewport同层SHADOWS_ONLY／hidden ON-OFF、每状态实际frame_post_draw与重复原图；背景中不烘焙十个模型。
- 两块CC0 Boulder和八株CC0 Shrub03低草重新导出独立alpha。实际最低顶点及最低6%支撑定脚底，输出完整原body和重复图，不复用失败轮AABB假锚点。
- 影层从真实ON／OFF亮度差提取，并排除水域、桥／码头甲板及实际body alpha膨胀2px；接触土斑与cast分开。
- 实际重渲land必须全像素不变；walk只允许既定局部地形投影包络内变化。旧路线控制点、地标、九个未替物件及五柱前景不变。
- 初始写BUILD_IN_PROGRESS；失败或partial不能启动Field，READY只在实体、导航、真实非空影和冻结旧源检查完成后写入。

不修改正式v12／v13 staging、Field／autoload／project.godot、剧情数据或存档。未新增资源下载、生图或费用。
