# 华山 / 武当门派地图 v3、门框遮挡与大地图高清化（2026-09-13）

## 本批结论

- 华山由旧单图拆成“山门 → 演武坪 → 观瀑剑台”三张独立场景；武当拆成“山门 → 太极场 → 紫霄宫前庭”三张独立场景。
- 六张地图均以1536×1024独立构图，经项目审定的Real-ESRGAN模型重建为3072×2048运行图，按原生尺寸滚动，不再把整张门派图缩进一屏。
- 六处场景的角色显示比例统一为0.70；环境建筑、广场和跨屏路程负责表现门派规模，人物不再因底图整体缩小而显得巨大。
- 华山、武当新山门以及现行洛阳城门、凌月山门均具有脚底淡化区域。角色穿入门楼覆盖范围时仅角色降至约42%～43%透明，门楼本身保持不透明。
- 江湖大地图桌面母图从1536×1024原始构图直接使用Real-ESRGAN重建为4608×3072，并恢复同源道路强化；15个桌面分块和15个移动分块已重新生成。逻辑尺寸、门户坐标与导航蒙版不变。

## 门框半透明标准

可穿越城门、山门、牌楼不能只画在背景上而继续让角色完整显示在屋檐前。地图应同时满足：

1. 门洞脚底线处于可走区；门柱属于阻挡区。
2. `actor_fade_zones`覆盖角色从门檐下穿过的脚底范围。
3. 半透明只作用于角色，不能让整张门楼或背景一起淡化。
4. 用门洞内见证点校验淡化区，用门柱见证点校验阻挡。

本批纳入自动门框合同的现行场景为华山山门、武当山门、洛阳南城门与凌月山门。后续新增同类门框必须沿用相同字段和测试，而不是依赖单张图的视觉巧合。
