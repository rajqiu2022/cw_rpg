# 战斗 / 数值验收清单（battle）

> 适用对象：技能 / 敌人 / 装备数值 / 战斗控制器调整。

## 必过项

- [ ] 改动后第 1 章战斗节奏仍在「3-6 回合内可结束」目标内（用现有敌人 + 起步装备测一遍）。
- [ ] 关键事件 (`enemy_defeated` / `damage_dealt` / `loot_dropped` 等) 仍按既有 `EventBus` 信号广播；`QuestManager` 触发器没被破坏。
- [ ] 新增技能 / 敌人 / 装备的 `id` 在数据集中唯一，命名风格与现有一致（snake_case，`thug_lone` / `palm_strike` 这种）。
- [ ] 装备加成公式与 `BattleController` 现有叠加方式一致；不引入隐式负值或除零。
- [ ] 战利品列表（必掉 / 概率掉）id 在 `Inventory` / 装备表中存在。
- [ ] 状态异常（M6 起）有「持续回合 / 解除条件 / UI 显示」三件套。

## 提交时附带

- 调整理由（一句）
- 期望体验变化（一句）
- 实测对比（与上一版几回合 / 几血量差异）
- 是否需要 lore 改技能描述
