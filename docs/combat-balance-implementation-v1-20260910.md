## 规则变更

- 防御继续减法结算，仅把本击吸收限制为暴击后威力的80%（向下取整）。高攻击/正常防御区保持原伤害；高防区不再直接压成1。此上限是固定规则，不暗中跟随玩家等级。
- 去掉全局残血输出衰减；虚弱、破防、增伤、易伤等显式状态仍生效。
- GM拆解显示有效防御、实际吸收、本击最大吸收及是否封顶。保留旧低血trace字段但倍率固定1。
- 旧单体敌人共用可支付技能选择函数、每次施放扣一次MP、按技能命中率结算；未命中不触发反伤、重定向、异常或防御后保底伤害。
- 封招保留普攻/防御，不放行其他零耗技能。抽取 `_team_apply_action_end_status(unit)`，供运行与QA共同调用，原状态衰减行为不变。
