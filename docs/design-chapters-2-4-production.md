## 第二章：竹尾风波

目标时长：12-18 分钟。核心体验是调查、救援和第一次组队战。

| 场景 ID | 场景 | 主要功能 |
|---|---|---|
| `ch2_s1_zhuwei_market` | 竹尾村集市 | 打听失踪弟子、商店、支线入口 |
| `ch2_s2_forest_edge` | 密林边缘 | 足迹调查、采药、教学伏击 |
| `ch2_s3_forest_ambush` | 密林伏击地 | 救援悦无姮、连续战、假令牌证据 |
| `ch2_s4_lingyue_gate` | 凌月山门 | 交付任务、女主邀约、第三章入口 |

主线：`q_ch2_main_01_investigate` -> `q_ch2_main_02_rescue_yue`。支线数据全部保留，但按 NPC/场景解锁，不允许开章时一次性显示七条。

战斗编排：蒙面杀手斥候 -> 双人救援战 -> 蒙面杀手精英。章末精英使用流血/眩晕之一，首次展示同伴援护反馈。

章末产出：悦无姮关系值、烈云盟令牌（剧情物）、凌月信物、第三章武林大会入口。

## 第三章：入派抉择

目标时长：18-28 分钟。核心体验是大会考校、五派选择、门派专属任务和新招式。

公共场景：

| 场景 ID | 场景 | 主要功能 |
|---|---|---|
| `ch3_s1_wulin_assembly` | 武林大会 | 五派亮相、苏雾笙发言、选择门派 |
| `ch3_s2_trial_ground` | 考校场 | 通用资格战、门派选择确认 |

分支场景：`ch3_wudang_hall`、`ch3_huashan_courtyard`、`ch3_gufeng_camp`、`ch3_lingyue_hall`、`ch3_mingwu_manor`。

每条分支必须包含：一段门派冲突、一场专属战斗、一个调查/交互目标、1-2 招可装备技能、一个影响后续章节的 faction flag。选择后不能静默切换门派，读档除外。

| 门派 | 专属任务 | 奖励 |
|---|---|---|
| 武当 | 调查陆青云之死 | 太极初式、玄武心境 |
| 华山 | 化解剑气内争 | 华山一剑、紫霞凝罡 |
| 古峰 | 酒试与比武 | 开山一刀、金刚力 |
| 凌月 | 调查白晚晴之死 | 踏月凌波、月华引 |
| 茗雾 | 隐影试炼 | 茗雾步、隐影诀；埋入异常证据 |

章末统一汇流：接到洛阳调查令，进入第四章。任务界面只显示已选择门派的分支任务。

## 第四章：洛阳奇遇

目标时长：15-22 分钟。核心体验是城市调查、两名关键角色登场和生擒活口。

| 场景 ID | 场景 | 主要功能 |
|---|---|---|
| `ch4_s1_luoyang_yamen` | 洛阳府衙 | 接案、查看卷宗、确定调查点 |
| `ch4_s2_siying_clinic` | 思颖医馆 | 受伤救治、赵思颖登场、医药支线 |
| `ch4_s3_luoyang_market` | 洛阳街市 | 流行追月比武、线索与城市支线 |
| `ch4_s4_ancient_temple` | 城外古寺 | 栽赃现场调查、章末战、生擒活口 |

主线：`q_ch4_main_01_luoyang_case` -> `q_ch4_main_02_ancient_temple`。支线按府衙、医馆、街市、城外四个区域逐步开放。

章末战分两阶段：外围伏击 -> “自称烈云盟”的首领。胜利后不直接击杀，进入审讯对话并写入 `captured_fake_liuyun_witness`。最终奖励为《青冥录》残页和第五章入口。

## 跨章系统要求

- `chapter_unlocked` 与 `current_chapter` 是章节显示的唯一依据。
- 任务日志只列出已接受任务；未接受任务不得提前泄露标题和章节。
- 每章至少 1 个主线 Boss/精英、2 类普通敌人、1 个非战斗互动目标。
- 第三章 faction flag 必须进入存档，并影响技能、任务、NPC 台词和后续奖励。
- 每章最多 2 个可操控探索区；其余使用 AVG 背景、角色立绘、对话和固定热点。
- 敌人采用场景可见接触战，不做暗雷；剧情对话结束后再恢复玩家操控。
