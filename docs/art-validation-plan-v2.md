# 美术风格一致性验证计划 v2（ChatGPT 网页版）

> **背景**：DMXAPI 不稳定（IP 风控 / Azure moderation / 503 渠道熔断 / 200 空响应，详见 `experience-log.md §1.5.1`）。
> **本文档范围**：**仅 L1 风格验证阶段**（5-20 张样本，决策导向）走 ChatGPT Plus 网页手动。
> **不在本文档范围**：L2 批量生产（数百到上千张）**仍然走 API 自动化**（DMXAPI 主路 + 容错 + OpenAI 直连备路），见 [`docs/decisions/ADR-001-art-pipeline-strategy.md`](decisions/ADR-001-art-pipeline-strategy.md) 2026-04-27 修订 #2。
> **目标**：在 1-2 个晚上内拿出"AI 美术能否撑起整个项目"的最终结论。

---

## 0. 工作流

1. 你打开 https://chatgpt.com，确认右上角订阅有效（Plus / Pro 都行）
2. 模型选**支持图像生成的最新版**（GPT-5.5 / GPT Image 2，看你账号有哪个）
3. **新开一个对话**，先发"前置 prompt"（§1）建立上下文
4. ChatGPT 回复"明白"后，按 §2 顺序贴 prompt
5. 不满意就追问微调（"再厚涂一点" / "脸再瘦一些" / "重绘一遍换姿势"）
6. 满意后右键图片 → 保存为 → 按指定文件名存到 `assets/art_validation_v2/<分类>/<id>.png`
7. 全部 stage 1 出完发我（截图或 git push 都行），我做评估报告

**预计耗时**：你 30-45 分钟出 stage 1（5 张），我 15 分钟评估。

## 0.5 为什么 L1 手动 / L2 必须 API（边界明确）

| 维度 | L1 风格验证（本文档） | L2 批量生产（不在本文档） |
|---|---|---|
| **资产数量** | 5-20 张 | 数百到 1000+ 张 |
| **目的** | 决策："AI 美术能不能做" | 生产：把决定要的资产都出出来 |
| **工具** | ChatGPT Plus 网页手动 | DMXAPI gpt-image-2 主路（容错） + OpenAI 直连备路（5 月 GA 后）+ DMXAPI gpt-image-1.5 降级 |
| **稳定性要求** | 手动出图几乎不失败 | 必须有容错（探活 / 退避 / 降级 / 多渠道 fallback） |
| **决策速度** | 30-40 分钟拿结论 | N/A（按计划批量跑，不计较单图速度） |
| **成本** | 月费 $20 已包，无单图成本 | API 单图 ≈ ¥0.13（DMXAPI gpt-image-2 token 计价实测） |
| **何时启动** | 现在 | L1 通过后 |

**关键原则**：**手动出图不是生产方案，只是验证方案**。L1 通过后，L2 阶段会重构 [`scripts/gen_assets.py`](../scripts/gen_assets.py) 加 4 类失败差异化重试 + 多渠道 fallback，**不再让用户手贴 700 次 prompt**。

## 1. 前置 prompt（每个新对话先发这一条）

```
你接下来要帮我为一款独立武侠 RPG 游戏生成美术资产。
这是我自己原创的故事，主角叫"沈不归"，不引用任何已有 IP。

整个项目的统一视觉约束：
- 美术风格：港式武侠漫画的厚涂质感
  墨线分明、色彩浓郁、人物五官立体有体积感、肌肉与衣纹线条有力
  衣袂飘动有动势、皮肤有轻微高光
- 整体氛围：古风武侠、苍凉、年代感、有戏剧张力
- 色温：偏暖（赭石 / 墨青 / 暗红 / 米色为主），避免冷蓝高饱和
- 镜头：默认 3/4 侧身或正面胸像构图，无强烈透视变形
- 严禁:
  - 现代服装 / 现代发型 / 现代配饰
  - 3D CG 渲染感、照片级写实
  - 二次元萌系、迪士尼风、网红脸
  - 文字水印、签名、logo

主角沈不归的固定外貌（之后所有提到他的图都默认这套）：
- 二十多岁黑发男子，长直发束于脑后，几缕散发垂在两鬓
- 脸型清瘦、轮廓分明、剑眉星目、神色冷峻
- 身穿黑色长袍 + 深色披风（披风内衬深色，不必特定颜色）
- 体格修长矫健，腰悬长剑

明白这些约束后请回复"明白"，然后等我发第一个具体生成任务。
```

> ChatGPT 回复"明白"后再继续，否则上下文没建立好。

## 2. Stage 1：5 张 NPC 立绘（最关键，先验这个）

> **为什么是 NPC 立绘**：主角一致性已经在 v2 测试里验证过了。真正的考验是 **5 个不同人**，每个都是新角色，但要保持**同一画师的笔触**。如果 stage 1 通过，说明 AI 能撑住整个项目；如果连这 5 张都画风跑偏，后面 UI / 场景 / 物品就别想了。

### 2.1 客栈老板 — `npc_inn_keeper.png`

```
第一张：清风镇客栈老板的胸像立绘。

人物：
- 五十出头中年男子，身材微胖、面色红润
- 国字脸，络腮胡修剪整齐，鬓角微白
- 头戴黑色软帽，身穿深褐色粗布短袍 + 米色围裙
- 神情和善但眼神精明，嘴角带点店家式的职业微笑

构图：
- 1024×1024 正方形
- 胸像（从胸部以上入画），3/4 侧身角度
- 角色占画面 70%，居中偏左

背景：
- 客栈内堂的暖色木质氛围（虚化处理，不抢人物）
- 背景能隐约看到挂着的红灯笼或酒幡

要求严格保持前置 prompt 里描述的港漫厚涂风格、墨线分明、暖色调。
重点：人物面部刻画到位，能让玩家一眼记住"这是个会说话的店家"。
```

## 3. Stage 1 评估（5 张出完后我做）

我会按 6 个维度打分（1-5 分制），写入 `docs/art-validation-report-v2.md`：

| 维度 | 怎么评 | 通过线 |
|---|---|---|
| **风格内一致性** | 5 张 NPC 看起来是不是同一画师笔下 | ≥ 4.0 |
| **跟主角风格契合** | 拿 v2_neutral 主角图对比，是不是同一世界观 | ≥ 4.0 |
| **角色辨识度** | 5 张 NPC 是不是 5 个明显不同的人 | ≥ 4.5 |
| **武侠氛围** | 不是动漫风、不是仙侠风、不是西幻 | ≥ 4.0 |
| **可游戏化** | 抠图后能直接当立绘用、不需要修脸 | ≥ 3.5 |
| **可重复性** | 同样 prompt 重出一遍能不能保持 | ≥ 3.5（这条要 stage 2 才能验） |

**通过判定**：6 项里 5 项达标 → 进 stage 2；3 项以下 → pivot（考虑 LoRA / 换技术栈 / 换画风）

## 4. Stage 2（stage 1 通过后才做）— 转 API 自动化

> **重要**：Stage 2 **不是用 ChatGPT 网页继续手贴**。Stage 1 通过即意味着"AI 风格能撑住"决策已成立，下一步是 **L2 批量生产**——重构 [`scripts/gen_assets.py`](../scripts/gen_assets.py) 加 4 类失败差异化重试 + 多渠道 fallback，然后**自动跑**几百张资产。

Stage 2 范围（待 [`scripts/gen_assets.py`](../scripts/gen_assets.py) 重构后批量跑）：

| 类别 | 数量 | 说明 |
|---|---|---|
| UI 元素 | 6 张 | 主菜单按钮 / 战斗 HUD / 任务面板 / 商店面板 / 背包格 / 对话框 |
| 物品 / 装备图标 | 6 张 | 铁剑 / 麻衣 / 小还丹 / 大还丹 / 凝气丹 / 地图（64×64 正方形） |
| 怪物 | 3 张 | thug_lone（路边匪徒）/ bandit_mountain / boss_zhao_wuji 战斗版 |
| 场景背景 | 3 张 | 官道 / 主街 / 废宅（替换现有 Lovart 占位） |
| 重做验证 | 2 张 | 同 prompt 跑 2 次比对，验可重现性 |

Stage 2 启动前必须做的**容错工程**（待办，不在 L1 范围内）：

- 跑批前 [`scripts/ping_dmx.py`](../scripts/ping_dmx.py) 探活
- `--concurrency 1-2` 默认（≥ 4 必触发 IP 风控）
- 4 类失败差异化重试：IP 风控等 30 分钟自动恢复 / Azure moderation 不重试改 prompt / 503 渠道熔断 5-30 分钟退避 / 200 空响应 3 次内 retry
- 失败任务自动降级到 DMXAPI `gpt-image-1.5`
- OpenAI 官方 `gpt-image-2`（≈2026-05 GA）作为最终 fallback

完整 L2 流水线计划在 [`docs/decisions/ADR-001-art-pipeline-strategy.md`](decisions/ADR-001-art-pipeline-strategy.md) §2.1。

**Stage 2 预计耗时**：API 重构 1-2 小时；自动跑 20 张约 30 分钟；用户全程不需要手贴 prompt。
