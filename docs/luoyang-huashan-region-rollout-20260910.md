# 洛阳与华山开放游历地图接入

本批将已完成的 2304×1536 区域母图接入游戏，背景、道路导航、人物、交互物与出入口同步迁移。运行时不拉伸母图。

## 洛阳三分区

| 场景 | 位置与作用 | 默认落点 |
| --- | --- | --- |
| ch4_s1_luoyang_yamen | 西北城门与府衙外院，门房查卷、含嘉水则石雕、切磋、终局复访 | (0.170, 0.190) |
| ch4_s3_luoyang_market | 西南南市，义诊摊、书生、诗会、军械铺、切磋与传闻文献 | (0.280, 0.515) |
| ch4_s2_canal_docks | 东侧沿河码头，漕运委托、脚夫任务战、老漕卒 | (0.650, 0.455) |

三者使用同一地域母图，不再把洛阳城市入口画成单间室内府衙。保留原 scene_id 以兼容任务推进和存档，分区在可见道路路口双向连接。府衙—南市、府衙—码头、南市—码头均可提前游历。古寺仍为独立郊外地图。

旧悬空人物热点改为真实 NPC；调查点依附地图中的实体。含嘉水则的推演与拓片共用中央圆形石雕，推演后才出现拓片阶段；门房卷宗依附府衙朱门。问诊药案与旧护具匠札记分别位于南市实际柜台及军械铺摊位；所有这些点都不在广场上摆放放大的背包图标。码头货箱保留实体箱子。主要调查仍受 chapter4_started / luoyang_case_found_clue 等条件保护。城市各区均为安全区，码头原随机战移除，救脚夫保留显式剧情战。三章完成才自动开启第四章，不因提前踏入洛阳而开案。

四张新接入场景启用 SceneScript.actor_positions_are_feet：玩家/NPC坐标、导航、落点都以地面脚底为准。旧场景仍沿用中心点语义，避免整体改变已验收旧地图。NPC更换谈话朝向、idle/walk贴图后保持脚底锚点，名称和碰撞同步。

## 华山公开山门与观瀑台

新增 openworld_huashan_forecourt，世界入口 (0.105,0.840)。从山门沿实际台阶与折返石路到西侧观瀑台，游天鸿位于 (0.113,0.344)。

初次对话可选择学习或暂离。学习通过正常 GameState.learn_skill 授予紫色「华山剑法·岚回三叠」，不要求章数或门派，悟性要求 6；悟性不足时加入待参悟清单，达标后正常习得。复访不重复发放奖励。此公开游历场景不改原第三章门派主线。
