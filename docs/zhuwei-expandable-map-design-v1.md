# 竹尾村可扩展地图方案 v1

## 目标

竹尾村从单屏场景升级为原生 3072x1024 横向可行走区域，不拉伸任一张 AI 图。玩家从西街进入，能经过主街、东街和桥头，进入酒馆与民居，并从东南道路离开。

## 生产结构

1. `terrain_left` 与 `terrain_right`：各为 1536x1024、无人无字的地形底图。
2. 两张地形图的接缝各预留 256px 重叠安全带：只允许连续石路、低矮草地、水沟或竹影，禁止屋顶、门柱、台阶、树干和角色。
3. 审图后先检查拼接预览，再以原生像素合成 3072x1024；禁止缩放、拉伸或用 HUD 遮接缝。
4. 房屋、树、栅栏、招牌、箱子均用独立透明 PNG 放置。房屋脚底才有碰撞；屋檐、树冠、门框走 `ForegroundLayer`，仅负责遮挡角色。
5. 每间可进入建筑拥有独立 `SceneScript` 与原生室内底图；外门仅是交互区，不能把“进屋”烘焙进底图。

## 竹尾村布局

- 西街：村入口、武馆切磋点、客栈外门。
- 主街：行商、求助村民、桥头传闻点；中间保持路面通行，不驻留战斗敌人。
- 东街：两户民居入口、小巷、城西出口。
- 酒馆：可进入，账册/传闻交互。
- 民居：后续加入床铺、信件、储物等支线解谜。

## 可行走与验收

- `WalkableMapLayout.design_size` 必须等于合成图的原生尺寸，`display_at_native_size = true`。
- 用小而明确的正向 `walkable_regions` 描出道路、门前台阶、桥面；不用整张陆地多边形。
- 每个入口、出口、交互物件都要有可达探针；每个屋顶、河流、树干、建筑脚底都要有不可达探针。
- 合成接缝必须通过截图检查：道路纹理、光向、阴影、地势和可行走线都连续，出现明显断线即淘汰整对面板。
