# MVP M5 验收清单 · 背包 / 装备 UI + 物品使用

> 目标：在 M4 多场景与商店闭环基础上，补齐玩家可见的背包、装备、物品使用与存档持久化。
>
> 范围：M5 只做探索场景中的背包与装备管理；战斗中使用物品、拖拽换装、图标美术与批量装备强化留给后续 milestone。

---

## 0. 启动前

- [ ] `Inventory` autoload 存在，且 `project.godot` 正常注册。
- [ ] `res://data/items/` 至少包含 HP 药、MP 药、剧情物品。
- [ ] `res://data/equipment/` 至少包含武器、护甲、鞋子、饰品等 M5 展示用装备。
- [ ] `field.tscn` 顶部 HUD 显示背包与装备入口。

## 1. 背包 UI

- [ ] 在 Field 场景按 `I` 或点击「背包 (I)」打开背包面板。
- [ ] 背包列表显示当前 `Inventory.slots`：
      - 物品名
      - 数量
      - 简短描述
      - 可用操作按钮
- [ ] 消耗品显示「使用」按钮。
- [ ] 装备显示「装备」按钮。
- [ ] 剧情物品只显示说明，不允许使用或丢弃。
- [ ] 背包为空时显示「背包空空如也」。
- [ ] 按 `Esc` 或点击关闭按钮可关闭面板。

## 2. 物品使用

- [ ] 使用 HP 药时：
      - 角色 HP 增加，但不超过 `max_hp`
      - 物品数量减少 1
      - 数量为 0 时从背包移除
      - 发出 `EventBus.item_used`
- [ ] 使用 MP 药时：
      - 角色 MP 增加，但不超过 `max_mp`
      - 物品数量减少 1
      - 发出 `EventBus.item_used`
- [ ] HP/MP 已满且物品没有实际效果时，按钮不可用或使用失败不消耗。
- [ ] 非消耗品、剧情物品不能通过使用按钮消耗。

## 3. 装备 UI

- [ ] 在 Field 场景按 `E` 或点击「装备 (E)」打开装备面板。
- [ ] 装备槽展示 6 类：
      - 武器
      - 头部
      - 护甲
      - 手部
      - 鞋子
      - 饰品
- [ ] 已穿戴槽位显示装备名与属性加成。
- [ ] 空槽显示「未装备」。
- [ ] 背包中装备点击「装备」后进入对应槽位。
- [ ] 装备面板点击「卸下」后对应槽位清空，装备仍保留在背包。
- [ ] 装备属性加成参与 `Inventory.get_atk_bonus()` / `get_def_bonus()` / `get_speed_bonus()`。

## 4. Field 接入

- [ ] HUD 右侧新增「背包 (I)」与「装备 (E)」按钮。
- [ ] 打开背包/装备面板时不触发场景热点。
- [ ] 对话播放中按 `I` / `E` 不打开面板。
- [ ] 任务面板 `J` 保持原行为。

## 5. 存档 v3

- [ ] `SaveManager.save_to_slot()` 写入：
      ```json
      "version": 3,
      "inventory": {
        "slots": [{"item_id": "healing_pill_minor", "count": 2}],
        "equipped": {"weapon": "iron_sword"}
      }
      ```
- [ ] `SaveManager.load_from_slot()` 能恢复背包与 6 槽装备。
- [ ] 旧 v2 存档没有 `inventory` 字段时，仍可加载为默认空背包。

## 6. 自动验证

- [ ] 自动校验脚本覆盖：
      - 消耗品使用会治疗并消耗
      - HP/MP 不超过上限
      - 装备 6 槽序列化 / 反序列化
      - 装备加成汇总正确
- [ ] Godot CLI 可用时，执行校验脚本通过；若本机未配置 PATH，则记录为未运行。

## 7. M5 不做

- [ ] 不做战斗中背包操作。
- [ ] 不做拖拽排序。
- [ ] 不做装备比较弹窗。
- [ ] 不做图标正式美术，仅保留文字 UI 与后续图标字段。

## 全部 ✅ 后

更新经验记录，提交 M5；进入 M6（章节结算 UI / 技能成长 / 更完整战斗体验）。
