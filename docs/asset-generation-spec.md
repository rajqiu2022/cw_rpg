# 资产生成规范（Asset Generation Spec）

> gpt-image-2 出图必须遵守的硬约束。每次生成新资源前核对，出图后验收。

---

## 一、角色精灵（NPC/主角 Sprite）

### 1.1 画布与比例

| 项目 | 规范 |
|------|------|
| 生成尺寸 | 1024×1024 |
| 角色占画布高度 | **25%~35%**（头顶到脚底，不是全身撑满） |
| 角色脚底距画布底部 | 约画布高度 **8%~12%** |
| 角色宽度 | 按人体比例自然，不要撑满 |
| 背景 | 纯白 #FFFFFF |

> 为什么：画布要留大量空白。Godot 中 NPC scale 默认 0.08~0.15，
> 如果角色占满画布 90%+，即使 scale=0.08 也会 2 倍于主角高度。

### 1.2 出图验收

```
[ ] 角色高度占画布 ≤ 35%
[ ] 角色脚底不贴画布边缘
[ ] 纯白背景可去底
[ ] 去底后角色高度 ≤ 400px（NPC）/ ≤ 200px（主角）
```

### 1.3 命名规范

```
npc_{name}_idle.png       # NPC 站立单帧
npc_{name}_idle_{n}f.png  # NPC 站立 n 帧 strip
hero_walk_{dir}_{n}f.png  # 主角行走动画
```

## 二、UI 元素

### 2.1 对话框外框

| 项目 | 规范 |
|------|------|
| 生成尺寸 | 1536×1024 |
| 对话框占画面高度 | **≤ 15%**（紧贴底部） |
| 宽高比目标 | 6:1（匹配 1800×300 场景帧） |
| 背景 | 纯白 #FFFFFF |
| 后处理 | 去白底透明 → RGBA PNG |

### 2.2 头像/立绘

| 项目 | 规范 |
|------|------|
| 生成尺寸 | 1024×1024 |
| 脸部占画面 | 50%~60% |
| 构图 | 肩部以上，居中偏上 |
| 背景 | 场景虚化散景（不要纯色/纯白） |
| 后处理 | 去白底（如有白边）→ RGBA PNG |

### 2.3 按钮

| 项目 | 规范 |
|------|------|
| 生成尺寸 | 1024×1024 或裁切参考图 |
| 三态 | normal / hover / pressed 整图生成 |
| 宽高比 | 约 4:1（横向长条按钮） |
| 文字 | 简体中文，手写楷体风格 |
| 后处理 | 裁切单态 → 透明底 RGBA |

### 2.4 UI 验收清单

```
[ ] 透明底 RGBA PNG
[ ] 尺寸匹配场景帧比例
[ ] 风格：寒山玄铁 · 雾蓝侠影
[ ] 文字简体中文无错字
[ ] 无繁体/英文/水印/签名
[ ] 亮度不低于 v6 主菜单基准
```

## 三、通用规则

### 3.1 Prompt 硬约束

每次 prompt 必须明确：
1. 元素占画面百分比（如"角色占画面高度 30%"）
2. 背景要求（纯白 / 虚化 / 透明）
3. 禁止项（繁体、英文、水印、签名）

### 3.2 后处理流程

```
生成 → 去白底 → 裁切 getbbox() → 保存 RGBA PNG → Godot 编辑器导入
```

### 3.3 场景 scale 计算公式

```
目标显示高度 ≈ 主角显示高度（~147px at scale 0.945）

NPC scale = 147 / (贴图去底后高度)
```
