# 大地图、重叠交互、南坊私塾与装备展示修正（2026-09-11）

## 用户反馈与处理结果

### 1. 大地图可见道路仍有不可行走区域

- 修正林西村至中央路网的一段中心线偏移，以及穿越村屋的旧返回线。
- 导航验收从“门户之间能连通”扩展为“底图可见公共路面横断面 + 角色脚底余量 + 危险地形负例”。
- 33个登记横断面共470点全部可走；5995个中心线样本保持5px脚底余量；13个世界门户连通；12个水面、悬崖和屋顶负例保持不可走。
- 上述100%只代表本批登记的公共路面样本，不代表已经自动识别整张底图的每一条装饰小径。

### 2. 林西村南坊出口被NPC挡住

- 农夫与巡村老兵移出两个出口的直接命中区域。
- 世界点击改由Field统一分发，优先级为：可见出口箭头、前景NPC、场景物件、裸出口地面。
- 鼠标与触屏均可直接点出口箭头；仍要求玩家在交互范围内，远距离点击只显示靠近提示。
- 根Control和纯背景不再吞掉世界输入，并过滤Godot鼠标/触摸互相模拟产生的合成事件，确保一次按下只执行一次。

### 3. 南坊私塾缺少课堂身份

- 新建独立公共私塾底图：先生讲席、书案、九套学生桌凳、中央与侧向过道、底部门口齐全。
- 新建24个实体阻挡和独立通行布局，出生点位于门内可行走区域。
- 旧私人书斋/账册场景未被覆盖，两个用途不同的场景继续独立存在。
- 运行底图：`game/art/backgrounds/bg_linxi_south_classroom_25d_v1.png`；生成原图、提示词和manifest位于`assets/raw/scene_background/linxi_south_classroom_codex_builtin_v1/`。

### 4. 当前装备槽与属性详情

- 六个装备槽显示64×64图标、槽位名和按品质着色的装备名称；空槽使用对应部位的语义图标。
- 左键打开与背包同构的固定详情卡，右键直接卸下；触屏先选择槽位，再使用可见操作按钮。
- 属性采用结构化带符号数据：正值绿色、负值红色、零值隐藏；特殊效果按装备品质着色。
- 角色与行囊、悬浮提示和旧I背包共用同一属性展示规则。
