# NPC 精灵、对白与配音核查

2026-11-17，Godot 4.6.2 桌面工程。

## 核查范围

- 检查八章、开放区域及室内的 111 个地图资源、151 条场景 NPC 摆放、439 个对白资源和 116 个战斗敌人定义。104 个地图通过正式 Router 的资源直载，其余 7 个以原场景数据核对。运行时追加的居民、任务阶段和动态生成对白仍需分别进场检查。
- 检查了对白起始节点、节点跳转、NPC 引用、显式头像和精灵文件，以及战斗五类帧的资源引用。修复后，此范围内没有发现缺失的显式地图精灵路径、断开的对白节点或找不到文件的已配置战斗帧。
- 从地图、交互和对白后继可追溯的具名发言共 426 条。381 条找到了同名且非空的候选 MP3，45 条未找到，含 12 条总录文书。这个文件统计未解码全部旧录音，也不包含临时对话和运行时发言人回退。

## 验证与余项

Godot 隔离实测 168 项通过。120 条录音逐文件加载，抽测走村货郎、古寺首领和大会执事实播，并验证缺段时回退整句。从正式地图确认三组新待机能切帧、两位客栈食客分别开口，从正常切磋入口确认林西乡勇教头的战斗外观。武当弟子和古寺埋伏兵通过战斗组件的出招、回备战和倒地停留测试。旧启动日志仍有与本批无关的洛阳来源校验报错。

仍有部分 NPC 共用基础精灵，部分战斗定义缺完整独立动作。已知角色配音可核对登记声线和实际播放键，旧录音的年龄听感、表演情绪以及动态对白仍待逐人逐分支试听。现有在线合成服务的试音返回 403，残余无录音台词未批量套用同一声线。部分旧称“晨市”的已配音剧情也仍需文本和录音同步更新。

- 当前场景或对白中仍指向缺专属战斗主图的角色，包括洛阳地痞、矿道灭口人、雪岭截路刀客、茗雾渗透者、茗雾暗哨和茗雾密探。七个已绑定地图精灵的切磋定义仍需独立战斗动作。
- 当前静态发言样本中，剩余 33 条缺候选录音的 NPC 台词集中在镖局枪手、守村人、护商镖师、沈伯、渡船管事等人。新增的行脚客对白由运行时分配，也仍缺独立录音。
