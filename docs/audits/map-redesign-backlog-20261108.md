# 正式地图改造盘点 · 2026-11-08

口径：只把玩家可进入、正式路由实际加载的唯一地图计入施工范围。章切换、门派/城镇 registry、剧情对话、普通门、双向楼梯与大地图入口是有效入口；旧存档 ID 别名、未接设计稿、历史 World 版本、测试房和战斗 UI 不重复计数。目录里的 TRES 数不是现役总数。

## 完成定义

每图登记正式 ID、入口/返回脚、旧/新资源和证据；室外要有地貌、自然路口、成片建筑布局，室内要有符合用途的分区与陈设。沿原任务、营业、遇敌、触发、NPC、宝箱及采集合同接入，确实需要变更坐标时验证安全落脚，不改任务和数值。真实进返或至少该变更的最高风险路线、正常镜头与代表性碰撞通过后，才把该图从待改移到已合。未定位到实际入口的旧资源另列待判，不假定退役或声称已升级。
