# 第一章后山洞窟多场景迷宫 v1

日期：2026-08-22

## 目标

把原先“一张洞穴图里同时完成宝箱、矿车、头狼和货筒”的单房间体验，扩展成可辨认、可回退、无死路的短迷宫。迷宫不依赖一张超长拼接图，而由四个固定镜头场景通过双向出口组成。

## 场景拓扑

```text
后山密林
   ↕
入口营地
  ↙    ↘
废弃矿道  地下水道
  ↘    ↙
  头狼深窟
```

- `ch1_s4_zhuwei_beast_cave`：入口营地。保留休整营火、旧木箱和矿车调查，向左右分出两条路线。
- `ch1_s4_cave_mine_gallery`：废弃矿道。中央岩柱形成小环路，左上有可选宝箱，右上进入深窟。
- `ch1_s4_cave_waterway`：地下水道。地下水潭把干燥岩台分成左右两条路线，两端汇合；右下有遗落补给。
- `ch1_s4_cave_deep_den`：头狼深窟。矿道与水道分别从左右进入，中央进行头狼战，后方调查封蜡货筒。

所有边均有反向出口。玩家可以从任一支路抵达深窟，也可以原路退回入口营地；没有只能进入、不能返回的死路。

## 节奏与引导

1. 入口营地是低压观察区，先看到左右岔路，不直接出现头狼。
2. 矿道用火把、矿车和矿脉引导，奖励偏伤药与钱。
3. 水道用蓝绿色水光作为地标，奖励一枚恢复内力的凝气丹。
4. 深窟用冷光、爪痕和兽毛形成战斗预告；击败头狼后才出现任务货筒。

## 美术与碰撞合同

- 三张新增场景均为 1536×1024 原生图，固定2.5D镜头，洞外留黑。
- 先制作行走拓扑图，再使用 Codex 内置生图按拓扑绘制正式背景；不调用 ALAPI。
- 场景图不烘焙文字、箭头、角色或任务标记。
- 可行走多边形只覆盖通道与战斗区；水潭、岩柱、矿车和货箱使用 blocker 保留碰撞。
- 任务物按任务与旗标显示：头狼仅在 `q_ch1_main_zhuwei_wilds` 进行中出现，封蜡货筒仅在头狼被击退后出现。
