# 村外雨景移动性能修正（2026-09-12）

## 反馈与原因

用户反馈林西村外下雨时移动明显卡顿。检查确认角色移动热路径已经有方向缓存和采样节流，新增压力主要来自雨幕：旧版全屏Shader在1080P每个片元中为远近两层雨丝反复计算多组伪随机哈希，与绘制背景同时合成时成本偏高。小雨还常驻9组由两条抗锯齿Line2D构成的落地水花。

## 调整

- Field首次需要雨景时，用固定种子一次生成128×128稀疏雨纹并缓存。
- 全屏Shader改为两次纹理采样，通过不同UV尺度、速度和偏移保留远雨、近雨与斜风。
- 冷色氛围、雨丝颜色、强度、透明度、剧情开关、室内抑制、存档和独立雨声保持不变。
- 小雨水花由9组减至5组，大雨/暴雨由12组减至8组。

## 验证

- Godot 4.6.2 editor import：exit 0。
- `test_environment_rain_batch_20260910.gd`：0失败，新增“无逐像素hash”和“缓存雨纹”约束。
- 环境动画、水雪天气、移动反馈、玩家四向步态4组相关回归：0失败。
- Windows OpenGL Compatibility、1920×1080、RTX 4080，真实山道雨景四向移动240帧：平均16.670ms / 60.0 FPS，P95 18.276ms，P99 33.208ms。
- 静态视觉证据：`game/screenshots/rain_mountain_road_performance_v2.png`。

## 剩余风险

桌面探针受60Hz垂直同步限制，且测试GPU性能较高。用户原复现场景、Web/微信和低端GPU仍需单独真机确认；若仍掉帧，下一步应增加平台级半分辨率雨层，而不是继续削减角色移动或道路碰撞精度。
