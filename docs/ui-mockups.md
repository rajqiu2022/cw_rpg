# UI 视觉规范 v0.1

> 此文档作为 AI 辅助 UI 开发的"视觉目标"（参考 godogen 的 visual-target 思路）。
> 改 UI 前先读此文档；改完后截图对比验证。

---

## 通用容器原则

所有面板遵循以下布局约束，**禁止** 硬编码 `offset_*` 值（除非是不可替代的艺术纹理定位）：

| 用途 | 容器 | 说明 |
|------|------|------|
| 面板整体居中 | `Control` + `anchors_preset=8` + `offset_*` 定大小 | 1280×720 尺寸居中 |
| 水平排列 | `HBoxContainer` | 按钮栏、属性行、分栏 |
| 垂直排列 | `VBoxContainer` | 标签列表、属性列、选项叠放 |
| 网格布局 | `GridContainer` | 装备槽位（2×3）、背包格子（6×N） |
| 边框/背景 | `PanelContainer` | 带主题面板背景 |
| 间距 | `theme_override_constants/separation` | 统一控制，不加空节点占位 |

```
│  │ [PanelBg 纹理铺满]                                       │  │
│  │                                                          │  │
│  │  ┌ VBox (标签栏) ┐  ┌── GridContainer (6列网格) ───┐   │  │
│  │  │ [全部]         │  │ [格1] [格2] [格3] [格4] ... │   │  │
│  │  │ [消耗]         │  │ [格7] [格8] [格9] ...       │   │  │
│  │  │ [装备]         │  │ ...                          │   │  │
│  │  │ [剧情]         │  └──────────────────────────────┘   │  │
│  │  │ [材料]         │                                       │  │

│  │                       │ [物品图标]                    │    │  │
│  │                       │ 名称 + 品质 + 分类            │    │  │
│  │                       │ 描述                          │    │  │
│  │                       │ 属性加成 (装备)               │    │  │
│  │                       │ 售价                          │    │  │
│  │                       └──────────────────────────────┘    │  │
│  │                                                          │  │
│  │  ┌──── HBox (按钮栏) ────┐                                │  │
│  │  │ 容量 25/80  [使用] [装备] [丢弃]  [关闭]              │  │
│  │  └───────────────────────┘                                │  │
│  └──────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────┘
```

### 改进要点
- 底部按钮栏：当前是 4 个独立硬编码 offset 的 TextureButton → 改为 `HBoxContainer` + `separation`
- 关闭按钮：当前在布局外 `(1089, 662)` → 移入按钮栏右侧
- 标签页 VBox 和 SlotGrid 的距离 → 用 `HBoxContainer` 包含二者

## 2. 装备面板 (Equipment Panel)

### 参考布局

```
┌──────────────────────────────────────────────────────────────┐
│  ┌───────── MainPanel (居中) ────────────────────────────┐  │
│  │ [PanelBg 纹理]                               [关闭 ✕] │  │
│  │                                                        │  │
│  │  ┌── 装备区 (GridContainer 2×3) ──┐  ┌ 属性区 ──────┐│  │
│  │  │ [武器槽]     [头部槽]          │  │ 筋骨   8(+3) ││  │
│  │  │   剑 icon                       │  │ 机敏   7(+0) ││  │
│  │  │   铁剑                          │  │ 内劲   8(+1) ││  │
│  │  │                                │  │ 悟性   6(+0) ││  │
│  │  │ [手臂槽]     [护甲槽]          │  │ 生命  10(+4) ││  │
│  │  │                                │  │ 内力   8(+0) ││  │
│  │  │ [鞋子槽]     [饰品槽]          │  │ 攻击     16  ││  │
│  │  │                                │  │ 防御      7  ││  │
│  │  └────────────────────────────────┘  │ 速度     12  ││  │
│  │                                      └──────────────┘│  │
│  └────────────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────────────┘
```

### 改进要点
- **严重问题**：当前 6 个 ColorRect 全是硬编码 offset（1320/1428/1515/1321/1423/1517），完全无法自适应
- → 改为 **`GridContainer(columns=2)`** + 统一 `SlotCell` 子场景/类
- 当前 `PanelBg offset_left = 1280`（溢出 640 宽的 Control）：→ 改为 anchor 居中
- 属性区：当前 10 个独立 Label 手工偏移 `offset_top` → 改为 **`VBoxContainer`**

## 3. 任务面板 (Quest Panel)

### 当前状态：较好

已经使用 `PanelContainer > VBoxContainer > HBoxContainer` 结构。
需要优化的只有左侧任务列表的样式一致性和选中高亮。

### 改进要点
- 任务条目统一用一个 `QuestItem` 子类生成（当前 `_build_quest_row` 在代码里造）
- 详情区当前使用 `RichTextLabel` + `fit_content=true`，可行

## 5. 战斗界面 (Battle Scene)

### 当前状态

使用相对锚点（`anchor_*` + `offset_*`），以 1920×1080 为基准。HUD 元素位置合理但部分硬编码。
战斗 UI 复杂度最高，当前迭代暂不重做，只记录规范。

## 6. 通用主题色

| 用途 | 颜色 | 色码 |
|------|------|------|
| 金色（标题/重要） | `#c8a04a` | UI_THEME.GOLD |
| 翠绿（功能/确认） | `#4ecb71` | UI_THEME.JADE |
| 钢蓝（信息） | `#5a8ec0` | UI_THEME.BLUE_STEEL |
| 深红（警告/关闭） | `#c05050` | UI_THEME.CRIMSON |
| 暗背景 | `#0a1018` 95% | panel bg |
| 文字主色 | `#d8dce0` | UI_THEME.TEXT |
| 文字次要 | `#788898` | UI_THEME.MUTED |
