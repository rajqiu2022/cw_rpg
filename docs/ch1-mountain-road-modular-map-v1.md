# 第一章山道模块化地图生产单 V1

## 目标

将 `ch1_s1_road` 从一张烘焙场景图替换为可扩展的 `3072x1024` 本地探索地图。它必须由一个无建筑、无交互物的自然地形底图与审核过的透明模块组成，不允许独立 AI 面板拼接。

## 当前运行状态

- 当前 `bg_ch1_s1_road_release_v1.png` 是可用的完整场景，但画面内已烘焙石碑和远处村屋。
- 它只可作为临时原生背景，不能叠加石碑、村门、建筑或围栏模块。
- 运行布局已锁定为原生 `1536x1024`，避免再次以布局尺寸放大。

## 目标地图构图

```text
西段：林西村外路口 -> 石碑观察点 -> 竹林缓坡
中段：路边木箱 -> 山贼遭遇区 -> 可绕行的岩壁肩部
东段：开阔上坡 -> 竹尾村方向出口
```

路线从左下方向中部延伸，再转向右上出口。三段地图以同一份可重复地面纹理和道路模块拼装，地图边缘由独立竹丛、岩壁、灌木和前景叶片收口。

## 底图合同

- 尺寸：单张原生 `1536x1024`，只允许作为自然地形底层；最终世界由同一模块体系扩展至 `3072x1024`。
- 可烘焙：土路、草地、泥土、远景岩壁、远景竹林、自然碎石。
- 禁止烘焙：建筑、村门、围栏、桥、路牌、石碑、箱子、尸体、武器、火盆、人物、敌人、文字、箭头、UI。
- 中心道路连续宽度不低于 240px，并预留石碑、木箱、遭遇区的水平路肩。

## 模块与层级

| 层 | 已有候选 | 使用规则 |
| --- | --- | --- |
| Ground | `road_dirt_*` / `road_grass_*` | 只铺地表，不作为碰撞依据 |
| Visual | `veg_bamboo_*` / `veg_bush_*` | 树根或岩脚才设置阻挡 |
| Interactable | 木箱、石碑、路牌 | 每个独立配置碰撞、交互范围、一次性旗标 |
| Foreground | `veg_foliage_fg_R` 等 | `render_layer = "foreground"`，只遮挡画面，不用整张透明图做碰撞 |
| Portal | 现有小型动态箭头 | 仅放在道路尽头，位于前景之上 |

## 验收

1. 原生像素构图中不存在拼接缝、重复建筑或烘焙交互物。
2. `design_size` 与最终纹理或组合地图尺寸一致，不能用来放大单张资源。
3. 正向 `walkable_regions` 只覆盖道路和路肩；角色从出生点能到石碑、木箱、遭遇区和东西出口。
4. 建筑/岩石/竹丛仅在脚底设置 blocker；前景叶片可遮挡角色但不切断道路。
5. 审图通过前，新底图和模块都不替换运行中场景。
