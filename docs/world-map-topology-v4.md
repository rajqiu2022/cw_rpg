# 江湖大地图拓扑 v4

## 目标

- 地图绘制顺序固定为：**玩法拓扑 → 可行走道路 → 阻挡地貌 → 高精场景图 → 门户与出生点验收**。
- 林西村与竹尾村是相邻村落，中间只有一段林西古道；茗雾山迁至东南雾岭，不再隔在两村之间。
- 玩家只能沿道路、桥梁、山口和渡口移动；群山、密林、江河与海面均不可直接穿越。
- 大地图只展示城市、村庄、门派和独立的大型区域。村外密林、山洞、废宅、漕渠、地道等内部场景必须从所属聚落或上级场景进入，不在大地图重复开口。
- 已接入据点保持可达；扩展据点只作为后续剧情锚点，不伪装为当前已完成内容。

## 可行走规则

1. `world_map_jianghu_layout_v4.tres` 只把道路走廊写入 `walkable_regions`，不再使用覆盖整张地图的大多边形。
2. 路径宽度按 2304×1536 逻辑图约 38–56 像素；交叉口和门户适当放宽，防止玩家卡在转角。
3. 每个门户中心必须落在道路走廊内；每个阻挡探针必须落在山体、森林、水域或海面。
4. 城镇出口与世界地图门户使用同一对双向锚点：从哪个城门出去，就从同一城门内侧返回。任何 `A → B` 场景入口都必须有语义一致的 `B → A` 回程，禁止出来落到第三个场景。
5. 野外节点显示建议等级；城镇安全区不触发随机战，只有野外道路与显式剧情战可以进入战斗。

## 美术约束

- 3:2 横向手绘武侠舆图，目标逻辑尺寸 2304×1536，最终运行图不得低于该尺寸。
- 道路必须与拓扑底稿一致且清晰连续；桥、山口、渡口是通行收束点。
- 地图本体不烘焙可读文字，由 Godot 门户标签显示地名与建议等级，避免生图乱码。
- 地标需一眼区分：村落、城郭、门派山门、山洞、废宅、渡口、海港不可使用同一建筑轮廓。
