## 原版为什么拼不起来

| 位置 | 实际问题 | 重设计处理 |
|---|---|---|
| 孤立岗楼 | 没有墙体、墙道或地形将它接入关防；只是另放一栋楼 | 左岗楼与门关做成同一关防核心，内部咬合整体成立 |
| 关门接直墙 | 墙顶高度、地脚、厚度和砖尺度各不相同；仅PNG包围盒相交不能当连接 | 两侧以统一接口接墙，墙顶/前后地脚/垛口分别对齐 |
| 右侧纵深墙 | 一块斜墙插进正墙，缺少转角，墙面与墙顶互相穿插 | 专用转角或连体墙翼；沿共同地形边界转向 |
| 场地边界 | 大矩形红地，无法解释峡口、防御线与高差 | 岩壁夹持关口，墙端嵌入岩肩；细夯土路与粗红岩分材质 |
| 饮水/货物 | 两件物件散放在空地，没有使用空间 | 饮水贴背风墙，候检收进路侧凹院，留开进门主路 |

## 新的空间关系

关防连续体：**左岩肩 → 短连墙 → 岗楼/门关核心 → 右墙翼/转角 → 右岩肩**。关防线的每个端头都有建筑或岩体承接。

主路从下方抵达门前，直接穿门，门内再折向右上方缓坡进入下一层台。主路采用较浅、较细的压实土；峭壁和碎岩留在路外。门前不做巨大无用途广场，也不把大石块纹理铺满通行带。

给水与候检是从主路侧面凹入的两个小空间。先定入口、站位与回到主路的连接，再放槽、货包、手车和NPC。它们的靠墙关系和防坠边界一起设计，避免只给物件找一块空地。

## 拆件边界与接口

最先重做**连体关楼核心**：门梁、门墩、相连岗楼与短接段作为一组建筑成立。模块化边界设在两侧规整的墙体接缝上，不再把独立岗楼拖到门旁凑。

| 模块 | 必须提供的连接 | 当前状态 |
|---|---|---|
| 连体关楼核心 | 左/右墙缝、门洞、前后落脚、可独立遮挡的门梁说明 | 待制作；旧gate＋tower组合不沿用 |
| 正面直墙 | 等高等厚的两端，连续墙道/垛口节奏 | 待按新核心出图，旧直墙不能默认合格 |
| 左/右纵深墙 | 各自正确的固定镜头朝向和同规格接缝 | 待制作；不用旋转正墙或镜像充另一方向 |
| 内角/外角 | 两轴墙面与墙顶真实转折，不能靠两个端面互穿 | 待制作 |
| 左/右岩壁收口 | 墙端嵌岩与地脚接触，完整岩肩轮廓 | 待制作 |
| 缓坡/挡墙 | 前后路面连续、高差/边缘/防坠关系一致 | 待制作/重新适配，不默认b坡道能直接接入 |
| 槽、货包、NPC待机 | 按成人比例与新地脚重新适配 | 原资源留存供复用评估，不能计为结构拼接完成 |

每个建筑接口至少标注五项锚点：前地脚、后地脚、墙道前沿、墙道后沿、垛口顶。相邻接口共享同一墙厚、墙道高度、砖块规格和受光方向，接缝不能只对齐透明画布边缘。

拼接余量应藏在真实结构（端柱/岩体）内，不能拿任意大面积重叠、地表盖片或淡出掩盖接口错误。源PNG完整alpha、留白、净门和人物比例仍要分别检查。需要本地改像素时另按明确范围处理，旧12图许可不自动扩大。

先锁地图镜头与成人112px尺度，再在新接口图上规定尺寸。此概念图的斜视、曲线路径和遮挡只作结构参考，**不从生成图直接推导世界坐标、碰撞、固定俯角、精确净宽或可走高差**。

## 下一次拼装的顺序

1. 连体关楼核心＋两翼墙＋必要转角/岩壁收口，先出无物件的整体结构预览。逐接缝检查墙顶、墙面、地脚是否连续，检查门洞和岩壁围合。
2. 加地面与内侧坡道，明确入口/出口、高差与禁止穿越的岩壁。核实实际完整人物通行、门下遮挡和返程。
3. 最后加路侧作业凹位、槽、货物与人物，检查尺度和用途。结构预览与实际场景需对照相同镜头。
