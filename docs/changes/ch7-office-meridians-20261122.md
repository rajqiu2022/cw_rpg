# 第七章茗雾内署的巡守与封脉

追查「内署亲令」时，内院的点腕巡守在权限档案房前拦路，「雾中点腕」每次命中增加 16 内伤。档案房的截流巡守守着审验室，「横剑截流」每次命中增加 20。两招均波及全队，逐人判定命中与护脉效果。巡守最多把每人内伤推到 90，胜利后保留到下一场，每道巡守只需击败一次。

审验室的护档使张袖蓄势，下一次行动才施展「封针散手」。命中增加 100 内伤，防住减半，冰心玉再减半。满 100 封招两个自身回合，仍可普攻、防御和用药。回春引能替一人清除积伤或解封；清心露供战斗中自救，场外禁用以免空耗。毁档战胜利后清除这段路线的积伤。

## 外院支线「反装的脉案」

外院开放内路后，可以向老药工打听两名抄手的伤势，接下寻案委托。外院西侧转运桌下藏着一本反装的蓝皮账，交回后领一枚冰心玉，满包可腾位再领。药工随后出售伤药与清心露。支线可以略过，主线卷宗会提醒玩家提前打听。新对白用文字呈现。[接单、取案、领玉与买药记录](../../reports/ch7_meridians_20261122/supply3.log)

## 同档三组实战

Windows 桌面开发版从主菜单读取同一个隔离存档。原 22 级审验室旧档沿原门退回外院，完成支线、用存档银两买药并一次性补满血后保存为共同起点。冷孤云 22 级，沈青禾和唐行舟各 14 级。三组均经 NPC 对白打完两道巡守、内署毁档，胜利后取出庄主私印底令并保存。[共同起点](../../reports/ch7_meridians_20261122/outer-before.json) · [原档回外院](../../reports/ch7_meridians_20261122/stage.log)

三组均保留原三人阵容，前两组青禾不施治疗。冰心玉组只给冷孤云戴一枚。首领战优先对付焚令手，青禾见到蓄势可防御，第一轮封针出手后按各人当时可用的单体招式追击。每次胜利后把三人补到满血。封招按轮到本人行动且招式确实禁用计数，各人的回合分别计算。金创药包含战斗和战后补血，已用背包起止数量核对。三组均未消耗清心露。
