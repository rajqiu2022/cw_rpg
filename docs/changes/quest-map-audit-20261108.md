## 已修正

- 竹尾新地图只取布局交互，旧热点中的双盆回声、扁担换肩和双车险局没有生成。三个交互接入竹尾村和晨市两套现役场景，沿用原对白、线索和奖励。村西南民居旁听回声，东南摊棚旁找脚夫，五线索齐后到东南工坊前的货车旁结算。接近交互点显示既有提示。
- 武当大地图入口改指山门后，早期游历与事后返回都失去了武林会场入口。山门新增可走到的会场箭头，前期可以解让位棋。第三章的开场对白仍要求完成第二章。
- 凌霜复命原先只检查北林救人旗标，提前游历山门就可以跳过旧矿洞追证。改为核对矿洞账册后才开放复命。失踪弟子支线的任务目标和交还对白改为指向实际的凌月山门。
- 凌月主楼、四处竹舍、静台亭和作棚按屋基轮廓调整碰撞。角色与建筑按投影脚点排序，斜屋基按当下横坐标取前沿。山门保留两侧柱脚和可走门洞。内庭入口从广场移到主楼正门台阶脚下，显示「主楼正门 · 空格进内庭」，返回落在同一扇门前。
