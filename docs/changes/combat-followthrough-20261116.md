# 战斗接敌、出手与收势

- 主角的剑、棍、拳掌共用位移驱动的步态，近身落脚才出手，按武器和招式选择命中帧，招式结束后恢复备战、换步归位。孤云九式保留四姿空翻，落地后补进剑势；暗器普攻原地出手，低帧率也给甩手姿态一个完整的渲染更新。原伤害公式、多段次数和武器外显不改。
- 唐行舟（队友和切磋对手）和狼王的原有步态改由推进距离驱动，呈现快出手、收招、退步；无真实多帧素材的其他敌人未纳入此改动。没有新增或加工 PNG。
- PC 隔离测试 `combat_followthrough03`：30 项通过；主角实测剑斩、剑刺、棍、拳、掌、暗器、翻跃接剑的分层帧与归位，其中暗器走正式攻击流程验掉血且不移动。唐行舟、狼王用正式战场动作组件，采样进攻/后撤为各四帧/各两帧，均单次 strike、回备战。另 `blade_wolf_followthrough04` 9 项通过，断岳刀实际攻击与狼王待机未回归。两轮自然退出，指定真实存档槽只核元数据且未变化，编辑器未关闭。
