# 竹尾晨市武馆改造

2026-11-10。晨市原生场景使用独立武馆门面。门楣有「晨市武馆」匾额，左侧是器械练功廊，正门敞开，门阶、箭头和原返回点对齐。外立面使用原生比例，按当前场景画面估算门洞净高约 165 世界像素。正式武馆进出仍用原两个场景 ID 和返回脚点。

室内中央留作往来及切磋，边区加入三名练拳、练棍、练掌的弟子，各用独立动作循环。晨市练家子、游馆师兄、沈家护院的场内精灵与切磋备战使用同一帧，战斗进身、出掌与受击从同一套角色图取帧。三人使用晨市专用敌人配置，沿用原切磋 ID、奖赏和招式威力。切磋用重斩改为同威力的空手推掌，以匹配新人物。其他地点的同名模板仍用原配置。落败帧复用受击姿态。

## 图片来源和生成提示

内置 imagegen，三张原始 RGBA 保存在 [武馆原图目录](../../assets/raw/zhuwei_dojo_20261110)。正式文件和帧资源位于 [武馆模块目录](../../game/art/modules/zhuwei_dojo_20261110)。挑战者用 Godot 图集区域取帧，练功帧按原像素取区并贴到统一脚底的透明画布，保留源图。

- [武馆门面原图](../../assets/raw/zhuwei_dojo_20261110/hall.png)｜透明背景的写实 3D 中式武馆，近正面微俯视，灰瓦、木柱、敞开的门和与门对齐的石阶，左侧为有木桩和棍架的练功廊。门楣文字「晨市武馆」，无人物和地面。
- [练功人物原图](../../assets/raw/zhuwei_dojo_20261110/drills.png)｜透明 4 列 3 行写实动作图。每行同一人物、服饰与方向，分别为深灰训练服男子练拳、褐衣男子练棍、灰蓝训练服女子练掌。保留头、脚和棍的完整轮廓。
- [切磋人物原图](../../assets/raw/zhuwei_dojo_20261110/challengers.png)｜透明 4 列 3 行写实角色图，每行分别为晨市练家子、游馆师兄和沈家护院。四列为备战、进身、攻击、受击，角色在各姿势中保持身份和服饰。

## 实机核对

桌面正常镜头核对了[武馆外观](../../game/build/zhuwei_dojo_20261110_qa/01-exterior-final.png)、[室内练功](../../game/build/zhuwei_dojo_20261110_qa/02-interior-final.png)、[沈家护院切磋](../../game/build/zhuwei_dojo_20261110_qa/03-sparring-final.png)。55 项通过。原门真实空格进返，三套循环均观察到至少四个姿态，三位切磋者均从原确认框进入战斗并回到各自原脚点。前置和到门口使用隔离测试状态与定点，未长途游历。首次室内串帧已通过独立帧修正。竹尾现役来源校验精确同步；另一路 CityNavigation 的既有来源不匹配与退出资源日志仍出现在测试中。

本轮截图与进返验证完成后，工作区内的晨市场景定义又出现改动，末次检查时它与原生来源表仍不一致。后续启动可能在加载武馆前被来源校验拦住。上述 55 项对应本轮已核验的文件组合。
