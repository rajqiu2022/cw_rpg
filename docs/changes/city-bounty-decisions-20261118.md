# 城市缉捕榜：追捕、验缴与冤案

## 玩家流程

- 汴州、襄州、金陵榜亭可在贴近榜前时用空格打开；同一空格此前可能被周边 NPC 抢走。榜亭只在紧邻且真正进入交互区时优先；榜亭和验缴官都在范围内时选更近者，不改远处一般 NPC 或出口的交互规则。榜上加大说明文字，保留两张榜文的版式；旧档有更多待办时可翻页。定义改用 ResourceLoader 列目录，避免按实体文件名漏读重映射资源；没有重打发布包。
- 四城原有十二案保留，另加汴州「沉舟劫粮」与金陵「劫盐伤役」两桩一次性冤案。各城每天从案件池随机排榜；同城同日重新打开不会抽出新名单。旧案在追捕、待抉择或待验缴时不下榜。
- 普通目标（包括江洋大盗和夜闯民宅的夜鹞）败后给物证和对应装备，战斗结算用现有品质色及装备图标。物证随身存档，背包满留在案袋；没装下的装备按已有结算提示显示。发榜衙门验缴才给钱、声望、历练和经验；原有附赏保留，已经作为战利品发放的那件装备不再重复发。
- 冤案胜利后听当事人交代，选择照榜交人、放其乔装离开、邀其乔装入队。后两项分别因个案扣 8 或 12 声望（沿用声望最低为 0），收下旧铜渡牌或镖局腰牌。回原衙门可同样领赏银，不加回声望，也不触发官府对主角的通缉。入队使用真实队友资源和存档 ID，现复用现有素材；未新制专属角色动画。
- 洛阳仍保留第四章主案先查公榜、再开放可重复榜的顺序。其公开城门在本轮改动前就出现 `CITY_COMPLETE_LIVE_VALIDATION_FAILED`，地图尚未显示，不能将其他三城的实测算成洛阳通过；未放松地图来源完整性校验。声望与后续剧情、门派职位的挂钩留待后续设计。

## 验证

- [榜亭测试](../../game/build/quest_warrants_20261110/board_probe.gd) 在正式场景定点到空闲的榜前脚位，然后实按空格、触发现有揭榜按钮，检查回到同城。PC 有画面，汴州、襄州、金陵合计 18 项、0 失败。
- [缉捕与抉择测试](../../game/build/quest_warrants_20261110/branch_live.gd) 用隔离档固定已接榜、候选藏身点和低血量，再走真实目标、普通攻击、胜利结算、对话抉择和衙门验缴。普通案 46 项、放行 50 项、移交 50 项、有画面招募及下一场战斗阵容 53 项，均 0 失败。这不是从世界地图长途全走或十四案全打；不读取或写入真实存档。
