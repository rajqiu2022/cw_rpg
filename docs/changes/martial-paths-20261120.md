# 九重之后的四门紫色武学

| 武学 | 第十重的条件 | 玩家反馈 |
|---|---|---|
| 华山剑法·岚回三叠 | 基础悟性达到 22 | 九重显示当前值与目标，达到后用阅历参悟 |
| 紫霞凝罡 | 基础内力达到 50 | 读取人物的内力根基，装备加成及当前剩余内力不参与判定 |
| 断雪回锋 | 完成第五章「雪路三哨」 | 三哨清除后向护粮守卫交差，九重修为与实战经历齐备便悟出末刀 |
| 惊燕穿云剑 | 完成「山涧奇遇」 | 在华山观瀑剑台听过游天鸿传剑后，第五章赈粮路开启起重访，选择留下观钓 |

属性线沿用普通升重价格与悟性折扣。支线已结而武学尚浅，会先在行功手记记下这段经历；练成九重时一并悟出末式，只支付八升九的阅历。先练到九重的角色当场结案即可领悟。五门门派与两门江湖绝学保留各自的行功提示和试配心法玩法。

## 从现有 PC 存档复核

- 取第五章交差前存档副本，按原有阅历把断雪回锋练到九重，在护粮营走到守卫面前交差，触发一次十重。可用阅历从 1787 到 2047，差额等于任务奖励 260。再次交谈进入回访对白。[护粮营记录](../../reports/martial_paths_20261120/camp.log)
- 在同一存档的另一副本预置惊燕穿云剑，再正常研读至九重。通过场景路由定位观瀑剑台，在场内实际走到游天鸿面前。首次听回锋口诀，复访选择离开，再访留下观钓，完成奇遇，再次交谈回到日常对白。只触发一次十重。这段验证从剑台开始，未徒步重走中原至华山，也未重打第三章论剑小会。[观钓记录](../../reports/martial_paths_20261120/elder.log)
- 面板与规则共 50 项通过。比较每项基础属性差一点、恰好达标、阅历差一点三个边界，佩戴实际提升悟性的手镯仍无法越过基础悟性门槛。两条支线覆盖先完成再修炼、先九重再完成。另起进程读出四门十重，零次重复演出。第五章已交差旧档副本调至九重验证静默补悟，第八章原有十重保留。五门派及两门江湖心法路线回归通过。[属性与顺序](../../reports/martial_paths_20261120/desktop.log) · [护粮营桌面面板](../../reports/martial_paths_20261120/camp-insight.png) · [冷读](../../reports/martial_paths_20261120/fresh.log) · [旧档](../../reports/martial_paths_20261120/legacy_ok.log)
