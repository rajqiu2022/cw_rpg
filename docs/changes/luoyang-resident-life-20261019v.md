# change-id: luoyang-resident-life-20261019v

目标：制作第一批有职业形象、可复访阶段对白和语音的洛阳居民候选；同时盘点多数生活NPC无对白的覆盖缺口。

本轮写权：lore只写新居民设计、候选manifest和12份新对白；system只写候选selector和审计，不接正式Field；art只写新纸匠模板；Root登记两次builtin生图、保存候选和配音工具、做有限校验及收束。彼此不重叠文件。正式地图、现有NPC/任务/奖励/存档、C/Field/Router及其来源校验不改。

子目标：

1. 四名既有身份各有三阶段生活对白，另设计12名核心居民长期规划，使用既有flags且不泄露未查明案情。
2. 老纸匠先做独立半身立绘与同人四帧精灵；不得把场景精灵放大冒立绘，年龄服装为本批候选而非既定世界观。
3. 明确声线、文本绑定和有界配音试产，生成文件不可覆写原游戏音频，失败保留且不自动重试。
4. 新候选selector/资源有限加载与状态测试；不重已通过的全城入口或十房测试。

验收：新对白可独立加载、链可达/无奖励和状态副作用；身份/脚位不被投影篡改、纸匠原任务对白不被闲聊抢占；配音输入有文本SHA和显式voice，复用只接受同输入同音频；图保raw与实尺寸/透明边/四帧脚锚检查，未通过不得接正式。

风险：现有36生活NPC明确留空dialog字段，不能简单登记catalog（Field对此类ground-anchored NPC会拒绝）；正式接入需要后续精确来源闭包迁移，不能删除校验。完整素材/配音尚未验收前不宣称正式玩家可见。

风俗依据：[中国非物质文化遗产网·洛阳牡丹花会](https://www.ihchina.cn/project_details/15243/)记述唐代洛阳种植与赏花传统。仅取日常种花赏花，不把1983年后官方花会名称写入古代，不把通用纸作/装卸习惯宣称洛阳专属史实。
