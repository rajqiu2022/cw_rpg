- 清河镇镇口驿舍旁张贴河埠盗货、勒矿伤工，目标在襄州矿谷。案子交襄州江防府。
- 赤岩镇关门外的路肩张贴盗驼队银袋、冒差截信，目标在中原旧驿。案子交汴州府衙。

- 复用现役地图、榜亭、战斗界面和素材，没有新增县衙室内或修改主线。洛阳自身的场景校验问题不在本轮范围。
