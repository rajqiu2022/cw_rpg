# 冷孤云战斗备战和拳掌动作

正式战斗待机按外显分四类。剑抬刃，刀压低，长棍双手握持，空手与拳套举手警戒。降魔杵使用单手重兵器架势。四类各一张专用姿势，左右沿用镜像及原有轻微呼吸。地图动作沿用原入口和持挂规则。

拳套普通攻击使用四帧握拳直击。标注为掌法的技能使用四帧推掌，继续使用原命中帧、移动和结算。两套动作分开标注双手锚点，神兵护手的光效沿手外缘走。实测用仙尊护手分别施展普通攻击和排云掌，并验证收势回备战。
