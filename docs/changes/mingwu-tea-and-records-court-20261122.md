# 第七章茗雾桥市与山庄外院

## 玩家进镇时看到什么

从南路来，先经过收茶铺，再到临溪客堂前的秤棚和验单桌。沿较细的石铺路向东，待运茶包和独轮车一直排到河边货棚，栈板接上泊船，北侧木桥通往山庄。街上六组独立短墙共十二段，已从正式场景和碰撞清单一起移除。

[从茶商处看桥市](../../reports/mingwu_map_review_20261122/01-tea-town.jpg) · [从桥头看货棚与泊船](../../reports/mingwu_map_review_20261122/06-bridge-market.jpg)

## 山庄外院

外院是办转运手续和封存案卷的地方。正门两侧共用一栋门房，西侧开窗收验，东侧落锁候运。案桌在开窗廊下，车和封好的货件靠库门，药工在西侧药棚旁。院心留给行人，石板下两道排水沟通向门房。门洞内的剧情出口和从内院回来的落点均按新门槛定位。本轮新绘的建筑与地面包括桥下货棚和船、档房门楼、竹边石庭。

## Windows x64 Release 复测

使用隔离 Windows 用户目录，从标题画面的继续游戏读取烈云旧渡 18 级存档二副本。验包进程无工程读取权限。测试驱动通过移动、交互、对话选项和战斗操作走剧情。

| 实走位置 | 观察结果 |
| --- | --- |
| 烈云旧渡 → 中原 → 茗雾茶镇 | 查渡口线索，问守渡人，入茶镇查转运桌、问茶商，「双线求证」结算。 |
| 客堂前两段旧墙脚 | 从南往北分别在地图横坐标 1585、2210 穿过原墙带，继续走至桥头，过桥进入外院。 |
| 外院 → 烈云分舵 → 外院 | 核对外院转运目录，返回烈云查封渡名册，实胜封渡战，两线互证完成。 |
| 外院药棚 → 案桌 → 药棚 | 找老药工接「反装的脉案」，翻到蓝皮账，交差前后冰心玉从 0 变为 1，装备成功。 |
| 山庄外院 → 内院 → 外院 → 茶镇 | 正常解锁后从新门槛进去，原路返回，最终落在茶镇山庄口。 |
