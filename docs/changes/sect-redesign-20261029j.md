# 武当与茗雾场景改造：设计先行 · 2026-10-29j

用户要求改造几个门派场景，本批先选此前已有总规的武当派与茗雾山庄。遵循用户此前“先做设计图”的要求，完成两张新版设计候选；尚未创建新的可试玩场景或覆盖正式门派地图。

## 武当派：云山层台

[原生设计图](../../assets/raw/sect_redesign_20261029j/wudang_masterplan_v2.png)

山门、太极道场、紫霄宫院形成三级主台，两个主要阶段明确连接上下台面；藏经院与弟子居舍通过东侧生活路线联系，后山清修形成西侧支线。灰岩、松林、铜绿瓦与深木构成高山轮廓。主殿、厢房、居舍、棚亭按用途区分体量；器架放道场边缘，同时保留拳掌和剑术活动空间。

看图结果：主要阶口和台地支撑清楚，瀑布奇观已收敛。部分后山路线被植被遮住，不能把画中路线当成已验证导航；下一步需制定地面坐标、高程、脚体净宽和边界碰撞。

## 茗雾山庄：茶谷曲院

[原生设计图](../../assets/raw/sect_redesign_20261029j/mingwu_masterplan_v2.png)

茶镇入口→外院客堂→内院回廊→议事主厅横向递进；茶园、晒茶与分拣作业通过独立服务路线连接茶镇。白墙深瓦、低谷溪渠、短桥和低台阶区别于武当的高岩层台。门墙与院廊围合，公共到私密的空间层次沿现有设定，不新增剧情门禁。

看图结果：整体已明显降低，溪谷和桥跨较旧图收敛；茶作/客院/内院可辨。左下部分房屋仍裁边，远处小径遮挡，图中阶数仍不能当精确施工数据。原图仅为整体设计，禁止裁房当模块，也不将其铺成可走背景。
