用户在29j两张总规之后明确“按照这个来改造”。本批将两派落为独立原生Godot场景，未覆盖其他城市或正式门派剧情地图。

打开相应场景按F6，默认正式冷孤云跟随与四向待机/行走；WASD或方向键移动、Shift快走、Tab全景/跟随、空格本地物件说明、Esc关闭、R返回入口。显示与人物脚点用同一高程数据；台阶插值改变人物高度和物理层，坎面及阶侧不可横穿。

## 设计落实与当前边界

武当新制五开间道殿、通行山门、生活厢房、山松、太极石坪和灰岩山体；铜绿瓦与灰岩区别于茗雾的新白墙庄厅、转角两层客堂、低檐茶棚、茶垄与白墙。建筑增加开间/层数形成差异，主角仍使用正式地图身体；没有拿战斗立绘充当地图弟子。

武当山门→太极道场→主殿连续攀登后，经藏经侧阶和生活侧路返回；茗雾先过平桥到平路，再上内院与庄厅低台，经东侧货路和另一座桥返回茶作区。白墙开口、回廊柱脚、桥栏、水域和岩石均有实际碰撞。台面、阶梯、坎界和侧墙已烘存为场景节点，可在编辑器查看；重载不会重复生成或二次抬高。

这次完成的是**可试玩室外首版**。设计图的密集山体包裹、连续曲院、建筑朝向/密度与生活人群仍有差距，未作完整设计还原终验；门派专属NPC与行走、业务内景、剧情服务和正式世界入口尚未接线。旧NPC与剧情ID未改。两派保留原有正式地图，本批F6场景不会替代大地图入口。

## 验证与失败保留

1. 首次隔离import退出0但shader多一个括号导致编译错误，原`import01`日志保留，不能当成功。修复后只导入本批新图及当前新源码；没有启动主工程全量import。
2. [首轮实机44项/2失败](../../assets/staging/sect_maps_20261029k/town_project/artifacts-k/verify01.json)：八阶上下、侧墙、坎面负控等42项通过；两桥向东终点要求超过480px，撞到x3400的台地侧墙，整报告FAIL保留。之后缩短桥并平移溪渠，桥端接平路；不是删除台地墙来放行。
3. [连续路线14项/0失败](../../assets/staging/sect_maps_20261029k/town_project/artifacts-k/routes02.json)：4014真实Godot键事件物理ticks；每派从默认出生点全程无途中瞬移，到主厅并走侧路返回，茗雾另一桥与茶作路线通过。自然退出0、stderr空。
4. [导入与保存读回20项/0失败](../../assets/staging/sect_maps_20261029k/town_project/artifacts-k/baked03.json)：12图RGBA精确、两场景烘存、节点不重复、视觉高度不重复、主角地层正确。自然退出0；12条原始PNG只读加载的“导出不支持”警告来自QA的Image.load_from_file，保留，不称空stderr。游戏场景本身使用导入Texture2D。
5. [保存后键盘残余14项/0失败](../../assets/staging/sect_maps_20261029k/town_project/artifacts-k/baked-input04.json)：Tab/Space/Esc、每场一处烘存阶口真上行、两桥当前尺度前后栏阻挡。自然退出0、stderr空。不重跑已经通过的整套路线。
6. 原生GPU全景、主厅及茶作图已逐张查看；北向坎立面原先错误显示成院后高墙，最终只绘制朝南可见立面，边界碰撞保持；院前铺地接到台基。功能成功不等于构图密度和最终美术成功。
