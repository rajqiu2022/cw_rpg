## 桌面验证

Godot 4.6.2 在隔离项目导入新 MP3，随后在正式桌面工程核对音频时长、文件哈希、对白节点和实际播放路径。第二轮 **1161 项通过，0 失败**。通过正式对白播放器实际启动林西采药回报、古峰路拦截、第六章师徒对质、第七章戚云笙作证、第八章苏雾笙对峙五个样本，同时检查旧版焦急妇人仍可播。第一轮有两句因测试未提供原章节前置而进入早访对白。第二轮补的是隔离测试状态，使用原游戏门槛。验证未经过从地图行走到 NPC 的全程，也未测试移动端或导出包。
