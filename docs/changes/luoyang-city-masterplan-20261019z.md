# change-id: luoyang-city-masterplan-20261019z

目标：按用户“先生成一版洛阳城大地图”的要求，先交整体空间规划与各区关键建筑要素，再依据同一总规改造分区。五张截图是问题证据，不是要照搬的布局，也不是本次图片编辑目标。

本轮交付：一张内置imagegen新生成总览概念图、十个分区的要素/地面/生活人群/探索层设计、前五项反馈的只读来源审计与后续验收清单。图为武侠游戏中的架空洛阳方案，不声称某朝代历史复原图；未指定年代，不私自新增皇帝/宫廷剧情。后续正式命名、任务和数值另按原世界观审核。

本轮不做：不部署y军士包，不要求关闭编辑器，不停止或卸载Ollama，不重跑Godot，不覆盖正式地图/门户/保存。生成图只作总规参考，不能直接当整张可走底图接入；实际仍是地面、独立建筑、院墙、树木、摆件分层组装。

分工：ART负责单图prompt/spec/登记/离线预检、建筑与美术要素；System只读确认HUD、任务物件、角色尺度、教官头像、三门门脸和码头南簇来源；Root负责规划取舍、内置工具唯一出图、图片审阅、交付及状态记录。首次仅一张，不自动重试或CLI fallback；若关键空间意图明显不符，先说明偏差再决定一次针对性编辑。未知模型/提供商/费用保持null。

核心验收：城墙与护城河组成完整城市边界；主街、次街、坊巷有层级与回环；建筑足迹与院落分离，不靠重叠屋顶凑密度；府衙、商街、民居、豪宅、码头、园林、古寺各有能辨识的地标、地面和生活人群；豪宅有独立大门/照壁/多进院园，不是普通铺面右门；商楼多开间不等于三个独立房型；任务探索层藏在侧巷/后院/仓栈支路，不在主街中央用高亮拾取物剧透。

前五项后续验收（本轮尚未实现）：

1. 任务摘要鼠标移入显示半透明黑底，单击可固定；再点取消，文本不跳位、不吞地图操作，复用既有正式PNG背板。
2. 码头先定仓栈、埠务所、装卸场、行人道与船位，再逐幢按足迹放置；建筑与檐口不穿插，可达门前净空保留。
3. 任务物件未接任务不得显示或可拾取；接取后仍须线索/调查定位，藏于可找但非主街直视处。主角仅调视觉与帧锚，碰撞/速度/导航不缩放，待统一人体身高而非整图高度对比。
4. 教官外观、头像、立绘须同身份：粗犷、壮实、有习武年龄感；先核既有生成资源及实际catalog覆盖链，不再兜底年轻村民脸。
5. 每个外门对应外观匹配的用途/内景和精确返回脚位；豪宅独立门院，普通商楼不能挂民宅/豪宅混杂三个入口。
