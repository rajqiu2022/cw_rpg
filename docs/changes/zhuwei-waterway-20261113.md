# 后山洞窟地下水道重建

入口营地接右下干岸，沿岩岸向北，再过横跨主水流的石桥到左上头狼深窟。水面、落差和岩壁均在可走边界之外。旧画面中的散置踏石改为单一连续桥面。油布药包放在右岸岩台边，可近身按空格或点击查看，沿用原对白和一颗凝气丹奖励。

新版使用 1536×1024 原生等比底图，场景配置按鞋底坐标定位。绘制路径、走区和两端箭头按同一张底图对齐。深窟一侧的返回交互区移到旧水道出口对应的安全地面。场景 ID、两端归来落点、敌人和任务状态沿用原定义。水流和瀑布使用底图绘制。
