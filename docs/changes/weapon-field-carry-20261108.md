# 刀剑佩腰、棍背负与断岳刀余烬

地图待机和行走共用收纳规则。普通剑、普通刀和烬河断岳刀用各自的鞘贴腰佩挂。侧面时由原主角近侧手臂遮住鞘口。木棍、降魔杵、通天棍和镇潮金箍棍背负，正面与侧面由身体遮住棍身中段，背面显示棍身。进入战斗后改用持握姿态。

烬河断岳刀的刀刃有橙红脉冲、外缘光晕和游离火星。收鞘后光和粒子集中在鞘口附近。保留原刀图、攻击帧和命中时点。

## 侧身背棍修正

左右侧身时，背上的斜棍按侧视投影贴近背脊并画在身体下层。棍身由当帧身体轮廓遮住，侧向停用漂散粒子。正背沿用原挂点和粒子。林西桌面版 89 项检查通过，覆盖四种棍的四向待机，以及金箍棍左右实际行走。
