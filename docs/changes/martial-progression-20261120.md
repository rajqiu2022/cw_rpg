# 武学研读、满层悟招与绝学破境

五派各选一门入门招式作为悟招基础。研读仍从一重开始，以可用阅历支付；悟性每高于门槛一点折价 5%，最多五折。九次升重按原基础价的 60%、100%、160%、240%、320%、430%、560%、730%、900% 计，再算悟性折扣、向上取整。五门入门招式统一基础价 8。悟性刚达标时，从一重练到四重只需 26 阅历，原来四派需 72，武当绵掌需 84。默认基础价 28 的紫色武学，同段从 168 降到 90。

| 门派 | 满十重的基础招式 | 领悟的新招 | 实战用途 |
|---|---|---|---|
| 武当 | 武当绵掌 | 绵掌·叠浪 | 单体内功，积累内伤 |
| 华山 | 华山一剑 | 一线穿云 | 穿透防御 |
| 古峰 | 开山一刀 | 叩关刀 | 两回合破甲 |
| 凌月 | 凌月点星棍 | 横棍拦江 | 横扫群敌 |
| 茗雾 | 茗雾扫风 | 袖底藏锋 | 两回合流血 |

原招继续可用。江湖棍法另有一条满层领悟线，悟性未达新招要求时沿用候学队列。旧档补发已经达到条件的传承，原有十重修为继续有效。

五派各一门绝学，另有盘龙十七式及擎天镇岳棍，在九重遇到瓶颈。武学页把「行功手记」放在九重详情最上面，写明卡在何处，玩家自行挑选心法。按「尝试破境」才验证当前装备，失配可再试，成功按本重价格扣阅历，展示圆环展开、招式图标及「恭喜突破第十重」。切换心法或重启都保留十重。林西回师门的剧情传承仍走原流程。

古峰护粮营新增行脚僧和行义帮粮秤人，分别承接涤脉禅关与三桩义约。江湖心法的探索途径和门派传授分开，任务和行功手记均不公布突破配对表。[阶段成长](../stage-progression-catalog.html) · [武学全录](../equipment-skill-catalog.html)
