# 第六章地下档库的两道毒哨与丹砂佩

林西正屋门边的送药人给出可选支线「灯布上的乌痕」。打听换灯老仆的伤势，在茶桌托盘下取灯布，交还可获一枚丹砂佩。送药人随后出售金创药和解毒丹。先谢绝也能从兵器架暗门进档库，回头仍能接单领佩。满包交还沿用现有奖励空位检查。新对白使用文字。[接单、领奖与买药](../../reports/ch6_archive_poison_20261122/supply.log) · [谢绝后过门、再回访领佩](../../reports/ch6_archive_poison_20261122/skip-next.log)

掌灯巡守在下层灯座旁用单体「毒针」，守架巡守在中段档架前用群体「油封散镖」。两人的招式只上普通毒，两战各自打赢就退场。销卷使与焚册客守在上层，销卷使袖底泛出青烟后，下次行动用「隐影夺命」。普通毒每个自身回合扣最大气血的 5%，烈毒持续三回合，每次扣 12%。防住隐影夺命能把烈毒降为普通毒；同一回合身上两毒并存时只结算较强的一种。丹砂佩减半佩戴者的毒发，青禾「回春引」能替一人回血并拔去两毒。

## 同档实战

Windows 桌面开发工程从第五章伪旗统领战前旧档出发，打赢统领，进入第六章，进林西正屋查完押运旁注与兵器架。接支线领佩、以存档银两买入金创药后，在暗门前保存。三组复制同一份存档，冷孤云 17 级，沈青禾和唐行舟各 11 级。每组均从正屋暗门入库，现场对话接三场战斗，获胜后查底册和涂改栏，完成「地底原册」。[原档到达正屋](../../reports/ch6_archive_poison_20261122/stage.log) · [三组共同起点](../../reports/ch6_archive_poison_20261122/hall-before.json)

三组阵容相同。第一组和第二组保留青禾但不调用治疗，第二组只让冷孤云佩戴支线的一枚丹砂佩。第三组无人戴佩，青禾优先为烈毒或剩余毒期较长的队友施回春引。沿路普攻，首领战先打焚册客，首轮隐影夺命实出后，先行动的队员防御，给青禾留出一次行动机会，再用可施展的单体招式追击销卷使。每战后全队补满气血，药量按背包起止数量核对。共同起点有 80 份金创药和 5 枚解毒丹，三组均未消耗解毒丹。前一次优先抢攻的试玩在青禾动手前就结束了首领战；为验证她能否实际拔掉烈毒，正式对照三组都留出同样的行动窗口。毒发只计队员实际掉血，逐次核对毒发前后的角色气血；兵刃直接伤害计入补血需求。以上每种打法各一趟，实际消耗随行动与命中变化。
