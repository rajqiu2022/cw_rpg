# 雾林断讯与半枚焦茶印

茗雾外围的截盟护卫、点烽手和精英统领同属叛徒组织「烬茶社」。第八章在集结地完成会盟点名后，第一次进雾林便会遇到他们的巡兵。林内每走满 320 像素有 32% 机会遭遇，每次按原有编组抽取单人、双人、三人或精英。进出林道仍可自由返回营地补给。

巡兵的刀、针和散镖都造成毒性伤害。普通攻击和绝招命中后均挂三回合普通毒，重复命中刷新时间；「血影散星」在这群叛徒手中换成淬毒镖。丹砂佩同时减半佩戴者承受的直接毒伤和毒发伤害。沈青禾的青木护元诀消耗 18 内力，全队在接下来各自三个回合减免六成毒伤，两者合用承受两成。回春引或解毒丹能清除已中的毒。

## 主线与支线

- **雾林断讯**保留截断烽讯、保护证人路线的目标。卷宗提示毒性与防护，开战前可看见叛徒袖口的焦叶印。西棚随军药师出售丹砂佩、解毒丹、金创药和回气药。
- **半枚焦茶印**从集结地西棚的护送药单接取。查找雾林东侧货堆，取回证人的黄绳药包和假领药印，再交回西棚，获得 80 金、120 经验、一枚丹砂佩和两颗解毒丹。支线可暂缓，回营交差与主线断讯各自结算。

Windows 桌面客户端从雾林旧档回到营地，先谢绝、再回来接单，找随军药师花 210 金买一枚佩和六份金创药，进林取回药包。从截盟使对白进入主线双敌战，打断烽讯后回营交差。沿路自然遇敌五场，包含单人、三人及精英。主线战结算一次，支线交差实得一枚佩和两颗丹。[剧情、自然遇敌和交差日志](../../reports/ash_tea_20261122/route3.log)

## 用药对照

另从已取回药包、已断讯、尚未交差的槽位冷启动。货堆没有重复出现，回营交差后奖励到账，断讯旗标保留。[读档续交](../../reports/ash_tea_20261122/resume2.log)

同一份 21 级三人队旧档，在 Windows 无画面引擎中固定巡兵编组，连续打完单点烽手和护卫加点烽手两战。每场结束后，用正式背包里的金创药给各人补至满血。对照用存档副本配发补给，各组开战前均已补满气血。金创药每份恢复 40 气血。受招数字为战斗公式的直接命中值，青木护元诀额外提供护体和回血，实耗药量已包括这些效果。
