# 第一章：藏物、临战制药与武器升级

## 玩家流程

- 林西山道、竹尾后山和后山洞窟加入四处一次性藏物：一件蓝品护手、一把紫品短刀、两张可阅读的残页。没有地图任务标或常驻文字；碰撞可达且靠近时才出现地面光圈，空格查看，确认后取出。背包已满时不消耗藏物。杜青衫有可选的山道线索；折竹残页本身有继续探索的线索。两页齐、悟性达到 6 后才可研习紫品「藏锋息法」，无需消耗残页。
- 野外草药可在背包的「药方 · 制药」中配成砺锋丸（伤害 +15%）、凝锋丸（暴击率 +15 个百分点）、固元散（有效防御 +8）。配方分为临战和常备两类，原有恢复/解毒配方保留，三种临战药不加入商店库存。使用战斗药遵守原有的背包操作消耗回合规则。
- 在林西向杜青衫选择「请杜师傅看看兵器」，进铁铺点「升级／打造」。+1、+2、+3 分别需要 2、3、4 铁矿及 10、20、35 金，每级攻击 +2；三个第一章矿点各给 3 矿。+3 品质升一级，橙品不变；获得不可重掷的 1～2 条不同附加效果，不替换原有特效。池为锋痕（命中后 18% 流血两回合）、淬毒（命中后 16% 中毒两回合）、破势（暴击倍率 +0.20）。强化存在单件装备上，同名副本独立，按同名物品结算的普通商店不会误卖强化品。
