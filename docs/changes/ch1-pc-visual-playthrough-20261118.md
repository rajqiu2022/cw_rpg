# 第一章 PC 画面复跑

## 看到的问题与调整

- 林西山道旧规则每走 620 像素就有一次 16% 的随机遇敌判定。画面复跑在训练后的山道穿行中打了 3 场路遇，前两场仅隔约 624 像素。现改成 1,600 像素、12%，仅作用于林西山道。相同工程的后继实走有 2 场路遇，其间约 1,592 像素。不是出战上限；敌人组、伏击、支线和返程不改。原生地图校验仍开启，只精确更新被改的场景及其清单哈希。
- 实际画面中，路碑外露的一角油布和白花能在进入交互圈前看见。竹尾猎径的藏页贴黑岩，入场描写改成玩家看得见的黑岩和折竹；洞窟的刀口旁补碎石，矿灯残页留作读信后的线索。山道铁矿不挪离岩壁，在主路肩到崖脚之间加不发光的离散碎石，并略放大可采矿体。太深、像污渍的第一版碎石未保留。
- PC 第一轮复现：后山随机山匪也写入了「废宅守卫已败」，到废宅时守卫消失。林中随机野兽同样可能提前开启洞窟。两处现只认可各自剧情战的胜利来源，普通击杀、掉落与经验照旧。保留旧存档已经写入的进度，不强制让旧档重打。

- 有窗口、有画面的 Godot PC 工程版从标题新档跑到 `chapter_end.tscn`，四处藏物、三种制药、三处矿、林西铁剑 +3、真正的后山兽群和废宅守卫以及赵无忌均经过实际游戏逻辑。用于整章复现的 [QA 路线脚本](../../game/build/ch1_exploration_tempering_20261118/playthrough.gd) 依据地标、寻路和实际交互，不传送或改剧情旗，但**不算整章盲玩**。
- 另在独立测试档做了两段只看窗口的检查：从山道入口顺道路、白花、碑和油布，按空格采白芍 ×2、取蓝色护路旧腕 ×1；从主路看新版碎石走到崖脚，看到交互光圈后按空格采铁矿 ×3。手动走这两段时未用地图坐标选方向。其余三处藏物未做只看画面的手动检查。测试窗口为自动化工具提供短按/长按方向辅助，移动碰撞与交互都是原游戏逻辑。
