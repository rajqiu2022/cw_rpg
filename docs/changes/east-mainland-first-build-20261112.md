# 东大陆与外海航线 · 第一批正式接入

从白鹿渡搭原船抵达东海埠，与渡船管事对话，选「搭外海船前往潮门港」。上岸后可经东大陆驿道进入沧浦城、盐湾村、茶岭村。原东海埠回白鹿渡选项保留；西返时从潮门船头先乘船返回东海埠，再换白鹿渡船。

## 本次实现

- 原西部 v16 世界不挪坐标、不改原进出门和来源校验。东部使用独立 6144×8192 场景；陆地海岸多边形同时用于绘制和走区，海路没有步行桥。
- 四处聚落各有独立布局与本地对白，潮门港码头、货栈和出港驿道分开；沧浦以市场街为中心，盐湾有网棚与渔船，茶岭有茶畦与作坊。复用已入库素材，本批没有重制专属建筑。
- 四条区域道路同源显示在地面和 M 键外海页上。外海页以虚线标航向，不能点击传送；可切回中原页。海域、道路和地标可见不代表是一张已合并的可连续走地图。

## 范围与限制

- 桌面测试从白鹿渡开始，两段船线往返均使用正式对话选项；四处聚落用实际 Space 触发，以夹具定位入口，未逐段全程徒步。核对道路绘制、海面与路口的走区判定、外海页和中原页切换。测试使用隔离档案目录，未读取、写入或恢复真实存档；没有关闭用户编辑器。
- [最终桌面日志](../../game/build/loading_20261106_system02/east_mainland_20261112_live06/stdout.log)：43 项通过、0 失败，自然退出 0；源文件和真实存档元数据前后无变化。另目视确认外海页无中原旧地名叠出。
- 返航进东海埠仍沿用其既有默认落点。本批未改旧港坐标版本，未做统一东西总览、东区右上小地图、沧浦河湾或盐湾专属晒盐场，未验发布包。
- 早期验证原样保留：对话框并行编辑时的编译失败、旧道路绘制只认遮罩、两条驿道经过建筑脚底的检查失败。首批路线通过后另修外海页旧西部标签叠层。既有纹理退出日志保留。
