# 烈云巡守战斗朝向修复

用户截图中的「烈云强硬派巡守」使用朝右绘制的旧蒙面首领图和三张出招帧，敌人定义却按朝左原图设置。修复前 PC 复现待机、移动、三张出招和受击收势均未镜像。

仅在 BattleSpriteFacing 加入这四个源文件的明确朝向。敌方在右侧时面向左侧主角；目标在右侧时仍能相应转向。没有直接全局翻转敌人、改立绘原图或数值，也不影响另一套朝左绘制的 standard_v2 蒙面杀手。

十二个现役敌人定义共用此图，包括烈云巡守、茗雾档房守卫、雾林拦路者及其精英版本，全部继承修正。
