# 八章敌人扩充 · 2026-11-12

后续调整：按用户要求撤掉洞穴巨蛛及其工程素材。后山矿道的随机编队恢复原狼类权重。下文记录首批接入时的内容和验证。

按[敌人盘点](../audits/enemy-audit-20261112.md)的四批顺序接入正式桌面工程。共新增 8 个敌人定义，启用 5 个此前无出场入口的定义，另更新 5 个现役敌人的动作或招式。所有新敌人可加载待机、移动、攻击、受击与退场五组帧。四个可选人形强敌和第四章刺客在场景与战斗中使用同一角色形象。

| 批次 | 接入地点与变化 |
|---|---|
| 1 · 早段与野外动物 | 第四章古寺地下运货道的伪烈云盟首领以四帧待机 NPC 出现，触发原对白和原三人编队，战斗新增伏步挑刀。竹尾猎径 G 键普通挑战为野狗，北林精英挑战为头狼。北林旧道随机表也增加野狗。江南芦荡加入斑虎，古峰雪岭关打完原剧情战后可遇雪熊 |
| 2 · 可选强敌 | 第三章古墓守卫、第六章茗雾断卷客、第七章烈云破阵校尉与茗雾封针使，均在原剧情条件满足后出现，交谈可迎战或离开。战斗胜利后沿用敌人击败旗，NPC 不再重复出现 |
| 3 · Boss 招牌技 | 伪旗统领抬手发出压阵旗令，群体伤害附虚弱，原两名开场援兵仍在原编队。苏雾笙以壶雨封脉同时攻击全队，沿用茶毒。薛影以三影截脉换位，在残影之间插入专属掌击帧。三招各有四张独立施招帧 |
| 4 · 西域和洞窟 | 赤岩镇关外 G 键挑战沙狐。沙漠城城门外可用 G 键挑战一队沙地野狗，再往外是高品质精英西域雄狮。后山矿道加洞穴巨蛛，古峰废矿加龙脉巨蟒，雁门关加寒岭苍鹰 |

动物随机编队保留原步距、判定概率和剧情门槛。新编队从原有普通条目中分出权重，各表仍为 100。竹尾头狼和西域雄狮沿用野外精英装备结算，剧情 Boss 仍走原剧情条件。沙地野狗与竹尾野狗共享同物种的动作，编队与数值各自配置。

## 验证范围

使用正式 Godot 桌面工程与隔离用户目录。第四章用真实 NPC 对话接回原三人战。四场可选战测试剧情条件满足后的出现、地图四帧、拒战、再次交谈和开战。竹尾及两座西域城的五处主动挑战用正式消费者开战。五张随机表核对物种、总权重、资源与音效。竹尾头狼和西域雄狮在低血量测试条件下经普通攻击击败，分别获得蓝品锁子甲和山岳重甲并入包，关闭结算返回原脚点。苏雾笙、薛影和伪旗统领在隔离双人队伍中由正式敌方回合施放，观察到专属第三帧、内力消耗及单次命中信号。洛阳导航仅同步实际改动的探险脚本哈希和长度。无界面验证未覆盖手机版、整章从头游玩或音效听感。
