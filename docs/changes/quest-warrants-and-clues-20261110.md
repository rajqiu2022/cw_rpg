# 白水旧路调查与四城缉捕榜

## 本轮正式接入

- 第六章「白水旧路」：原册给出交接地点，旧碑和窄车辙引向翻车一侧；靠近轮轴才可发现铜箍和换绑绳痕。线索能支持换车，不能单凭铜箍断定孩子在车上。保留原截证战和主线门禁，不在路中央生成独立大型道具。
- 第六章支线「三缺一的驿签」：从残驿的路牌背面接取，去翻车东侧查破木箱夹板，用刻痕和粮袋账排除干扰项。答错可重选。完成后给钱、经验、布匹和丹药；不要求完成此支线才能走主线。
- 第五章支线「少记的两袋粮」：护粮战后查营内分粮簿，在东棚粮车辕下找湿封签，回原处登记，证明两袋受潮粮只是移去晾晒。奖励金钱、经验、木料和布匹，不动原伪旗线索。
- 洛阳、汴州、襄州、金陵沿用现有榜单，保留原 8 案，另加 4 案。每日轮换、同案同日不可重复领赏；已经接受或待验缴的案件不会在轮换时消失。败逃仍会更换藏身点。
- 击败榜案目标后，物证进背包；背包满时留在案袋。到发榜府衙交验后才结算榜案的赏金、声望与地方物资或装备。洛阳安排在原府衙正堂，另外三城在对应榜亭旁安排验缴官，没有加建府衙室内。
- 通缉目标走原战斗路由。兼容旧榜单存档字段，并修正接近带高清替换精灵的目标时，原生描边宽度未覆盖而报错的情况。
