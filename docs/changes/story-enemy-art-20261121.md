# 伪旗统领、茗雾假令传使与护令客

三套独立透明图集以现有冷孤云持刀姿态为画风参照，沿用三个角色的服色。每人 16 个姿态，其中两门武功各有四帧。伪旗统领的压阵旗令在原地举旗发令，断门绝刃近身举刀下劈；传使以红黑披风和单手发针辨认，护令客着蓝衣、双手扣镖散射。两人的雾隐三式在原有移形步法中使用各自的连斩姿态。三人的普通攻击、受击后仰、屈膝和侧卧倒地各自取独立画面。

## 第五章　伪旗哨站

读取已有的 [16 级哨站存档](../../reports/ch5_ch8_rebalance_20261120/captain_before.json) 的隔离副本，步行接近伪旗统领，交互触发三段对白，与统领和两名伪烈云突袭手开战。胜局中实拍旗令、断门绝刃、受击、屈膝和落败；战后对白登记统领已败。

## 第八章　祭台假令

读取已有的 [23 级祭台存档](../../reports/late_campaign_altar_20261119/platform_before.json) 的隔离副本，从祭台传使发起对话。分开护证分支依次走完集结、宣令、质疑、拔刃、护证五段后进入原双敌战，战后完成「截住首令」并接到「庄主问局」。两场均使用存档内原有的队伍、装备与数值。先防守观察随机招式的一次复测落败，随后从同档正常进攻获胜，又从同档打完一场，录齐两名敌人的全部四门武功、受击及落败。下方祭台动作对照均取自最后这一场胜局。
