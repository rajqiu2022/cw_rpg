## 实现

- [layered_actor.gd](../../game/build/layered_actor_20261106_lab/layered_actor.gd)：同一身体帧＋独立武器Sprite＋同源手部Atlas视图＋资产化光效。手部是运行时纹理区域视图，不另存或修改人物PNG；矩形手部视图仍是样板实现，复杂手指轮廓应后续独立精修。
- [manifest.json](../../game/build/layered_actor_20261106_lab/manifest.json)：每动作逐帧脚锚、握点、角度、武器层级；每件武器独立握点、尖点和光效附着点。没有把武器画进人物底稿。
- 同一动画时钟控制动作，光效时钟随播放推进，暂停同步停止；换装即时替换整组武器/FX并清零光效时钟。身体与手部Atlas在配置时缓存，避免每帧构造资源。
- 武器基于item_id选择，未知ID/动作拒绝，不改物品数值。两种武器目前共用单手握姿，用于证明拆层能力，不宣称重刀独有发力动作完成。
- 原生右向、左向镜像；不是两份独立左右美术。遮挡示意保留遮挡物不透明，克制地补人物/武器0.42影像；矩形世界区域mask是试验台，尚未接主游戏真实建筑遮挡掩码。
- 独立项目使用Compatibility渲染器，从工程副本加载原图并生成内存mipmap，原图像素不改。不改主 `project.godot`、Player、Inventory、BattleController、Router、正式来源pin或存档。
