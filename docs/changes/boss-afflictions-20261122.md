# 第六章烈毒与第七章封脉

| 剧情战 | 蓄势与命中效果 | 玩家对策 |
|---|---|---|
| 地下档库 · 茗雾销卷使 | 袖底泛出青烟后，「隐影夺命」会给命中的队员施加三回合烈毒，每个自身回合开始损失最大气血的 12%。普通毒与烈毒同时存在时，两者各自计时，当回合只受较强的一次毒伤。 | 放招时处于防御或护体状态，所中的新毒为普通毒，每回合 5%。佩戴丹砂佩，普通毒和烈毒的持续伤害都减半。解毒丹能自救，沈青禾的回春引能替队友拔毒。 |
| 内署毁档 · 茗雾内署护档使 | 双袖张开后，「封针散手」对命中的每名队员施加 100 点内伤，独立于招式原有的普通中毒判定。满 100 点触发两回合气脉闭塞，期间可以普攻、防御、用道具。 | 防住这一击，所受内伤积累减半。冰心玉也减半，同时使用只积累 25 点。用清心露自救，或让仍能运功的沈青禾用回春引清除内伤并解封。 |

林西药铺的药师苏伯出售丹砂佩（120 金）、冰心玉（74 金）、解毒丹（50 金）和清心露（150 金）。两章任务卷宗均加了备战线索。沈青禾沿用已有的「回春引」，可选择一名存活队友，气血已满也能祛除毒与内伤。已有存档里持有的冰心玉和已学会的回春引直接生效。

## Windows PC 验证

使用现有 17 级地下档库和 22 级封印审验室战前存档的副本。两场均从现场 NPC 剧情对白开战，经过蓄势和命中后，冷孤云分别用解毒丹、清心露自救，沈青禾都用回春引救了唐行舟。两场均进入胜利结算。封脉时另检查了当前角色的招式全部禁用，普通攻击仍可使用。[档库实战](../../reports/boss_afflictions_20261122/archive_final.log) · [内署实战](../../reports/boss_afflictions_20261122/office_final.log)

购物环节在战前存档里直接打开正式林西药铺交易界面，购买一件饰品和两份对应药品，核对扣款并实际给沈青禾佩戴。下表为两场开场后的独立条件对照，用复制的角色属性结算同一招，不改场上角色的气血、状态或装备。

| 同一次命中的条件 | 销卷使，每次毒发（344 气血） | 护档使，从零内伤接招 |

| 无饰品，未防御 | 41 | 封脉 2 回合 |
| 只防御 | 17 | 50 点内伤 |
| 只戴对应饰品 | 21 | 50 点内伤 |
| 饰品加防御 | 9 | 25 点内伤 |
