## 实现边界

仅`project.godot`新增LifeSkills一行autoload；新增5个GD与1点表：recipes、crafting_service、gathering_service、crafting_panel、life_skills与gathering_sites。原Inventory/GameState/SaveManager/Router/ShopUI/任务/地图/PNG不写。新模块通过既有Field状态接口和原ShopDef精白名单接入，不绕严格native source校验。

制作先副本规划扣材料后的容量，允许材料耗尽释放格子；完整提交slots/gold/serial后才发原库存/物品/金币事件。失败不扣钱料不改实例编号，满包不部分加入，不用原add_item失败回滚；同步事件期间防重入。

普通点刷新采用全局“每累计3场非逃跑胜利一轮”，不是每点从采集起再计3场，也不按切场景/读档立即刷新。采集状态在`GameState.flags.life_skills_resources_v1`的victories/harvested字典中，沿原flags存档机制保存，不改schema。它不是剧情flag，写入不广播flag_set，避免旧MainField因普通草被采而重建地形；真正剧情导致world_container重建时，新增宿主检测失效根/节点并重装点位。

UI复用现有确认面板、商店按钮三态及字体；最终只运行时AtlasTexture选现有按钮非透明区域，不处理原PNG。标题/表格缩入画框，制造列表可滚动；简体中文，缺料/工钱/等级/空间明确禁用。
