# 后期区域地图统一改造 v2

日期：2026-09-09

## 统一基线

- 镜头：固定高位斜俯视 2.5D；禁止切回等距微缩模型、光滑 3D 渲染或纯平面舆图。
- 材质：以竹尾村 release v3 为基线，使用写实手绘木、石、瓦、植被与自然光。
- 尺寸：区域母图 2304×1536，覆盖约 1.2×1.42 个 1920×1080 视口；保留多屏探索感，同时降低微信端纹理与相机压力。
- 构图：一个区域母图包含 3～6 个功能分区，用道路、台阶、桥和回环连接；不再为每个任务节点单独生成一张单屏背景。
- 接入门禁：背景、导航蒙版、NPC/热点/入口坐标必须同批迁移。禁止只换底图。
