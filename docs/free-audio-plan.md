# Free Audio Plan

## Current baseline

`game/art/audio/free/` contains original procedural WAV files generated by
`scripts/generate_free_audio.ps1`. They are safe as project-owned placeholders
and are already wired to the runtime:

- `bgm_field_free_v1.wav` and `bgm_battle_free_v1.wav`
- attack, skill, hit, defend, UI confirm, victory and defeat cues

`AudioManager` loops WAV BGM streams, fades between scenes, and falls back to
these files whenever a scene, enemy, or skill has no specific audio path.

## Replacing them with free recorded assets

Use one of these libraries, then store the downloaded source and license note
next to the adopted file:

1. OpenGameArt: prefer assets explicitly marked CC0 or public domain.
2. Freesound: filter for CC0; do not assume every result is commercially usable.
3. Pixabay Music and Sound Effects: check the current Pixabay Content License
   for each downloaded asset and retain the asset page URL.

For every adopted file record: source URL, creator, license, download date and
the final in-game filename. Avoid NC (non-commercial), ND (no-derivatives),
unclear remix packs and assets without a visible license statement.

The game code does not depend on a particular library. Replace a path in a
scene, skill or enemy resource, or update the defaults in
`game/scripts/autoload/audio_manager.gd`.
