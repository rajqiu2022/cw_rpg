# 江湖大地图拓扑 v5

## 本轮修订

- 大地图只开放城市、村庄、门派与独立大型区域：林西村、竹尾村、凌月山、华山、武当山、古月峰、洛阳、茗雾山，以及白鹿渡、清河镇、雁门关、东海埠预留点。
- 后山密林、后山洞窟、城西废宅、河滩营地、洛阳漕渠与古寺地道不再作为大地图入口；它们必须从所属聚落或上级场景进入。
- 林西村与竹尾村位于西南并由一条短路直接相连；茗雾山位于东南，不再隔在两村之间。
- 运行图使用 1536×1024 Codex 内置生图母图，再由官方 `RealESRGAN_x4plus_anime_6B` 模型做神经细节重建，最终为真实 3072×2048，不再采用普通插值加锐化。

## 出入口合同

1. 任意普通场景入口 `A → B`，必须提供语义一致的 `B → A` 回程。
2. 一个场景存在多个来源时，为各来源保留独立出口。例如古寺同时可返回洛阳街市与漕渠码头。
3. 章末单向推进也要保留原入口：城西废宅内堂下方返回外院，上方才是推进到第二章晨市的出口；晨市另有返回内堂的旧路入口。
4. 世界地图与城镇使用同一城门坐标，离开和返回不跨越城区。

## 可行走区域

- `world_map_jianghu_layout_v5.tres` 使用26段相互重叠的道路走廊。
- 门户中心与通行探针必须位于道路走廊内；山峰、竹海、河面、海面和南部密林探针必须位于走廊外。
- 道路以外即使画面有空地也不可行走，避免玩家翻山、涉水或穿过建筑地标。
