# 可达性、战斗反馈与雁门关游历链修正（2026-09-11）

## 本批结果

- 林西南坊私塾入口的有效区域向门前道路延伸，仍保留近距离门槛，玩家不再停在门槛外却无法触发。
- 江湖大地图补宽洛阳西桥、雪岭上下折返、村落西北岔路等截图所示可见路面；13 个世界门户继续连通，危险地形负例继续阻挡。
- 白鹿渡段长风改用专门的四帧透明 Field 站立条带，不再把战斗立绘直接摆在探索场景。
- 战斗接敌期间按双方脚底纵深临时调整层级，后排攻击者穿向前排目标时位于目标下层，归位后恢复原阵型层级；当前行动只用箭头提示，不再强制把人物提到最前层。
- 普通战和队伍战胜利结算均记录每名参战成员的实际经验、升级前后等级；发生升级时显示 `Lv.X → Lv.Y 等级提升`。
- 成功撤离直接回到探索场景，不播放倒地、敌方胜利或失败结算；撤离失败仍正常消耗行动。
- 保留已审核的 8 类探索曲和 4 类常规战斗曲、1 类 Boss 曲，并按场景/遭遇稳定选择不同乐句入口，避免相邻场景反复从同一开头播放。
- 雁门关加入独立飘雪和低雾。原先入口即取的玄铁重剑、心法改为完整游历链：在关外累计两次战斗胜利或成功撤离后发现寒岭藏剑洞，洞内再通过两敌守藏战，才可开启石匣。
- 石匣给予玄铁重剑和《寒岭守元诀》秘籍，不直接学习心法。秘籍可在背包阅读，悟性达到 8 才能领悟，研习不消耗秘籍；学习入口与 `GameState` 都校验门槛。
- 林西南坊乡勇教头使用独立切磋敌人模板，调整为 240 气血、42 攻、8 防、32 内力，并使用普通攻击与重击；未修改 NPC、队友模板或全局伤害公式。
