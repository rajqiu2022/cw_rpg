# 环境叙事技术

> 来源：Game Design Skill for Claude Code - 基于《游戏设计的100个原理》

## 用途

通过游戏环境传达世界信息和叙事，不依赖过场动画或大段文字。

## 核心原则

**将游戏世界设定当作角色本身。**

## 执行流程

### 1. 识别叙事信息

- 谁掌权？
- 支持/反对派是谁？
- 各派系诉求是什么？
- 冲突原因是什么？

### 2. 选择环境元素

| 元素 | 叙事功能 |
|------|----------|
| 墙上涂鸦 | 揭示下层阶级利益 |
| 关闭的门窗 | 暗示恐惧或撤离 |
| 广播/公告 | 间接告知哪一方获胜 |
| NPC 对话 | 行人讨论短缺问题 |
| 物品摆放 | 暗示曾经发生什么 |
| 建筑状态 | 繁荣/衰败/战争痕迹 |

### 3. 设计角色空间

- 房间内容揭示性格特征
- 书架上的书 → 知识分子
- 武器架 → 武者
- 药材 → 医者

### 4. 实施测试

- 自然放置（不刻意引导）
- 需要观察力
- 可发现性（不是必须发现）

## 约束

- 不替代主叙事
- 不能单独传达复杂情节
- 需要玩家注意力

## 对本项目的应用（竹尾村/茗雾山庄）

### 场景：官道（ch1_s1_road）

| 环境元素 | 叙事信息 |
|----------|----------|
| 路边尸体 | 流贼横行，治安崩坏 |
| 石碑刻字 | 茗雾山庄势力范围标记 |
| 断剑/血迹 | 此处曾有战斗 |

### 场景：清风镇/竹尾村（ch1_s2_qingfeng）

| 环境元素 | 叙事信息 |
|----------|----------|
| 紧闭的门窗 | 村民恐惧，不敢出门 |
| 酒馆低声交谈 | 暗示有势力控制小镇 |
| 城门守卫 | 有人在监视出入 |
| 破旧的招牌 | 曾经繁华，现在衰落 |

### 场景：废宅（ch1_s3_hideout）

| 环境元素 | 叙事信息 |
|----------|----------|
| 被绑的人 | 茗雾山庄绑架平民 |
| 铁箱兵器 | 在收集武器，暗示阴谋 |
| 门后密室 | Boss 藏身处，权力象征 |

### 实现方式

- 通过 `hotspot` 的 `tooltip` 文字暗示环境信息
- 点击后进入短对话（1-2 节点），描述观察到的细节
- 不强制玩家查看，但好奇心驱动的玩家能获得更多世界观
- `set_flag` 记录玩家是否观察过某个环境元素（可影响后续对话选项）
