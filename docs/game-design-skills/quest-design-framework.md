# 任务系统设计框架

> 来源：Totten & Sandoval《World Design for 2D Action-Adventures》第4章 + 行业 Quest Design 最佳实践
> 整理日期：2026-05-24

## 用途

系统化设计 RPG 任务结构——从单任务节奏到全局任务网络，确保任务推动剧情、不重复、不空洞。

## 核心概念

### 任务的三个维度

每一条任务都可以在这三维上打分：

```
剧情驱动 ←——————————→ 系统驱动
（有角色有故事）      （纯粹数值目标）

线性 ←———————————→ 开放
（唯一解法）          （多路径完成）

必做 ←———————————→ 可选
（主线）              （支线/隐藏）
```

**所有主线任务**应该偏向"剧情驱动 + 线性 + 必做"象限。
**所有支线任务**应该偏向"开放 + 可选"，在剧情上做适度补偿。

### 任务链的四类拓扑结构

| 结构 | 图示 | 适用场景 |
|------|------|----------|
| **线性链** | A→B→C→D | 主线推进，章节制 |
| **轮辐式（Hub & Spoke）** | 中心城镇 → 多个独立支线 | 洛阳城、凌月山等据点 |
| **分支汇合** | A→(B或C)→D | 入派抉择（5派选1后再汇合） |
| **网状** | 多入口多出口 | 奇遇任务、隐藏结局条件 |

本项目的拓扑：
```
主线：线性链（章1→章2→...→章8）
支线：轮辐式（每章以据点为中心散发 3-5 条支线）
门派任务：分支汇合（章3选1派→章7重新汇合）
心向累积：网状（跨7章的多节点积分）
```

## 五步任务设计法

### 第 1 步：确定任务在拓扑中的位置

| 问题 | 回答 |
|------|------|
| 这条任务是主线/支线/门派/奇遇？ | — |
| 它依赖哪些前置任务？ | — |
| 它解锁哪些后续任务？ | — |
| 玩家在什么条件下触发它？ | — |

### 第 2 步：定义任务的心跳节奏

每条任务内部也要有"起-承-转-合"：

```
接受任务（30s）
  → 探索/赶路（30-60s）
  → 遭遇障碍（1-2min，战斗/解谜/对话）
  → 克服障碍（高潮段）
  → 回报/结算（30s）
```

**反例**："去某地杀 N 个怪"——缺少"起承转合"，玩家做完就忘。
**正例**：`q_ch1_main_zhuwei`（山道遇尸→调查→教学战→地图"快走"→密林）——每条主线任务都有叙事弧。

### 第 3 步：设计信息揭示（Information Unfolding）

参照 Totten §4.1 的"探索性信息揭示"原则：

| 信息类型 | 揭示方式 | 示例 |
|----------|----------|------|
| **必需信息**（不看不推进） | 自动弹出、NPC 直接告诉你 | 刑樊天说"去铁匠铺拿剑" |
| **引导信息**（看了更容易） | NPC 暗示、环境线索 | 石碑上的"小心"→ 前方有危险 |
| **隐藏信息**（不看也能玩） | 环境细节、可选对话 | 石坛刻字"活着回来"→ 刑樊天的心事 |
| **伏笔信息**（当前无意义） | 看似无关的细节 | 竹叶火焰纹 → 章七才明白是戚云笙 |

### 第 4 步：匹配奖励与投入

**奖励分类**：

| 奖励类型 | 体验效果 | 适用于 |
|----------|----------|--------|
| **数值奖励**（经验/金币/装备）| 即时满足 | 支线、战斗后 |
| **解锁奖励**（新关卡/新NPC/新武功）| 期待感 | 主线章末、门派任务 |
| **叙事奖励**（剧情揭示/角色发展）| 情感回报 | 主线高潮、心向分支 |
| **社交奖励**（称号/成就/隐藏要素）| 炫耀和探索欲 | 奇遇、收集 |

**奖励梯度**：主线 > 门派任务 > 支线 > 奇遇（数值上）

### 第 5 步：设置门控（Gating）

参照 Totten §2.1 的 switch/key/lock 机制：

| 门控类型 | 钥匙 | 适用 |
|----------|------|------|
| **Flag 门控** | 剧情 flag | `require_flag: "master_farewell_done"` |
| **物品门控** | 持有物品 | 凌月信物 → 凌月山入口 |
| **战斗门控** | 击败敌人 | `require_flag: "defeated_thug_lone"` |
| **等级门控** | 主角 Lv ≥ N | 高级区域入口 |
| **心向门控** | 好感度累积 | 章八结局 |

## 任务数据字段规约（本项目 .tres 标准）

```
quest_id       → StringName（全局唯一）
title          → 任务名称（≤10 汉字）
kind           → MAIN / SIDE / GUILD / SECRET
desc_not_started / desc_in_progress / desc_completed → 三态描述
completion_triggers → ["enemy_defeated:X", "flag_set:Y", "scene_entered:Z"]
reward_gold / reward_exp / reward_items → 奖励
prerequisite   → 前置任务ID
unlocks        → 解锁的后续任务ID
```

## 常见任务设计问题与修复

| 问题 | 诊断 | 修复 |
|------|------|------|
| **跑腿任务** | 只有"去A→回B"无中间冲突 | 在路程中加入 1 个障碍（巡逻兵/断桥/NPC 需要说服） |
| **收集任务** | 杀N个怪/捡N个物品，无叙事 | 给收集物加背景（"这些草药只长在你师姐的坟前"） |
| **任务岛** | 做完后对世界无影响 | 加后续 NPC 对话（被救的人出现在后面的场景感谢你） |
| **叙事断层** | 任务之间无因果连接 | 每条主线任务的结尾必须直接触发下一条（或给明确指引） |

```

  主线：考校→选门派→入派任务
  5派各有1条专属支线

章四（洛阳城 · Hub & Spoke）:
  主线：查案→医馆→古寺
  支线A：帮赵思颖采集罕见药材（+好感）
```
