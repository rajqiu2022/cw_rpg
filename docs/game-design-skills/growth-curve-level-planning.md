# 成长曲线与等级规划

> 来源：Dax Gazaway《Introduction to Game Systems Design》第13-17章 + 行业数值规划最佳实践
> 整理日期：2026-05-24

## 用途

规划 RPG 的等级范围、属性成长曲线、装备品质分层、敌人强度缩放，确保全程有"变强"的感觉而不会数值崩塌。

## 核心概念

### 成长曲线的三种形状

| 曲线类型 | 形状 | 每级感觉 | 适用 |
|----------|------|----------|------|
| **线性** | `value = base + growth × Lv` | 稳定、可预期 | 短流程（≤20级） |
| **指数** | `value = base × (1+rate)^Lv` | 越往后越爽 | 长线养成（50+级） |
| **对数** | `value = base + growth × log(Lv)` | 前期快后期慢 | 鼓励前期探索 |

**本项目的选择**：线性（8章 ≈ 10-15级成长空间），因为流程短，不需要指数膨胀。

### 品质分层（Equipment Tier Budget）

每个品质等级的战力预算倍率：

| 品质 | 颜色 | 预算倍率 | Lv1 武器 ATK | 掉落节点 |
|------|------|----------|-------------|----------|
| 凡品 | 白 | 1.0× | +5 | 商店/教学掉落 |
| 良品 | 绿 | 1.4× | +7 | 章3-4支线奖励 |
| 灵品 | 蓝 | 2.0× | +10 | 章5-6 Boss 掉落 |
| 神品 | 紫 | 3.0× | +15 | 章7任务奖励 |
| 仙品 | 金 | 4.5× | +22 | 章8最终Boss掉落 |

**原则**：同一品质的装备，高等级版本 ≈ 低一品质的高一等级版本

```
例：Lv10 凡品剑 ≈ Lv5 良品剑（战力约为 15 点）
     Lv10 良品剑 ≈ Lv5 灵品剑（战力约为 21 点）
```

### 战力量化（Power Score）

一个将所有属性映射到单一数字的公式，用于快速判断装备/等级是否平衡：

```
战力 = HP/10 + ATK × 2 + DEF × 1.5 + SPD × 1 + MP/5
```

| 等级 | 标准战力 | 战力成长 |
|------|---------|---------|
| Lv1 | ~55 | — |
| Lv3 | ~75 | +10/级 |
| Lv5 | ~100 | +12.5/级 |
| Lv10 | ~170 | +14/级 |
| Lv15 | ~245 | +15/级 |

## 五步成长规划法

### 第 1 步：确定等级天花板和总游戏时长

```
等级范围：1-15（MVP 可能是 1-10）
总经验值：约 5000（到达 Lv15）
平均每级经验：5000/14 ≈ 360
每场战斗经验：20-40（Boss 100-150）
每章战斗次数：3-5 场
预计通关等级：10-12（不做满级——留空间）
```

### 第 2 步：设置属性成长公式

```
每次升级：
  筋骨 +1    机敏 +1    内劲 +1    悟性 +1
  生命 +2    内力 +2    防御 +1

升级时派生刷新：
  max_hp = 80 + 生命×8 + 筋骨×3
  max_mp = 20 + 内力×6 + 内劲×2 + 悟性×1
  HP/MP 回满
```

### 第 3 步：规划每章的数值目标

| 章 | 推荐Lv | HP | ATK | DEF | 敌人战力 | Boss战力 |
|----|--------|-----|-----|-----|---------|---------|
| 1 | 1-2 | 184-210 | 15-16 | 8-9 | 30-50 | 120-180 |
| 2 | 2-3 | 210-236 | 16-17 | 9-10 | 50-70 | 150-200 |
| 3 | 3-4 | 236-262 | 17-18 | 10-11 | 60-80 | 180-220 |
| 4 | 4-5 | 262-288 | 18-19 | 11-12 | 70-90 | 200-250 |
| 5 | 5-6 | 288-314 | 19-20 | 12-13 | 80-100 | 220-280 |
| 6 | 6-7 | 314-340 | 20-21 | 13-14 | 90-110 | 250-300 |
| 7 | 7-8 | 340-366 | 21-22 | 14-15 | 100-120 | 280-350 |
| 8 | 8-10 | 366-418 | 22-24 | 15-17 | 110-140 | 350-450 |

### 第 4 步：设置装备投放节奏

**每章装备增量目标**（确保玩家感觉"每章都有提升"）：

| 章 | 新装备槽解锁 | 品质上限 | 主要获取方式 |
|----|------------|---------|------------|
| 1 | 武器、衣甲 | 凡品 | 剧情赠送+商店 |
| 2 | +头盔 | 凡品 | 商店+支线奖励 |
| 3 | +鞋子 | 良品 | 门派任务奖励 |
| 4 | +手套 | 良品 | 洛阳商店+Boss掉落 |
| 5 | +饰品 | 良品 | 古峰任务奖励 |
| 6 | — | 灵品 | 师承任务+奇遇 |
| 7 | — | 灵品 | 烈云盟赠予 |
| 8 | — | 神品 | 茗雾Boss掉落 |

### 第 5 步：设置敌人缩放曲线

**敌人属性 = 标准人 × 章系数 × 角色系数**：

```
章系数（Chapter Multiplier）:
  章1: 0.5×   章2: 0.7×   章3: 0.9×   章4: 1.1×
  章5: 1.3×   章6: 1.5×   章7: 1.8×   章8: 2.2×

角色系数（Role Multiplier）:
  杂兵:  0.6×    精英: 1.0×    小Boss: 1.5×    Boss: 2.0×
```

**示例**：
```
章3 精英敌人 = 标准人(Lv3) × 章系数(0.9) × 角色系数(1.0)
  HP = 402 × 0.9 × 1.0 ≈ 360
  ATK = 17.1 × 0.9 × 1.0 ≈ 15
  DEF = 6.1 × 0.9 × 1.0 ≈ 5.5

章8 Boss = 标准人(Lv10) × 章系数(2.2) × 角色系数(2.0)
  HP = 540 × 2.2 × 2.0 ≈ 2376
  ATK = 24 × 2.2 × 2.0 ≈ 106
  DEF = 9.5 × 2.2 × 2.0 ≈ 42
```

## 约束

- 不要让玩家**满级后还有大量内容**（剩余内容 = 浪费的成长空间）
- 不要让 Boss 的数值**超过同章标准人×2.5**（会变成数值碾压而非策略挑战）
- 装备品质跨度不要太大——仙品/凡品比 4.5× 已经很大（仙品是最终Boss掉落，可以）
- 每级战力提升应在 10-15% 之间（低于 5% 无感，高于 25% 变成数值碾压）

## 何时使用

| 场景 | 使用 |
|------|------|
| 新章节数值规划 | ✅ |
| 新装备设计前做预算 | ✅ |
| 玩家反馈"某章太难/太简单" | ✅ |
| 新增等级上限（DLC/扩展） | ✅ |

## 对本项目的应用

### 当前 MVP 第一章（Lv1-2）数值快照

```
玩家 Lv1（冷孤云）:
  HP=184, MP=90, ATK=15, DEF=8, SPD=12

教学战敌人（江湖散兵）:
  HP=60, ATK=8, DEF=3, SPD=6  → 战力约 44（远低于玩家 55）
  验证：TKK = 60/(15-3) = 5回合 → 偏慢，降至 HP=40 → 3.3回合 ✓

章末战敌人（蒙面杀手首领）:
  HP=150, ATK=24, DEF=6, SPD=10  → 战力约 111（玩家+悦无姮 ≈ 90）
  验证：TKK(有悦无姮) = 150/(15+20-6) = 5.2回合 ✓
       TTD = 184/(24-8) = 11.5回合 → 安全系数 11.5/5.2 = 2.2 ✓
```
