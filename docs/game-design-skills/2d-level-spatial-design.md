# 2D 探索型关卡空间结构设计

> 来源：Totten & Sandoval《World Design for 2D Action-Adventures》第1-5章（2024）+ Christopher Totten《An Architectural Approach to Level Design》
> 整理日期：2026-05-24

## 用途

为 2D 俯视/侧视探索型游戏设计有层次、有引导、有探索感的关卡空间，适用于 RPG 场景、地牢、城镇布局。

## 核心概念

### 关卡的建筑学隐喻

Totten 的核心主张：**关卡设计 = 空间设计 = 建筑学**。

| 建筑学概念 | 关卡设计对应 |
|-----------|-------------|
| **动线（Circulation）** | 玩家的自然移动路径 |
| **地标（Landmark）** | 场景中的视觉锚点（高塔、大树、发光物） |
| **围合（Enclosure）** | 场景边界和空间感（竹林围墙、山崖） |
| **层级（Hierarchy）** | 主路→岔路→密室的嵌套结构 |
| **门槛（Threshold）** | 场景切换点、Boss门、需要钥匙的入口 |

### 三大空间布局模式

| 模式 | 结构 | 玩家体验 | 适用场景 |
|------|------|----------|----------|
| **线性走廊** | 起点→A→B→终点 | 清晰、不迷路 | 新手关、主线推进 |
| **环形布局** | 绕一圈回到原点，中途多个分支 | 探索感强、不冗长 | 城镇、地牢 |
| **星形 Hub** | 中心安全区 + 多方向分支 | 自主选择、节奏可控 | 洛阳城、据点 |

### 门控层级（Gating Hierarchy）

```
            ┌─────────────────┐
            │   最终目标区      │  ← Boss Key（剧情 flag）
            │  （密林石坛）     │
            └───────┬─────────┘
                    │
        ┌───────────┼───────────┐
        │           │           │
   ┌────┴────┐ ┌───┴────┐ ┌───┴────┐
   │ 探索区A  │ │ 探索区B │ │ 探索区C │  ← 工具/能力门控（战斗/对话/物品）
   │（主街）  │ │（山道） │ │（酒馆） │
   └────┬────┘ └───┬────┘ └───┬────┘
        │          │          │
        └──────────┼──────────┘
                   │
            ┌──────┴──────┐
            │   起始区域    │  ← 无门控
            │ （新手关院子）│
            └─────────────┘
```

## 四步关卡设计法

### 第 1 步：设置地标和视线

每个场景的玩家进入后 **3 秒内**，屏幕上必须有一个可辨识的视觉焦点：

| 场景 | 地标 | 功能 |
|------|------|------|
| 新手关院子 | 石坛（发微光） | 暗示"这里可以互动" |
| 林西村主街 | 酒馆红色灯笼 + 铁匠铺的炉火 | 引导玩家走过去 |
| 村外山道 | 路边尸体 + 远处竹尾村的炊烟 | 制造紧张 + 给方向 |
| 竹尾密林 | 林深处透过树冠的金色光束 | 引导往深处走 |

### 第 2 步：设计动线（Player Path）

**动线三原则**：
1. **主线路径最亮/最宽/最直接**——不自觉得走上去
2. **支线路径偏暗/偏窄/需主动选择**——探索奖励
3. **回头路越短越好**——环形 > 死胡同 > 原路折返

```
新手关 动线设计：
  入口（右下）
    ↓  ← 石坛在左侧（探索奖励，偏暗）
  主干道（中央碎石路，最亮）
    ↓
  刑樊天（中央偏左，必经之路）
    ↓
  杜青衫（右侧铁匠铺，炉火引导）
    ↓
  出口（左上，石碑标记）
```

### 第 3 步：安置节奏点（Beat Placement）

每个场景需要有"呼吸"——紧张段和放松段交替：

```
场景 2（村外山道）节奏：
  进入旁白（放松，30s）       ← 抒情铺垫
    ↓
  发现血迹（微紧张，15s）     ← 环境线索
    ↓
  石碑"小心"（紧张上升，20s） ← 伏笔
    ↓
  尸体→散兵→战斗（高潮，60s） ← 教学战
    ↓
  拾取物品（回落，30s）       ← 奖励 + 线索（地图"快走"）
    ↓
  决定前往竹尾村（过渡，15s） ← 给下一场景造期待
```

### 第 4 步：隐藏信息层（Hidden Information Layer）

在必须走的路径之外，放"不找就错过"的叙事细节：

| 隐藏信息 | 位置 | 对叙事的作用 |
|----------|------|-------------|
| 石坛刻字 | 新手关角落 | 揭示刑樊天的内心（"活着回来"） |
| 木箱纸条 | 密林角落 | 伏笔刑樊天二十年前就在背叛茗雾 |
| 村口石碑小字 | 主街边缘 | 暗示刑樊天在村中的地位 |

## 场景设计检查清单

每个场景用这个清单过一遍：

```
□ 进入后 3 秒内，玩家眼睛落在哪里？（地标）
□ 主线路径是否比支线更显眼？（动线引导）
□ 至少 1 个需要主动探索才能发现的隐藏信息？
□ 场景内的节奏是否有"紧张→放松→紧张"的起伏？
□ 场景切换时，至少引入 1 个新元素？（新NPC/新机制/新视觉）
□ 是否有"回头路"？如果有，是否可以用环形结构避免？
□ 出口在视觉上是否清晰？（石碑/路标/光/炊烟）
□ 这个场景有没有让玩家记住的"唯一时刻"？（一句台词/一个画面/一个发现）
```

## 约束

- 建筑学方法最适合**预设视角**的游戏（2D 俯视、侧视、固定镜头）
- 不适用于程序化生成关卡（Roguelike）——需要人工微调每个场景
- 团队中最好有 1 人负责"关卡一致性"——避免不同场景风格割裂

## 何时使用

| 场景 | 使用 |
|------|------|
| 设计新场景布局前 | ✅ |
| 审核现有场景的玩家引导 | ✅ |
| 做开放世界（无缝大地图） | ❌（需不同方法论） |
