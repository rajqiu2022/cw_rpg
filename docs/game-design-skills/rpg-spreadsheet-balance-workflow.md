# RPG 数值建模工作流（Spreadsheet Methodology）

> 来源：Dax Gazaway《Introduction to Game Systems Design》第5-14章 + 行业数值策划最佳实践
> 下载日期：2026-05-24

## 用途

用电子表格（Excel/Google Sheets）系统化地构建 RPG 数值体系：从属性定义、标准人构建、到公式验证和全量平衡。

## 核心概念

### 标准人（Standard Person）

在确定所有公式之前，先定义一个"基准角色"。所有数值都相对于它来计算。

```
标准人 Lv1：
  HP:  360
  ATK:  15
  DEF:   5
  SPD:  10
```

**构建原则**：
- 标准人不是"玩家"，也不是"敌人"——它是一个**中性参考点**
- 所有职业/角色/敌人都是标准人的**系数变体**
- 例如：战士 HP = 标准人 × 1.2，盗贼 HP = 标准人 × 0.85

### 属性粒度（Attribute Granularity）

| 粒度级别 | 示例 | 适用场景 |
|----------|------|----------|
| 粗粒度（1-10）| 马力欧的 HP=3 | 平台跳跃、休闲游戏 |
| 中粒度（1-100）| 火纹的力量 1-30 | 策略 RPG、章节制 |
| 细粒度（1-9999）| FF 的 HP 9999 | 长线养成 RPG、MMO |

**选择原则**：粒度越细，平衡空间越大，但玩家理解和计算越困难。
**本项目的选择**：中粒度（HP 100-500, ATK 10-50），因为 8 章主线总长 80-120 分钟，不需要细粒度的膨胀空间。

## 六步工作流

### 第 1 步：确定设计意图（Design Intent）

在碰任何数字之前，先写清楚：

```
- 普通敌人应该存活几回合？ → 2-3 回合
- Boss 战应该打多久？     → 8-12 回合
- 一回合伤害占敌人 HP 比？ → 25-35%
- 玩家能承受几次攻击？    → 5-6 次（留有余量）
- 升级一次提升多少战力？  → 约 10-15%
```

### 第 2 步：建立标准人表（Standard Person Table）

| Lv | HP | ATK | DEF | SPD | HP成长 | ATK成长 |
|----|-----|------|------|------|--------|---------|
| 1 | 360 | 15 | 5 | 10 | — | — |
| 2 | 380 | 16 | 5.5 | 10.2 | +20 | +1.0 |
| 3 | 402 | 17.1 | 6.1 | 10.4 | +22 | +1.1 |
| ... | ... | ... | ... | ... | ... | ... |

**成长公式示例**：
```
HP(n)  = HP(1) × (1 + 0.06)^(n-1)    # 指数增长，每级 +6%
ATK(n) = ATK(1) × (1 + 0.07)^(n-1)   # ATK 成长略快于 HP
DEF(n) = DEF(1) × (1 + 0.05)^(n-1)   # DEF 成长最慢（防御不宜过强）
```

### 第 3 步：构建战斗公式（Combat Formula）

详见 [`rpg-combat-formula-handbook.md`](rpg-combat-formula-handbook.md)。
快速版：

```
基础伤害 = ATK × 技能倍率
实际伤害 = 基础伤害 × (1 - DEF/(DEF + 240))   # 防御递减公式
暴击伤害 = 实际伤害 × 1.5（如果暴击触发）
最终伤害 = max(1, 实际伤害 - 固定减伤)
```

### 第 4 步：模拟验证（Spreadsheet Simulation）

在 Excel 中构建以下表格：

| Turn | 玩家HP | 敌人HP | 本回合伤害 | 敌人剩余HP | 累计回合 |
|------|--------|--------|-----------|-----------|---------|
| 1 | 360 | 120 | calc | =120-D3 | 1 |
| 2 | =B2-敌ATK+防 | =E2 | calc | =E2-D3 | 2 |

**关键指标**：
- **TKK（Time to Kill）**：玩家击杀敌人需要的回合数
- **TTD（Time to Die）**：敌人击杀玩家需要的回合数
- **安全系数** = TTD / TKK — 应 ≥ 1.5

### 第 5 步：验证边界（Test Extremes）

用加倍减半法（见 [`doubling-halving-balance.md`](doubling-halving-balance.md)）快速测极端值：

| 极端场景 | 预期结果 | 实际结果 | 调整 |
|----------|----------|----------|------|
| 玩家 DEF ×2 | TTD 翻倍 | 2.1× | ✓ |
| 玩家 ATK ×2 | TKK 减半 | 0.48× | ✓ |
| 敌人 HP ×3 | TKK 增至3× | 2.7×（DEF递减影响） | ⚠ 检查boss战 |
| 玩家 HP ×0.5 | TTD 减半 | 0.52× | ✓ |

### 第 6 步：装备系统权重分配（Stat Budget）

按 Gazaway §13 的数据支点（Data Fulcrum）方法：

```
每个装备槽的总"战力预算" = 固定值

例：一把 Lv5 剑的预算 = 8 点
  分配方案 A：ATK +7, SPD +1     （均衡）
  分配方案 B：ATK +8            （纯攻击）
  分配方案 C：ATK +5, Crit +3%  （暴击向）
```

**6 槽总预算表（参考）**：

| 槽位 | 主属性权重 | 二级属性 | 战力预算（Lv1） |
|------|----------|---------|--------------|
| 头盔 | DEF 60% | HP 40% | 4 |
| 盔甲 | DEF 70% | HP 30% | 5 |
| 手套 | ATK 80% | SPD 20% | 4 |
| 武器 | ATK 100% | — | 7 |
| 鞋子 | SPD 70% | DEF 30% | 3 |
| 饰品 | 特殊效果 | — | 3 |
| **总计** | | | **26** |

## 约束

- 标准人方法是**原型期工具**——上线前需要真实玩家数据校准
- 电子表格模拟**无法替代**实际 playtesting（不包含玩家行为、策略、失误）
- 属性粒度选定后**不要轻易更改**（会导致全表重算）

## 何时使用

| 场景 | 使用 |
|------|------|
| 项目初期构建数值体系 | ✅ |
| 新增装备/技能前预算评估 | ✅ |
| Boss 战数值合理性验证 | ✅ |
| 上线后精细微调（±5%以内） | ❌（需真实数据） |

## 对本项目的应用

### 立即可以做的事

1. **构建标准人**：以冷孤云 Lv1 数据作为标准人基准
   ```
   当前 Lv1：HP=100, ATK=15, DEF=8, SPD=12
   → 重新校准到中粒度：HP=360, ATK=15, DEF=5, SPD=10
   ```

2. **建立 Lv1-20 成长表**：每级 HP+20, ATK+1, DEF+0.5
   ```
   Lv1:  HP=360, ATK=15, DEF=5
   Lv5:  HP=440, ATK=19, DEF=7
   Lv10: HP=540, ATK=24, DEF=9.5
   Lv20: HP=740, ATK=34, DEF=14.5
   ```

3. **校验教学战数值**：
   ```
   江湖散兵 (Lv1)：HP=60, ATK=8, DEF=3
   → TKK = 60/(15-3) = 5 回合 → 减半到 HP=40 → 3.3 回合 ✓
   ```

4. **校验章末战数值**：
   ```
   蒙面杀手首领 (Lv3)：HP=220, ATK=24, DEF=12
   → TKK = 220/(15-12) = 73 回合 ✗ 太慢！
   → 需要用技能倍率突破：
     林西基础剑法·一式 倍率 1.2x → 实际 ATK=18
     220/(18-12) = 36 回合 ✗ 仍然慢
   → 降低 Boss DEF 到 8：220/(15-8) = 31 回合
   → 加悦无姮助战（每回合 20 额外伤害）：220/(35-8) = 8.1 回合 ✓
   ```
