# RPG 战斗公式设计手册

> 来源：Dax Gazaway《Introduction to Game Systems Design》第9-14章 + 行业战斗数值最佳实践
> 整理日期：2026-05-24

## 用途

选择合适的战斗公式体系，构建伤害计算→防御减免→暴击判定的完整数值链，并验证公式的边界行为。

## 核心概念

### 公式选择的四个原则

1. **可预测性**：玩家能大致估算自己的伤害——不能完全靠猜
2. **无漏洞**：不会出现"无敌防御"（DEF太高→伤害=0）或"一击必杀"（ATK太高→秒Boss）
3. **递增感**：升级/换装备后有可感知的伤害提升（约10-15%）
4. **简洁性**：所有公式加起来，一个 Excel 单元格能写完

## 三大伤害公式族

### 族 A：减法公式（Subtraction）

```
Damage = ATK - DEF
或：Damage = max(1, ATK - DEF)
```

| 优点 | 缺点 | 适用场景 |
|------|------|----------|
| 极其直观，玩家秒懂 | DEF ≥ ATK 时伤害归零 | 短流程游戏（DEF 增长有限） |
| 零计算成本 | 后期数值膨胀严重 | 章节制 RPG（每章重置数值） |
| 易于调试 | 1 点 ATK 和 1 点 DEF 是等价的 | ATK/DEF 差距 ≤ 30 的游戏 |

**本项目适用性**：✅ 适合。8 章总长 80-120 分钟，数值不会膨胀到需要乘除法的程度。

### 族 B：防御递减公式（Diminishing Returns）

```
Damage = ATK × (1 - DEF / (DEF + K))
或 Damage = ATK × K / (K + DEF)
```

其中 K 是曲率常数。K 越大，DEF 的收益衰减越慢。

| K值 | DEF=80时的减伤 | DEF=160时的减伤 | 体验 |
|-----|---------------|----------------|------|
| 120 | 40% | 57% | 防御性价比低 |
| 240 | 25% | 40% | **推荐** — 防御有用但不无敌 |
| 480 | 14% | 25% | 防御几乎没用 |

**本项目适用性**：⚠ 可以作为"受伤虚弱机制的数学补充"，但不建议作为主公式——8章流程太短，玩家没时间感受递减曲线。

### 族 C：乘法/比例公式（Multiplicative）

```
Damage = ATK × 技能倍率 × (1 + 暴击加成) × 属性克制系数
```

纯粹用乘法链——没有减法项，全看系数。

| 优点 | 缺点 | 适用场景 |
|------|------|----------|
| 永远不会有"0伤害" | 容易数值爆炸 | 长线养成（MMO、Gacha） |
| 方便做属性克制 | 玩家没法心算 | 自动战斗为主的游戏 |

**本项目不适用**：8章太短，不需要乘法链的复杂度。

## 本项目的推荐公式方案

### 主伤害公式（减法 + 最低伤害保护）

```
基础伤害 = ATK × 技能倍率
实际伤害 = max(1, 基础伤害 - DEF)
暴击伤害 = 实际伤害 × 1.5（如果暴击触发）
最终伤害 = 暴击伤害 × 受伤虚弱系数
```

### 受伤虚弱系数（本项目独有机制）

```
敌人HP比例    虚弱系数（伤害输出能力）
100% ~ 70%  →  1.0    （正常）
70% ~ 50%   →  0.85   （开始减弱）
50% ~ 30%   →  0.65   （明显减弱）
30% ~ 10%   →  0.45   （大幅减弱）
10% ~ 0%    →  0.25   （濒死）
```

这个系数**双向适用**——玩家和敌人都是越伤越弱。

### 命中/闪避公式

```
命中率 = min(95%, max(5%, 基础命中 + 机敏 × 1.5 - 目标闪避))
闪避值 = 5 + 机敏 × 0.8
```

### 暴击公式

```
暴击率 = min(80%, 基础暴击(5%) + 武器暴击加成 + 悟性 × 0.5)
暴击伤害 = 1.5×
```

### 七属性到战斗值的映射（对齐 design-character-attributes-v1.md）

```
effective_atk    = 筋骨 × 2 + 内劲 × 1 + 装备攻击加成
effective_def    = 防御 × 2 + 筋骨 × 1 + 装备防御加成
effective_spd    = 机敏 × 2 + 悟性 × 1 + 装备速度加成
effective_crit%  = 5 + 悟性 × 0.5 + 武器暴击加成
max_hp           = 80 + 生命 × 8 + 筋骨 × 3
max_mp           = 20 + 内力 × 6 + 内劲 × 2 + 悟性 × 1
```

## 公式验证清单

每新增一个战斗公式，用以下边界测试：

| 测试场景 | 输入 | 预期 | 验证 |
|----------|------|------|------|
| 最小值保护 | ATK=1, DEF=999 | Damage ≥ 1 | `max(1, ...)` |
| 命中上限 | 任何命中计算 | ≤ 95% | `min(95%, ...)` |
| 命中下限 | 任何命中计算 | ≥ 5% | `max(5%, ...)` |
| 暴击上限 | 任何暴击计算 | ≤ 80% | `min(80%, ...)` |
| HP不溢出 | max_hp公式 | > 0 | Lv1 时 > 80 |
| MP不溢出 | max_mp公式 | > 0 | Lv1 时 > 20 |
| 零防不死 | DEF=0, ATK=100 | Damage = 100 | 减法公式自动满足 |
| 满防不无敌 | DEF=999, ATK=100 | Damage = 1 | `max(1, ...)` |

## 战斗回合模拟器（Excel 伪代码）

```
A1: 玩家HP    B1: 敌人HP    C1: 回合数
A2: =360      B2: =120      C2: 1

D2: 玩家伤害 = max(1, (玩家ATK × 技能倍率) - 敌人DEF) × 虚弱系数(敌人HP%)
E2: 敌人伤害 = max(1, (敌人ATK) - 玩家DEF) × 虚弱系数(玩家HP%)

A3: =A2 - E2    # 更新玩家HP
B3: =B2 - D2    # 更新敌人HP
C3: =C2 + 1     # 回合+1

下拉直到 Bn ≤ 0（敌人死亡）或 An ≤ 0（玩家死亡）
```

关键输出：TKK（回合数直到敌人HP≤0）、TTD（回合数直到玩家HP≤0）。

安全系数 = TTD / TKK。目标值：
- 教学战：≥ 5.0（玩家几乎不会输）
- 普通战：1.5 - 2.5（有压力但大概率赢）
- Boss 战：0.8 - 1.5（需要策略/道具才能赢）

## 约束

- 公式选定后**不要在开发中途切换**（族A→族B会导致所有数值重做）
- 系数（K值、倍率等）可以调，但公式结构不要动
- 受伤虚弱系数是**双向**的——意味着玩家也需要在低HP时撤退或嗑药，否则会陷入"越弱越打不过"的死亡螺旋

## 何时使用

| 场景 | 使用 |
|------|------|
| 新增敌人/Boss前验证 | ✅ |
| 新增技能/装备前验证 | ✅ |
| 玩家反馈"战斗太难/太简单" | ✅ |
| 添加新的伤害类型（毒/火/冰） | ✅（需补充公式） |

## 对本项目的应用

### 立即可以校验的数值

**当前 M6 待做项**：
```
敌人数据（需创建 .tres）：
  江湖散兵:    HP=60,  ATK=8,  DEF=3,  SPD=6
  蒙面杀手×2:  HP=80,  ATK=14, DEF=5,  SPD=9
  杀手首领:    HP=220, ATK=24, DEF=8,  SPD=10

校验：
  vs 散兵：TKK=60/(15-3)=5回合（等虚弱后约6-7回合）⚠ 偏慢
    → 减半到 HP=40 → TKK=3.3 回合 ✓

  vs 杀手×2：TKK=80/(15-5)=8回合 × 2个=16回合 ⚠ 拖沓
    → 悦无姮助战每回合打18-25伤害 → 每个杀手约3-4回合击杀 ✓

  vs 首领：TKK=220/(15-8)=31回合 ✗ 严重拖沓
    → 降低首领DEF到6：TKK=220/(15-6)=24回合 仍慢
    → 加悦无姮助战（每回合20）：TKK=220/(15+20-6)=7.6回合 ✓
    → 或把首领HP降到150：TKK=150/(15+20-6)=5.2回合 ✓
```

### 推荐的首领数据

```
蒙面杀手首领（masked_killer_leader）:
  HP:  150（降低后可 5-8 回合击杀）
  ATK: 24（每下打主角 ~16 伤害，主角能扛 6-7 下）
  DEF: 6
  SPD: 10
  技能：毒针 — 造成 18 伤害 + 40% 概率中毒（每回合扣 5% HP，持续 3 回合）
```
