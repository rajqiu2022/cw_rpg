# 体验节奏与结构

> 来源：Game Design Skill for Claude Code - 基于《游戏设计的100个原理》

## 用途

管理游戏流程、关卡结构、加载画面、过场动画、内容引入。

## 先行组织者类型

| 类型 | 用途 |
|------|------|
| 前期宣传 | 广告、Demo、预告片 |
| 加载画面 | 引入角色/建立视觉基调 + 时间指示器 |
| 过场动画 | 提供背景和上下文 |
| 选择菜单 | 使用视觉结构（地图而非列表） |

## 游戏体验结构

### 沙盒体验

- 自由探索 + 简单可组合机制
- 适合开放世界、建造类

### 轨道体验

- 线性完成
- **火车模式**：一致节奏
- **过山车模式**：突然方向变化

## 注意力管理

- 人类注意力跨度：**7-10 分钟**
- 社交游戏核心循环：1-2 分钟
- 任务完成：< 10 分钟
- **被动策略**：每 ~7 分钟展示新元素
- **主动策略**：用计时器检测不活跃（1-2 分钟）

## 注意力管理技术示例

- **Mario 关卡**：每关 3-5 分钟，引入 1-2 个新机制
- **社交游戏**：种植→等 5 分钟→收获循环，每日奖励，生命系统限制 15-20 分钟
- **混合结构**：沙盒探索 + 结构化 10-15 分钟任务
- **警告信号**：加载时离开、教程放弃、重复内容导致脱离

## 对本项目的应用（第一章叙事节奏）

### 体验结构：过山车模式（线性 + 节奏变化）

```
场景        时长      节奏类型     新元素引入
────────────────────────────────────────────
官道开场    1:30      平缓        对话系统、世界观
流贼战斗    1:00      高潮        战斗系统
清风镇      2:00      平缓        NPC、商店、任务
废宅探索    1:30      紧张上升    新敌人、环境叙事
Boss战      1:30      最高潮      Boss机制、策略
章节结算    0:30      回落        奖励、总结
```

### 注意力锚点（每 1-2 分钟）

1. **0:00** — 开场对话（建立角色）
2. **1:30** — 第一次战斗（新机制）
3. **2:30** — 进入新场景（视觉刺激）
4. **3:30** — 商店系统（新交互）
5. **5:00** — 废宅剧情（紧张感）
6. **6:00** — Boss 战斗（高潮）
7. **7:30** — 章节完成（成就感）

### 设计原则

- 第一章总时长控制在 **7-8 分钟**（人类注意力跨度上限）
- 每个场景 **不超过 2 分钟**
- 每次场景切换带来 **至少一个新元素**
- 对话不超过 **3-4 个节点**（避免阅读疲劳）
- 战斗不超过 **5 回合**（避免拖沓）
