# 心流状态设计框架

> 来源：Game Design Skill for Claude Code - 基于《游戏设计的100个原理》

## 用途

应用 Csikszentmihalyi 心流原则设计难度曲线和进阶系统。

## 基本条件

玩家技能水平必须匹配挑战难度：

- 挑战过高 → 挫败 → 退出
- 挑战过低 → 无聊 → 退出
- **理想**：在挫败和无聊之间持续波动

## 三阶段旅程

### 1. 引入（新手）

- 降低难度匹配技能
- 创建教程
- 美学奖励维持动力

### 2. 练习

- 呈现略高于当前技能的任务
- 鼓励技能发展

### 3. 心流

- 精确平衡挫败和无聊
- 监控技能增长调整挑战

## 设计考量

- 美学作为桥梁（初期吸引但不能单独维持）
- 避免低估新手引入关
- 避免过度依赖美学
- 避免静态难度

## 核心循环持续时间参考

| 时长 | 类型 | 示例 |
|------|------|------|
| 1-5 秒 | 微循环 | 射击、跳跃 |
| 5-30 秒 | 动作循环 | 战斗遭遇 |
| 30 秒-5 分钟 | 会话循环 | 关卡完成 |
| 5-30 分钟 | 游戏会话 | 任务完成 |
| 数小时 | 元循环 | 角色进阶 |

## 对本项目的应用（5-8 分钟 MVP）

### 难度曲线设计

```
时间    难度    阶段
0:00    ★☆☆    引入 — 官道对话，无战斗，认识世界
1:30    ★★☆    练习 — 遭遇流贼（简单敌人），学习战斗
3:00    ★★☆    探索 — 清风镇 NPC / 商店 / 任务接取
4:30    ★★★    升级 — 废宅敌人（中等难度）
6:00    ★★★★   高潮 — Boss 赵无忌（需要策略）
7:30    ★★☆    回落 — 章节结算，奖励，铺垫下章
```

### 心流维护策略

- **战斗循环**（5-30 秒）：单次回合制战斗不超过 30 秒
- **任务循环**（5-10 分钟）：整个第一章就是一个完整任务循环
- **奖励节奏**：每 1-2 分钟给一次正反馈（物品/金币/剧情推进）
- **防挫败**：动态难度（见 dynamic-difficulty-adjustment.md）
- **防无聊**：场景切换 + 新机制引入（对话→战斗→探索→商店→Boss）
