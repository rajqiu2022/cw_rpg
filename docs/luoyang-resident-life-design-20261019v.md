# 洛阳持续居民 · 第一批候选设计

状态：候选设计与12份候选对白，未接正式地图；本稿未生成语音，不改旧任务、存档、剧情正典。机器可读稿见 `assets/specs/luoyang_resident_life_20261019v.json`；候选资源索引见 `game/data/luoyang_residents_20261019v/manifest.json`。

## 目标与范围

让同一批当地人从“看着有人”变成能认识、能聊天、能再回访的居民。不是人人都派任务，也不是换一张脸便算新人物。首批四个职业身份已有真实 ID；十二人是后续总规划，不宣称都已做好。

每位居民应具备同人精灵、半身立绘、同源头像和固定声音。闲聊、任务、买卖等话题分开，已有任务入口不能被生活对白覆盖。演员说自己知道的事，不替主角宣布真相。

本稿按照环境叙事参考，把身份落在纸铺防潮、候客长凳、搬货互助与村民进城采买上；按任务设计参考，把日常交谈与接取、调查、回报分开。参考文档中的旧例子服从现行开放世界正典，不能反向覆盖主线。

## 三阶段对白规则

JSON 已给出四人各三阶段、每阶段两句，共24句，带唯一 `line_id`，可用于逐句配音。12份新 `.tres` 使用 `start → reply → end`，显式 `normal` 或 `concerned`，立绘留空以继承互动角色的默认立绘。阶段含义：

1. 日常：提前游历也可听，聊职业和生活，不强推章节。
2. 案情未明：只在对应纸业或漕运支线 ACTIVE 且已有 started 标记时出现。居民讲局部所见，不指认真凶。
3. 本地调查后：必须对应支线 COMPLETED 且已有结果标记成立。只承认该支线结果，不声称主线破案。

优先级为“本地调查后 → 案情未明 → 日常”。不一致旧存档落到日常，不凭一个旧完成旗标开领奖。旗标全只读，文字播放不能改任务状态。

例如老纸匠日常：“买来写家信的，用不着挑最贵的，挑一张落墨匀的就好。”调查中：“你问到什么，带回来慢慢说；我能认的是纸料，不敢认人。”事后：“旧木模我收在干处。往后再有人问起，至少还有实物可看。”

装卸伙计不再只会派差事：“重货两人搭手，轻货也别抢道。水边这点地方，容不得逞能。”事后仍提伤者需要养伤，不把获得奖励写成所有人的生活立即恢复。

## 十二人持续居民规划

首批四人之外，复用八个已经存在的身份：入城乡民、铺中伙计、行脚商、老漕卒、南市书生、牡丹诗会主持、记货伙计、候检旅人。完整 ID 与证据定位在 JSON `roster_plan`。

十二人都应可以主动交谈，不是所有人都要委托。乡民谈田间和采买，妇人谈家用与邻里，诗会主持聊花与诗友，记货伙计谈交接压力。功能重点不同，禁止复制一段“听说最近不太平”给所有人。

后章回访保持人物身份和本地工作；先靠已有支线状态持续变化，再逐项接真实公开城市结果。后续章节阶段、作息轮换、家人关系和新事件目前都是建议，未核实相关 flags 前不得自动启用。不能用“贯穿故事”当理由，让四个普通人提前知道最终幕后者、证人住处或主线密道。

## 精灵、立绘、头像、语音配套

- 老纸匠先做一个完整样板：同一老者的静止四帧、透明半身立绘、同源头像、经确认台词语音，再扩其他职业。不能声称静止四帧等于四向行走。
- 每位用独立 `identity_id` 关联，检查脸形、年龄、发须、职业服、主色和道具，不拿通用年轻村民头像代替年长工匠。
- 声线以年龄和口吻区分，使用自然普通话，不模仿具体真人或把夸张口音冒作考据。
- 音频按 `line_id` 绑定；新句、跳过、关框、切图都取消旧播放。音频失败文字立即可读，不能再拖慢地图加载。
- 本稿没有生成任何图片或音频，也没有授权修改正式绑定。最终资源与接入由对应负责人验收。

## 洛阳生活与历史边界

本作是架空大乾，不能将各朝代和现代洛阳节庆混成一个确凿历史版本。首批防潮、家信、搬货、街坊互助、村民采买都是符合职业的架空日常，不声称洛阳独有习俗。

制作人已检索国家级非遗资料“洛阳牡丹花会”（`https://www.ihchina.cn/project_details/15243/`），后续可考虑家院种花、相约赏花；本子任务未重复联网核验，且首批24句不依赖该史实。现代官方牡丹花会及其制度不得写入古代。饮食、节令、行会、水运制度等待选定时代风格后分别研究；没有资料支持时不写“洛阳自古家家如此”。
