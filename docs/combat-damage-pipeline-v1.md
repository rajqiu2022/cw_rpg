# 战斗伤害链路与乘区合同 v1

> 状态：运行基线；2026-08-24已接入暴击倍率上限与伤害拆解。  
> 日期：2026-08-24  
> 参考：`策划不说，但你应该懂的战斗属性（二）`、`rpg-combat-formula-handbook.md`、`rpg-spreadsheet-balance-workflow.md`。

## 1. 目标

1. 所有玩家、队友与敌人的伤害遵守同一条可追踪链路。
2. 同机制来源进入同一加算区，禁止同名加成互相乘算。
3. 控制装备、心法和绝学同时占用的机制数量，避免单件资源成为所有构筑的最优解。
4. 保留当前“数值形成软门槛”的方向，不增加等级差硬惩罚。

## 2. 项目正式链路

```text
命中判定
  ↓
外功/内功攻击造数
  ↓
固定伤害 + 面板攻击 × 总招式系数
  ↓
95%～105%伤害浮动
  ↓
暴击倍率
  ↓
破甲/穿透后的有效防御
  ↓
虚弱、残血与特殊状态修正
  ↓
最低伤害保护
```

### 2.1 命中

```text
命中率 = clamp(招式基础命中 + 装备命中, 0%, 100%)
```

- 普通攻击基线为85%。
- 命名招式原则上不低于90%。
- 命中是概率属性，不参与伤害乘区。

### 2.2 攻击造数

```text
外功攻击 = (筋骨 + 装备筋骨) × 3 + 通用攻击
内功攻击 = (内劲 + 装备内劲) × 3 + 通用攻击
```

攻击造数输出绝对值，不属于乘区。悟性不进入攻击、暴击、速度和内力公式。

### 2.3 招式基数与系数区

```text
总招式系数 =
    招式基础系数
  + 对应兵器系数
  + 门派系数
  + 已装备心法系数
  + 指定招式协同系数
  + 熟练度系数

招式基数 = 固定伤害 + 攻击造数 × 总招式系数 / 100
```

- 上述所有系数必须同区加算，不允许某一来源再乘一次。
- 固定伤害当前位于防御前，会被防御削减；这是正式规则，不再由单个招式自行决定。
- 后续应为“额外招式系数”增加审计上限，但绝学基础系数不受该上限影响。

### 2.4 暴击区

```text
暴击率 = clamp(5% + 装备暴击 + 心法暴击 + 状态暴击, 0%, 70%)
暴击倍率 = clamp(1.5 + 暴击伤害加成, 1.0, 2.2)
```

- 当前暴击率已有70%硬上限。
- 暴击倍率统一使用2.2倍软上限；请求倍率超过上限时，战斗日志与GM伤害分析会同时显示原倍率和实际倍率。
- 当前没有任何资源绕过软上限。绝学未来若确需突破，必须使用显式例外字段，不能靠多个装备词条暗中叠加。

### 2.5 防御区

当前保持减法公式：

```text
有效防御 = 防御 × 破甲修正 × 招式穿透修正
伤害 = max(1, 暴击后伤害 - 有效防御)
```

暂不切换防御递减公式。先用各章节标准人验证：

- 普通战TKK 2～4回合。
- 精英战TKK 4～7回合。
- Boss战TKK 7～12回合。
- 玩家TTD应高于目标TKK，并给防御、治疗和道具留下策略空间。

### 2.6 状态修正区

状态修正拆成三个固定区：

```text
攻击方修正 = clamp(1 + Σ增伤 - Σ减伤, 0.25, 2.00)
伤势修正   = 由攻击方当前生命比例确定（1.00 / 0.85 / 0.65 / 0.45 / 0.25）
目标易伤   = clamp(1 + Σ易伤, 1.00, 2.00)

状态后伤害 = 防御后伤害 × 攻击方修正 × 伤势修正 × 目标易伤
```

- 同名来源覆盖旧值，不重复叠层；例如两次“影杀”只保留一次。
- 不同来源在同一区内加算；例如影杀+20%与武器增伤+30%合计为攻击方+50%。
- 攻击方修正、伤势修正与目标易伤属于不同机制，三区之间相乘。
- 虚弱包含两个明确效果：作为攻击方时提供30%减伤；作为目标时将有效防御减半。后者属于防御区，不属于易伤区。
- 残血衰减来自角色伤势，不与虚弱放在同一加算区，避免低血量时弱化曲线突然改变。
- `DamageModifierStack`统一保存来源、数值和区间上限；GM直接显示同一对象，禁止UI复算。
- 中毒、流血是独立持续伤害，不暴击，也不进入普通攻击增伤/易伤区；凌月毒伤强化仅影响中毒结算。
- 防御姿态、回澜和反射属于受击处理，不进入攻击方增伤或目标易伤。
- 内伤属于积累机制，不直接成为额外伤害乘区。

## 3. 不引入的系统

### 3.1 等级差伤害惩罚

本项目不增加“低级打高级自动减伤”。敌人强度通过属性、招式、AI、状态与资源消耗形成软门槛，玩家可以自行练级和准备。

### 3.2 元素抗性区

当前没有五行或元素克制构筑。内外功差异由筋骨/内劲造数、内伤机制、招式特征和Boss设计承担。

### 3.3 大量最终伤害区

最终伤害只预留给少数剧情绝学和Boss特殊阶段。普通装备、普通心法不得新增独立最终乘区。

## 4. 词条供给边界

| 来源 | 主要职责 | 次要职责 | 不应同时覆盖 |
|---|---|---|---|
| 武器 | 攻击造数、对应兵器系数 | 暴击/命中/一种特殊效果 | 造数、系数、暴率、暴伤、命中、控制全部拉满 |
| 护腕/拳套 | 流派系数、筋骨或内劲 | 命中、状态 | 同时承担顶级武器造数 |
| 护甲/头盔 | 防御、生命 | 抗状态或护体 | 高额攻击与暴击 |
| 鞋子 | 速度、机敏 | 命中或闪避语义 | 高额招式系数 |
| 饰品 | 暴击、命中、特殊机制 | 稀有悟性 | 高额基础攻击与防御同时出现 |
| 心法 | 一个流派方向、一个特殊协同 | 常驻属性或主动运功 | 全武器、全伤害、暴击、内伤、治疗同时强化 |

## 5. 首轮审计结果

完整数据见 `combat-balance-zone-audit-20260824.xlsx`。

### 5.1 高风险装备

#### 烬河断岳刀

同时覆盖攻击造数、兵器系数、暴击率、命中率和破甲。主题应锁定“重外功 + 破甲”，建议后续优先取消命中加成，避免重刀同时成为精准武器。

#### 越纹州句剑

同时拥有高攻击、速度/机敏、林西门派系数、兵器系数、暴击率、暴击伤害和流血。建议保留“林西专属 + 鸟篆流血”，在门派系数、兵器系数和暴伤中至少收回一项。

### 5.2 高风险心法

#### 紫霞神功

主动暴击、装备暴击、剑系系数和指定招式暴击重复供给。建议保留主动爆发身份，降低或移除常驻装备暴击，避免催动时过早撞到70%暴击上限。

#### 玄武心经

常驻生存、内功剑系系数、暴击、内伤和三招协同同时存在。建议锁定“守御 + 内伤”，移除装备及协同暴击，保留伤害系数与内伤积累。

#### 玄霜归藏诀

作为终章蜕变心法允许高复杂度，但“全系内功 + 系数 + 暴击 + 内伤 + 两门绝学协同”会与橙武叠加。应先实现总系数、暴击率和内伤积累上限，再决定是否削弱数据。

### 5.3 需复核绝学

#### 擎天镇岳棍

全体伤害、95%命中、12%破防、100%虚弱三回合集中在一次释放中。建议保留群控绝学身份，但Boss对虚弱应有持续时间缩短或控制抗性，避免三回合全体压制成为固定最优解。
