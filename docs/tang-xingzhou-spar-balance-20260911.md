# 唐行舟切磋平衡复测（2026-09-11）

## 调整理由

唐行舟的切磋敌人仍沿用早期低数值模板：104 气血、16 攻击、18 内力。主角获得林西铁剑并使用现行固定伤害招式后，通常两次命中即可结束；唐行舟又只能支付一次“行舟扫叶”，多数命中只有约 5 点伤害，无法体现可选强敌或成长检验的作用。

## 期望体验

- 初到林西、尚未熟练招式时可以挑战，但胜负不稳，失败不阻断主线。
- 完成授艺并正确使用招式后应明显占优，通常约 5～6 回合取胜。
- 只用普攻仍可在成长后获胜，但耗时和风险显著高于使用招式，让武功学习与内力管理有实际价值。
- 只调整切磋用 `EnemyDef`；入队后的唐行舟、共享棍法、全局公式、切磋奖励和战后恢复规则保持不变。
