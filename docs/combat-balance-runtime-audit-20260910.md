## 已确认问题摘要

1. 林西一式 `mp_cost=0`，二式 `mp_cost=5`，扣内力代码正常；不能误诊成 UI 不刷新。

## 真实公式与消耗路径

- 主角外功有效攻击 = `3 × (筋骨 + 装备筋骨) + 装备通用攻击`，内功改为内劲；`battle_formula.gd:26`、`battle_controller.gd:1807`。角色面板旧 attack=`2×筋骨+内劲`，属性不相等时不能直接拿面板 attack 当所有招式攻击。
- 主角基础防御 = `2×guard + strength`（`character_stats.gd:129`），战斗再加装备防御（`battle_controller.gd:1815`）。
- 攻势 = 固定伤害 + 四舍五入(有效攻击 × 总系数)。浮动 0.95–1.05、暴击先结算，之后直接减防御，保底 1（`battle_formula.gd:61`、`:81`）。
- 残血输出全局衰减，双方都适用：HP<70% ×0.85、<50% ×0.65、<30% ×0.45、<10% ×0.25（`battle_formula.gd:110`）。不是受到重伤状态才触发；例如高阶弟子在装备主角面前满血重斩 9、残血<10%变成 2，普通攻击始终 1。
- 基础普攻命中85%，一般招式90%；基础暴击5%、普通暴伤1.5倍。林西铁剑加6个百分点暴击，穿戴后11%。
- 玩家编队消耗：`battle_controller.gd:1179`；旧单体路径：`:2021`；可用性检查：`:2749`。敌人编队在`:1380`扣MP，`:1897`筛选MP足够的技能；普通敌人按 aggression 选择非普攻，不是等权。
- 切磋结算会恢复入场HP/MP快照（`scene_router.gd:329`），所以“战后蓝条没少”与“战斗中零消耗”要区分。

## 林西酒永久加成丢失：真实复现

```text
新局 -> Inventory.add_item(linxi_jiu) -> use_item
WINE BEFORE LEARN 284/134
-> GameState.learn_skill(linxi_inner_breath)
WINE AFTER LEARN 200/102

独立新局 -> 同样喝酒 -> player.gain_exp(80)
WINE AFTER LEVELUP 203/98
```

按“永久+100/+50”的用户可见承诺，学习吐纳后应保留至300/152，升至Lv2应保留303/148。实际结果恰好少100/50。
来源：`inventory.gd:193`直接改 `player.max_hp/max_mp`；`character_stats.gd:83`无额外永久字段地重算；学习走 `game_state.gd:316`，升级走`character_stats.gd:108`。
这是确定性错误，应与“+100/+50是否过强”的设计判断分开处理。

## 其他成长/挑战断点

- 一式学校不匹配：`linxi_basic_sword_one.tres:23`为generic；铁剑`linxi_iron_sword.tres:35`为linxi；`inventory.gd:556`排除generic。实测一式gear `{school_scaling:0, weapon_scaling:6}`，二式 `{12,6}`。

- 入门主动零消耗列表（排除普攻、被动和敌人专用）：`gufeng_kaishan_yidao`、`huashan_yijian`、`lingyue_lingbo_yizhi`、`linxi_basic_sword_one`、`mingwu_saofeng`、`wudang_taiji_chushi`。不是所有0MP都应改：普攻应有兜底、被动不需消耗，敌人0MP技能也可能是作者明确设计。
- 铁剑+初始衣鞋+一重吐纳，真实Lv1→4为 HP200/219/238/257，MP102/116/130/144，攻40/43/46/49，防25/28/31/34。防御每级+3使早期普通敌人更快落入1伤地板；到了推荐Lv3时教学散兵普攻也只有1。
- 全资源扫描在防23下普攻中心值≤1：bandit_mountain、boss_luoyang_captain、companion_tang_xingzhou_spar、gufeng_bandit、linxi_dojo_disciple、linxi_dojo_senior。后两章旧资源也需按实际接入状态复核，不能仅凭资源存在就认定现行主线必遇。
- 第一章不全是1v1：凶兽固定双目标、头狼和Boss有按人数增援、废宅双守卫、护商双山贼。`chapter_1_content_plan.tres:21`–`:25`；`enemy_def.gd:68`还按额外队友缩放HP和攻击。上面的单敌矩阵不是完整章节胜率验证。

## 结论边界

本轮没有改耗蓝、敌人攻击、防御公式、装备或心法。确定修复项是酒的永久奖励持久化、流派加成断链与二式兵器限定一致性；其余需先设定教学/普通/精英/Boss的目标承伤比例、击杀动作数和资源预算，再用真实编队与有限MP复测，不以无限技能木桩模拟器结果代替实机节奏。
