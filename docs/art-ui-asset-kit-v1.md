# 《云影侠传》UI 美术资产 Kit v1

> 目标：把当前 HTML / Godot 程序样式推进为真正可用的美术 UI 资产包。  
> 风格基准：`docs/ui-style-v1.md` v2「寒山玄铁 · 雾蓝侠影风」。  
> 用户已确认参考图：`assets/raw/ui/cold_wuxia/v1/ui_cold_wuxia_common_kit_v1.png`，后续 UI 美术按这张延展。  

> 关键约束：**画面内不要英文，不要拉丁字母，不要西幻/妖魔元素，不要橙黄暖金。**

## 1. 总体方向

不是继续用纯 HTML / StyleBox 拼 UI，而是让 art agent 产出一套可切分、可 9-slice、可在 Godot 复用的 UI 美术素材：

- 玄铁匾额
- 冷钢蓝边框
- 雾蓝云纹暗刻
- 灰白冷宣纸详情卡
- 寒玉点缀
- 暗血红危险态
- 山雨、雾、竹影、寒光等中国武侠元素

所有文字优先由 Godot 运行时渲染，避免 AI 把字画错。UI 图片内原则上**不直接写字**。

## 2. 禁止项

- 禁止英文、拉丁字母、英文缩写、英文 UI 词。
- 禁止乱码、伪中文、繁体字。
- 禁止骷髅、恶魔、怪物、蜘蛛网、西幻符文、魔法阵、哥特纹章。
- 禁止橙黄色、暖金、大红绸、喜庆风。
- 禁止现代科幻 HUD、霓虹赛博、玻璃拟态。

## 3. 第一批 UI 美术资产

### 3.1 通用 UI 框架 Atlas

用途：主菜单、背包、装备、任务、商店、战斗 HUD 通用。

建议一张 1536×1024 atlas，包含：

1. 主标题玄铁匾额（无字）
2. 横梁 / 底梁（冷钢边）
3. 大面板框（9-slice 友好）
4. 小面板框（9-slice 友好）
5. 玄铁按钮 normal（无字）
6. 玄铁按钮 hover（无字）
7. 玄铁按钮 pressed（无字）
8. Tab 选中 / 未选中（无字）
9. 对话框长条（无字，留白足够）
10. 冷灰宣纸详情卡
11. 装备槽空框
12. 装备槽选中框
13. Buff 图标外框
14. 血条 / 内力条外框
15. 角花 / 云纹 / 竹影分隔线

要求：

- 背景纯白或透明，便于后处理抠图。
- 每个组件之间留足切分间距。
- 组件不要重叠，不要带文字。
- 色调以深墨蓝、玄铁、冷钢蓝、霜蓝为主。

### 3.2 属性图标 Atlas

游戏主要属性：

| 属性 | 美术意象 | 备注 |
|---|---|---|
| 筋骨 | 玄铁护腕、山石纹、筋脉线 | 不要骷髅，不要裸骨恐怖感 |
| 机敏 | 疾风步、燕影、短靴残影 | 表现速度和反应 |
| 内劲 | 丹田气旋、掌心寒蓝气劲 | 表现内家真气 |
| 悟性 | 竹简、棋子、寒光一笔 | 表现领悟与心法 |
| 生命 | 青玉葫芦、心脉光、药草露珠 | 不要现代红十字 |
| 内力 | 湖面波纹、丹田寒光、气海 | 与“内劲”区分：更偏资源槽 |
| 防御 | 玄铁盾、护心镜、岩纹屏障 | 不要西式盾徽 |

建议一张 1536×1024 atlas，7 个主图标 + 2 个备用空框。

要求：

- 图标内不写文字，属性名由 Godot 显示。
- 禁止英文和字母。
- 图标在 64×64 仍能读清。
- 外框统一为玄铁方框 + 冷钢边。

### 3.3 状态条 / Buff / 战斗 HUD

建议包含：

- 生命条外框 + 暗血红填充参考
- 内力条外框 + 寒蓝填充参考
- 经验条外框 + 雾白/冷钢蓝填充参考
- Buff 图标外框：增益（寒玉）、减益（暗血）、中性（冷钢）
- 战斗命令按钮底图：攻击、武学、防御、撤退均不直接写字
- 战斗日志框：长条冷色宣纸 / 玄铁边框

## 4. Godot 接入原则

- UI 文本全部在 Godot 渲染：`云影侠传`、`筋骨`、`机敏`、`内劲`、`悟性`、`生命`、`内力`、`防御` 等不要烘进图片。
- 需要 9-slice 的框体，四角和四边必须清晰、对称、可拉伸。
- 输出进入 `assets/raw/ui/cold_wuxia/`；人工切分后再放 `game/art/ui/cold_wuxia/`。
- 后处理要求：透明背景、无白边、无水印。
