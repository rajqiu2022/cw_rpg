# 《云影侠传》UI 风格稿 v2

> 目标：先定统一 UI 视觉语言，再细化主菜单、装备、背包、战斗等具体界面。
> 参考：`images/游戏主界面UI.png`、`images/装备界面UI.png` 只作构图与组件层级参考，不直接使用为游戏背景。  
> 用户已确认正式 UI 美术基准：`assets/raw/ui/cold_wuxia/v1/ui_cold_wuxia_common_kit_v1.png`。

## 1. 风格名称

**寒山玄铁 · 雾蓝侠影风**

关键词：

- 中国武侠
- 山雨云雾
- 玄铁匾额
- 雾蓝银边
- 冷灰宣纸详情卡
- 寒玉点缀
- 港漫厚涂质感

明确禁止：

- 外国神话元素
- 恶魔 / 骷髅 / 妖怪 / 魔法符文
- 西幻盔甲纹章
- 科幻霓虹
- 日式妖怪 / 阴阳符咒
- 蜘蛛 / 蛛网意象
- 大面积橙黄 / 暖金 / 红绸喜庆色

## 2. 视觉基调

整体不是“仙侠发光 UI”，也不是“西幻暗黑 UI”。本版定位为一整套正式游戏 UI Kit，而不仅是主界面。

应该像一套被山雨浸湿的旧江湖界面系统：

- 背景：寒山、夜雨、云雾、远山楼阁、竹林、旧镇。
- 主 UI：玄铁、深墨蓝、冷钢银边、云纹暗刻、少量寒玉点缀。
- 内容卡：灰白冷宣纸，不用黄旧纸，不做羊皮纸。
- 高亮信息：霜蓝、寒玉、冷白；暗红只用于伤害/危险。
- 文本：冷白 / 雾灰，避免暖米黄。

## 4. 字体 / 字形方向

Godot 默认字体可先用，但视觉上按以下方向设计：

- 大标题：手写榜书 / 牌匾字，粗、压迫、有刀锋感。
- 一级标题：宋体 / 楷体感，金色描边。
- 正文：清晰的宋体或黑体，不要花。
- 数值：可用窄体或等宽感，方便对齐。

后续如果引入字体，优先找：

- 站酷快乐体 / 站酷庆科黄油体一类标题字（需确认授权）
- 思源宋体 / 思源黑体作为正文

## 5. 通用组件

### 5.1 主按钮：玄铁按钮

结构：

```text
冷钢蓝边框
玄铁蓝黑渐变底
左右云纹暗刻 / 寒雾小装饰
文字居中，冷白或霜蓝
hover 时边框变亮、底色偏冷蓝
```

用途：

- 新游戏
- 载入进度
- 游戏设置
- 退出
- 战斗命令按钮

### 5.2 标题匾

结构：

```text
玄铁横匾
冷钢 / 霜蓝边框
云纹端头暗刻
大字居中，冷白描边
下方可有中文副标题，避免暖色发光
```

主标题：**云影侠传**

### 5.3 宣纸详情卡

用途：

- 装备详情
- 物品说明
- 任务描述
- 战斗日志扩展

结构：

```text
灰白冷宣纸底
深墨蓝正文
边角冷钢纹
右下淡水印 / 云纹
```

### 5.4 装备槽

结构：

```text
方形深色格
冷钢边 / 寒玉边
空槽显示淡墨图案
已装备显示图标或名称
选中时外圈霜蓝亮起
```

### 5.5 状态条

- HP：暗血红，仅保留危险感
- MP / 内力：寒蓝 / 玉青
- 经验：雾白 / 冷钢蓝，不用黄色

不要用现代扁平进度条，要像嵌在玄铁框中的细条。

## 6. 主菜单布局

参考 `images/游戏主界面UI.png`，但改成原创《云影侠传》。

布局：

```text
顶部：大标题匾「云影侠传」
中左：木牌菜单组
中右：主角角色卡 / 立绘框
两侧：竖向角色标签或装饰牌
底部：宣纸横条，显示一句江湖题词 + 版本号
背景：山雨 / 竹林 / 远楼阁，不是 UI 参考图本身
```

主菜单按钮建议：

- 新游戏
- 载入进度
- 游戏设置（后续）
- 游戏资讯（后续）
- 退出

## 7. 装备页布局

参考 `images/装备界面UI.png`。

布局：

```text
顶部：标题栏 + 队伍头像小卡
左侧：角色大立绘
中间：装备槽 3x3 或 3x4，当前先用 6 槽
右侧：宣纸装备详情
底部：attributes 属性区
右边缘：分类竖 tab（技玉 / 抗能 / 技术等可改成 武器 / 防具 / 饰物）
```

当前 MVP 只需要：

- 武器
- 头部
- 护甲
- 手部
- 鞋子
- 饰品

## 8. 背包页布局

建议：

```text
左侧：分类 tab
中间：物品列表 / 格子
右侧：物品详情卡
底部：金钱、负重/容量、角色状态
```

分类：

- 全部
- 药品
- 装备
- 剧情

## 9. 战斗页布局

建议：

```text
背景：战斗场景图
左下：玩家状态牌
右上：敌人状态牌
底部右：木牌命令按钮
中下：战斗日志卷轴
中央：角色立绘 / 战斗 sprite
```

暂不做：技能粒子、复杂动效、全屏必杀。

## 10. 可视化预览

已提供本地预览页：

- `tools/ui_style_preview.html`

该页仅用于看 UI 风格方向，不是运行时 Godot 界面。当前预览已包含：主菜单、玄铁按钮、tab、对话框、buff/debuff 图标、HP/MP/EXP 条、装备槽、冷宣纸详情卡和色板。Godot 各界面会按同一风格迁移。

## 11. 美术资产化

HTML 预览只用于定方向，最终需要 art agent 生成正式 UI 美术资产。详见：

- `docs/art-ui-asset-kit-v1.md`
- `prompts/templates/ui_cold_wuxia_kit.yaml`
- `prompts/templates/ui_cold_wuxia_icon_atlas.yaml`

资产原则：

- UI 图片内不要英文、不要拉丁字母。
- 优先无字组件，中文由 Godot 运行时渲染。
- 主要属性名：筋骨、机敏、内劲、悟性、生命、内力、防御。
- 属性图标不写字，但要能通过意象区分。

## 12. 第一轮落地优先级


1. 主菜单完整重做，先把“游戏门面”定下来。
2. 装备页按三栏布局重做。
3. 背包页跟装备页共用冷宣纸详情卡和玄铁列表。
4. 战斗页只做正式 HUD，不做技能特效。
5. 生成模块化场景 kit，而不是整张 loading 背景。
