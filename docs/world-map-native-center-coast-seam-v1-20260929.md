# 中原中心—东岸接缝候选审查 · 2026-09-29

结论：**视觉不通过，未接入正式 v12，也未覆盖 v13 staging。** 这一轮只新增中心区无建筑底座候选与可复现的接缝 QA；没有把两块图注册为正式可玩大地图。

## 输入与尝试

- 中心区底座候选：`game/art/backgrounds/world_map_v13_proto/bg_world_map_native_center_cleanplate_gen_v1_candidate.png`，1536×1024。以内置生图**编辑模式**参照东岸候选的投影、光照、草地材质；要求右缘道路在高约 28% 处接入东岸左缘。第一轮道路落点偏低，第二轮局部编辑后的右缘仍偏高且纹理颜色不同。两次结果均不是正式资产。
- 原样并排：`game/build/world_map_v13_native_center_coast_pair_raw_v1.png`，中心与东岸道路在边界断开，左右草纹明暗、笔触密度不同，整条竖向拼缝可见。
- 用 `game/scripts/dev/compose_world_map_native_center_coast_pair_v1.gd` 做 48px 道路末端纵向校准＋80px 羽化，以及 160px 实际重叠＋道路弯曲；各自产出本地 build 对照。前者出现明显竖向拖影，后者形成斜向纹理拉伸与道路急折；**均否决，不可用于运行图**。
- 裁出 1024×1024 的边界区，再用内置生图编辑要求只修中段、锁两侧并连通土路。返回图实际为 1254×1254，草叶笔触与原图不同；不能无损嵌回原画布。此图未拷进游戏资源目录。

## 验收结果

- Godot 4.6.2 严格资源导入 exit 0；这只证明候选图片/脚本可解析，不证明画面可用。
- **画面 FAIL**：中心—东岸两块的地表细节与道路出口无法通过并排、局部羽化或本轮接缝重绘达到固定 1536 像素分块的无缝标准。禁止把原图、羽化图或重叠图切入 `world_map_jianghu` 或 `world_map_jianghu_v13_staging`。
- 用户允许“没问题就合入”，而当前尚有明确问题，故正式地图保持 v12，九宫 staging 保持原状；现有海岸独立候选仍可用于机制验证，但不是视觉批准。

## 下轮制作要求
