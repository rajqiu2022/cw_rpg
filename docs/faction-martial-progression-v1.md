# 五派与无门派武学成长重设计 v1

更新时间：2026-09-09  
运行口径：`game/scripts/autoload/game_state.gd`、第三章道路选择、各章任务奖励

## 1. 总体原则

1. 五派各有清晰主修生态，但不强制“一派一兵器”：武当正式保留剑法、拳掌双线，华山以多分支剑法为核心。
2. 加入门派只授一门根基，不再一次发四门武学；完整套路必须经过考校、门派调查和中后期传承。
3. 无门派是可从第三章一路通关的正式第六道路，不是困难模式或内容删减模式。
4. 江湖武功、跨门派奇遇和开放世界橙色绝学不检查门派；只有明确写作“某派镇派传承”的奖励才检查门派。
5. 旧存档保留已学武学。武当旧支路旗标只作历史兼容，不再锁奖励；完成第三章的旧档自动补齐剑、掌入门传承。

## 2. 五派战斗身份

| 道路 | 主系 | 战斗关键词 | 第三章根基 | 考校后进阶 | 中后期传承 |
|---|---|---|---|---|---|
| 武当 | 剑法 + 拳掌 | 单体化劲、内伤、守中反击 | 玄武桩 | 绕指柔剑 / 武当绵掌 / 太极拳·揽雀尾 | 柔云剑法、武当八卦掌、玄武心经；终极太极剑法与两仪归一 |
| 华山 | 多分支剑法 | 单体快攻、暴击、破防、群体剑阵 | 华山一剑 | 破云、群峰落照、紫霞凝罡 | 岚回三叠奇遇、剑断千山、紫霞神功 |
| 古峰 | 刀法 | 重击、破阵、护体 | 开山一刀 | 开山十八刀·伏虎、金刚力 | 裂地、金刚不坏 |
| 凌月 | 棍法 | 点扫、位移、群体压制 | 凌月点星棍 | 回月扫尘棍、踏月凌波 | 寒潭映月棍、月华引 |
| 茗雾 | 暗器 | 身法、连击、收割 | 茗雾扫风 | 雾隐三式、茗雾步 | 隐影夺命、隐影诀 |

武当剑、掌两路不是二选一。剑路为“绕指柔剑 → 柔云剑法 → 太极剑法”，拳掌路以“武当绵掌 / 揽雀尾 → 武当八卦掌 → 两仪归一”递进；两路都以单体伤害为主，共用玄武桩和玄武心经。玩家可以全部学习，但每门武学的每一重都独立消耗历练，因此双修的成长成本自然高于专精。

华山不是只有一条纵向升级线：破云与岚回三叠服务单体破势，群峰落照服务群体清场，剑断千山承担终局单体爆发。隐藏前辈游天鸿的山涧奇遇不检查玩家门派，因此无门派也能靠探索得到华山旁支剑招。

## 3. 无门派成长线

第三章选择“不入门派：江湖自修”后，玩家完成“五证互校”和散修考校，获得江湖客牌，并选定一个早期研习方向：

- 剑：继续磨炼林西剑法二式；
- 刀：重斩；
- 棍：考校棍·横扫；
- 掌：回风绵掌；
- 暗器：竹雨穿林。

这只是早期引导方向，不锁后续武器。无门派玩家可以混学剑、刀、棍、掌、暗器五系，也可以通过公开任务或隐藏高人学到部分有门派源流但不要求入派的招式。代价不是系统封锁，而是必须收集对应兵器、分别投入历练，并为更多套路安排心法与装备。

当前已接入的江湖学习入口包括：林西武馆教头的棍法考校、竹尾擂台的拳掌、竹尾救援线的暗器、武林大会剑坛残谱、雪岭主线刀法，以及第五章游天鸿山涧奇遇的剑法。后续新增城市和村镇时，每个聚落至少配置一名公开武教头；每个大型野外区域至少保留一条不在地图上明示的高人或残卷线。

## 4. 江湖橙色武学与心法

| 传承 | 类型 | 路线约束 | 获取规则 |
|---|---|---|---|
| 移花换劲 | 橙色主动心法 | 无门派可得，五派也可得 | 开放世界五条原理线索 + 双车险局；不限章节 |
| 盘龙十七式 | 橙色掌法 | 不限门派 | 行义帮跨章义约长链 |
| 易筋经 | 橙色被动心法 | 不限门派 | 少林俗家结缘与禅关长链 |
| 孤云九式 | 橙色剑法 | 林西师承主线，不等于正式门派 | 第八章回村、地下档案室与师徒推演突破 |

运行门禁：开放世界绝学和隐藏高人任务不得增加 `joined_*` 条件；任务发奖使用 `reward_skills`。明确属于镇派终极传承的奖励才使用 `reward_skills_by_faction`。武当剑、掌兼修不得再使用 `reward_skills_by_flag` 做互斥门槛。

## 5. 核心玩法循环

游戏的第一核心循环固定为：探索大世界 → 发现教头、奇遇、谜题或残卷 → 完成任务与战斗验证 → 收集武功招式 → 寻找匹配兵器与心法 → 投入历练形成新套路 → 用新能力进入更危险区域。主线负责把玩家带到新地域，不应吞掉这一探索和收集循环。

门派路线提供稳定传承、较低试错成本和明确的中后期回报；无门派路线提供更宽的五系组合空间，但承担更多跑图、解谜、兵器收集与历练投入。两者强度上限一致，获取方式和成长节奏不同。

## 6. 第三章流程合同

`ch3_faction_choice` 必须提供六个选项：五派 + 无门派。六条路线都必须：

1. 产生唯一 `player_faction` 值；
2. 完成各自调查/考校；
3. 设置 `joined_faction`，使共享主线继续；
4. 回到 `ch3_s1_wulin_assembly`；
5. 不允许再次改选另一条道路。
