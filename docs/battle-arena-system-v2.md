# 战斗场景与五点阵规则 v2

更新：2026-09-02

## 目标

- 战斗环境跟随剧情地点，不再长期复用同一张竹林图。
- 人物脚底必须落在可战斗地面，不进入竹林、屋顶、远山或天空。
- 无标记战场看起来松散自然，但底层仍使用可验证的五个固定逻辑坐标。
- 主角偏瘦轮廓按有效像素面积补偿到不小于普通敌人，Boss仍可通过自己的倍率继续放大。

## 固定占位与无标记占位

### 固定占位

底图明确画有平台或战位结构时使用固定模式。人数变化仍从五点模板中按平衡索引取点，不随机偏移，确保脚底与美术标记对应。

### 无标记占位

本批七张正式底图均不绘制站位圈。运行时每侧仍只有五个固定脚底坐标：

```text
我方： (0.145,0.645) (0.245,0.705) (0.105,0.755) (0.335,0.795) (0.215,0.845)
敌方： (0.690,0.475) (0.795,0.525) (0.635,0.575) (0.860,0.620) (0.735,0.675)
```

- 坐标为1920×1080画布的归一化脚底锚点，不是人物中心。
- 1～4人战从三套安全子集中轮换；5人战显示全部五点。
- 坐标不做连续随机，避免进入UI、遮挡或踩出地面；变化只发生在已验收点之间。
- 人物Z顺序按脚底Y计算，靠下者覆盖靠上者，形成自然前后层次。

村落广场使用独立红框校准坐标，不复用通用洞窟/郊外阵型：

```text
村落我方： (0.220,0.710) (0.330,0.760) (0.190,0.820) (0.420,0.860) (0.290,0.910)
村落敌方： (0.600,0.430) (0.710,0.470) (0.560,0.520) (0.790,0.550) (0.670,0.580)
```

1920×1080下，我方脚底限制在用户标注的左下开阔地，敌方脚底限制在右上土台；人物头部可向各自区域上方延伸，但脚底不得越出地面框。

## 比例合同

- 单人基准：`formation_base_scale = 0.46`。
- 主角四武器战斗帧约23662个有效Alpha像素，普通山贼约37350～37497；运行时使用`1.28`等比缩放，按视觉面积而不是只按身高补偿偏瘦轮廓。
- 普通敌人：基准×`max(0.96, authored_scale)`。
- Boss或大型敌人继续使用资源自身大于1.0的倍率。
- 三人以上会整体等比收缩；主角、队友和普通敌人的有效人物高度保持接近。
