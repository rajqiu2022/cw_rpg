# 江湖大地图 v7：同源道路、像素导航与渡口航线

## 核心合同

- 运行底图：`game/art/backgrounds/bg_world_map_jianghu_v7_gameplay_hd.png`，真实 3072×2048。
- 运行布局：`game/data/maps/world_map_jianghu_layout_v7.tres`。
- 权威行走蒙版：`game/art/navigation_masks/world_map_jianghu_walk_v7.png`。
- 生成器：`scripts/build_world_map_v7_runtime.py`。
- 审查叠图：`assets/processed/scene/world_map_v7/world_map_v7_navigation_overlay.png`。
- 道路外观与行走蒙版来自同一组 19 条路线；禁止再从底图颜色猜路、低分辨率寻路补线或压成数百个栅格矩形。

## 视觉方向

- 港漫/经典武侠 RPG 的 2.5D 厚涂环境，深竹绿、冷蓝水、灰黑山岩和暖赭道路。
- 不使用泛黄宣纸、水墨舆图、低饱和褐灰、古地图边框或烤字。
- 城镇、村落、山门、渡口、海港和边关保持可区分轮廓；地名仍由 Godot 门户标签显示。
- 2026-09-03返修以林西村正式场景为风格参照，减弱旧版块面/描线感；洛阳是封闭城墙节点，陆路只接外部门洞或沿城墙绕行，不得画成一条穿城直路。

## 陆路规则

1. 玩家只在 `walkable_mask_path` 的白色核心区步行。
2. 可见道路比导航核心更宽，角色脚底始终留在道路中部；草地、山体、河面和海面不能直接穿越。
3. 道路跨水处必须有可见石桥、木桥或堤道；没有桥的水面保持黑区。
4. 十二个门户与主路网使用固定坐标，所有门户中心必须属于同一陆路连通分量。
5. 西南田野的短横桥支路使用`southwest_bridge_spur`，覆盖归一化x=0.283～0.374、y≈0.72；这是可见道路，必须同时进入像素蒙版和兜底多边形。

## 渡口与海域

- `白鹿渡` 和 `东海埠` 标记为 `travel_mode = ferry`，是水路换乘点，不是海面行走入口。
- 玩家步行抵达渡口后与船夫或码头交互，选择已解锁航线，再通过场景切换前往海域地点。
- 规划航点包括海崖古港、东海离岛和沿海水寨；它们不得用白色步行蒙版与大陆相连。
- 航线可要求船资、剧情旗标、天气条件或护航任务。返程必须回到同一渡口，遵守 A↔B 双向入口合同。
- 海图上可以表现船只、码头和淡淡航迹，但航迹仅作叙事视觉，不进入陆路导航蒙版。

## 性能合同

- 世界布局必须配置 `walkable_mask_path`；运行时采用 O(1) 像素采样，`walkable_regions` 只作低数量兜底与编辑器审计。
- 滚动地图使用真实 `Camera2D` 跟随玩家，世界、碰撞、出口和角色节点保持固定；禁止在 `_process()` 中平移整个 `WorldContainer`。
- 方向贴图只在武器、状态或方向改变时加载/切换；移动信号在 `move_and_slide()` 之后发送。
- 世界底图按原生尺寸显示，背景使用线性过滤；角色与像素图仍保持 nearest。

## 验收

- 蒙版和背景均为 3072×2048。
- 十二门户中心及 ±24px 探针可走；五个阻挡探针不可走。
- 全部陆路门户属于同一连通块；白鹿渡、东海埠之外的水域采样必须为黑。
- `navigation ⊆ visible road core`，不得出现穿林、穿城、横渡海面或截图红箭头式捷径。
- 1920×1080 连续横、纵、斜走各 10 秒，无 0/大跳交替；帧耗时 P95 不超过 16.7ms，单帧不超过 33ms。
