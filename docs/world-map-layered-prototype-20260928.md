# 大地图分层试样与 2026-09-28 定点修复

## 本轮运行版修复

- `world_map_v12` 的导航生成顺序改为“道路与开放区合并 → 城池/水域禁走区最终扣除”。此前禁走区扣完后又把道路整层涂回，导致人物走进洛阳城内和东海埠海面。封闭区现参与同源哈希，避免只改导航却不更新运行图与验证报告。
- 洛阳与东海埠入口移到陆侧、城外，三座新增城池也保留各自门外入口。重新生成 2304 运行图、4608 桌面图、导航蒙版以及移动/桌面各 15 张流式切片。`navigation_validation.json` 记录 20 条路线、2 块开放区、16 个连通入口、4394 个中心线脚底样本；这只证明拓扑合同，不代表全图每一块像素都已完成美术与地形审查。
- 金陵桥市两座烘焙灯柱分别登记“小面积脚底阻挡 + 独立 Y 深度前景”，人物不能站在柱座上，从后侧走过时灯柱画面压住人物。小物件可用自己的 `walkability_margin`，不必借用建筑的大安全边距。
- 茗雾山庄未开放门户改为世界内提示，不再显示“未解锁”。两个旧世界地图回程坐标顺手修正到对应入口，避免回程落到城内/海上。

## 分层地图试样（尚未切入游戏）

`assets/raw/scene_background/world_map_layered_proto_20260928/central_plain_clean_plate_v1.png` 是通过内置生图生成的 1536×1024 中原地形底座候选：只有草地、岩石、远山与东缘海岸；没有城池、屋顶、道路、文字、箭头或人物。它验证“先做干净地形，后放交互建筑”的视觉方向，但还不是扩大后的完整世界地图，也没有替换运行中的 v12。

下一版完整地图应按下列同源层制作，并逐块验收后才切换运行版：

1. **地形底座**：多块等比例 2.5D 地形，原生高分辨率；城池、桥、摊位不要烘焙进底座。
2. **可行走与地形类别**：陆地、道路、桥面为正向蒙版；水面、悬崖、城墙和建筑占地为最终负向蒙版。相机、分块和导航共用世界坐标，禁止因大图缩放重采样造成错位。
3. **独立建筑/物件**：城池、桥、门楼、树、灯柱均有可视资源、脚底阻挡、交互区域和前景遮挡；同一对象的数据成对登记，不再只靠截图估一个大矩形。
4. **验收层**：导出导航叠图；每块地图检查“海岸、桥头、城门、屋顶、出生点、返回点”正负样本，运行时验证足底半径和入口连通；穿物件截图逐个回填对象遮挡数据。

当前 v12 仍是单张烘焙式世界图，中央水道及复杂岩岸没有全量逐像素标注。本轮修复覆盖报告里的东海埠海面、洛阳与其他城池的代表点，不能称为所有水边、城墙的彻底根治。后续若要达成用户要求的更大、更精细和系统性层级正确，需完成上述分层资产与全图可行走审查后再切换。
