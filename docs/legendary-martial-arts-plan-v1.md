# 原创绝学长链规划 v1

> 日期：2026-08-17  
> 目标：吸收经典武侠的玩法母题，但不复用原作武学名、人物、门派秘史、口诀、对白或标志性桥段。

## 1. 投放原则

- 绝学不是宝箱里的一张纸，而是一条跨章长期承诺：先遇到人和问题，再理解原理，最后以行动证明有资格习得。
- 多数绝学在第五、六章结算；“孤云九式”作为师门终境例外，从第二章铺垫到第八章，只在终章恢复原名并突破十重。
- 每条长链混合至少三种玩法：调查、环境解谜、人物抉择、不同兵器切磋、护送或战斗；禁止连续四次“跑腿交物”。
- HUD 只显示地点目标，完整过程保留在任务日志，避免直接泄露解法。
- 所有奖励经过悟性门槛和待领悟队列；拿到传承不等于立即学会。

## 2. 母题转换与原创边界

| 经典玩法母题（仅内部参考） | 游戏内原创绝学 | 核心玩法差异 | 最终习得 |
|---|---|---|---|
| 与一名关键同伴反复相遇、共同补全失落剑理 | **孤云九式** | 与茗雾录事封砚秋多次解谜，终章回村与刑樊天从地下档案室取回祖师旧书；第十重恢复师门原名 | 第八章 |
| 由游侠乞众代代相传的刚猛掌法 | **盘龙十七式** | 行义帮以赈粮、救灾和护弱三场义约选传人；全体伤害并施加虚弱 | 第六章 |
| 佛门锻骨易脉、重塑根基的内功 | **易筋经** | 不是偷经，而是救人、护经、负重和静坐后获准研读；纯被动提升生命、内功与防御 | 第六章 |
| 接住外力、挪转方向并返还来敌 | **移花换劲** | 开放世界任意顺序验证回声、逆钟、让位棋、水则与换肩平衡，再化解双车险局；下一次受击按层数化解并返还 30%～60% 伤害 | 不限章节 |

以上仅保留抽象玩法母题。正式文本不得出现经典原名、原作人物、原作口诀及“某招克某招”的原文结构。

## 3. 四条跨章任务链

### 3.1 孤云九式：相遇 → 共解 → 求证 → 归村取书

1. 第二章“竹尾晨市”：结识茗雾外院录事封砚秋，读出三柄断剑的共同磨痕。
2. 第三章“武林大会”：与他复原回锋残图，解出“卸力、引偏、回中”的次序。
3. 第四章“洛阳旧市”：从刀、棍、暗器留下的试痕辨明同一套换力记号。
4. 第七章“茗雾外院”：保下被人准备销毁的缺页原目录，确认其装订孔属于林西师门旧谱。
5. 第八章“林西师徒院”：冷孤云三门基础武学均至九重后，与刑樊天、封砚秋合并四组证据；刑樊天坦承自己也只能练到第九重，并想起师父留在地下档案室的旧木匣。
6. 第八章“地下档案室”：找到《孤云残解》。书中说明“林西剑法”是避祸后的称呼，原名“孤云九式”；第九重练熟九处换力，第十重让九处首尾相接。回院三人共同推演后完成蜕变。

封砚秋是原创关键角色，不是师父替代品：他负责目录、装订和跨地线索；刑樊天与冷孤云共同完成武学推演。该链不锁门派选择，也不复用任何经典作品人物、对白或具体事件。

### 3.2 盘龙十七式：行义帮进入主线

1. 第二章竹尾河滩：帮助船户后获得半枚竹符，第一次知道行义帮不是乞讨组织，而是遍布驿路与灾区的互助网络。
2. 第四章洛阳漕渠：行义帮暗中协助保护证人，并提供伪装货运名单；正式进入主线调查。
3. 第五章古峰灾道：护送赈粮，玩家必须在追凶与救灾之间作出先后选择，但两条正义路线最终汇合。
4. 第六章嵩山脚下：完成“济饿、护弱、守信”三场义约，传功长老才授掌法。
5. 第七章联军：行义帮负责民夫撤离、消息传递与后勤，不作为第六个可加入门派。

### 3.3 易筋经：结缘 → 辨经 → 护经 → 禅关

1. 第三章结识少林俗家弟子，确认主角筋脉中有旧伤。
2. 第四章白马寺钟谜与伤者救治，证明玩家能辨伪经、先救人。
3. 第五章从被焚驿站护送残损经页回嵩山，途中不得让经页成为牟利物。
4. 第六章完成负重山阶、静坐听息与不还手护人三段禅关，获准研读。

此心法为纯被动，不出现在战斗招式选择中；提升心法会继续增加生命、内功与防御。

### 3.4 移花换劲：五理网状探索 → 双车险局

1. 竹尾村听双铜盆回声，理解旧力没有消失，只是在半拍后沿余响返回。
2. 凌月山门调停逆风旧钟，理解先顺来势、再借回摆收束。
3. 武林会场破解让位棋，理解让出空间可以迫使正面压力自行转向。
4. 洛阳府衙推演含嘉旧水则，理解分流不是截断，而是改变力量归去的位置。
5. 竹尾村帮脚夫调整扁担，理解换力时必须让旧劲托住下一步。
6. 五理齐备后，竹尾街口出现双车失控险局；玩家用空车接重车侧轮，把直冲换成斜旋并引入空巷，完成后自行悟得。

该链设置`chapter_independent = true`：四个开放地标从世界地图可提前游历，任何一条原理线索都能自动接取任务，五条线索可任意顺序完成。最终险局只依赖五理齐备旗标，不读取`chapterN_complete`、门派或等级；因此既能早期获得，也可能被玩家留到后期。

## 4. 数值与使用窗口

| 武学 | 品质 | 悟性 | 首层研读 | 定位 |
|---|---:|---:|---:|---|
| 孤云九式 | 橙 | 11 | 62 | 单体穿透 45% 防御 |
| 盘龙十七式 | 橙 | 10 | 60 | 全体伤害 + 虚弱 |
| 易筋经 | 橙 | 11 | 66 | 生命 +32、内功 +24、防御 +4，逐层成长 |
| 移花换劲 | 橙 | 12 | 68 | 常驻机敏/内劲；主动返还 30%～60% 伤害 |

绝学强度高于普通门派绝技，但不会替代全部技能：群攻、穿防、爆发、被动根基和防守反制各占一个战术槽。第七、八章敌人需要据此增加护甲、群体压力和高伤预警，而不是单纯提高生命。

## 5. 数据落地

- 长链任务使用 `auto_accept_triggers` 在第一条线索出现时自动接取。
- `require_all_completion_triggers = true`，每个长链里程碑必须全部完成；旧的普通任务继续保持任一触发即可完成。
- 普通长链通过 `reward_skills` 调用 `GameState.learn_skill()`；孤云九式例外，任务只找回《孤云残解》，最终由师门十重蜕变替换两式林西剑法。
- 四门现役绝学使用独立 `animation_id` 与独立四帧特效，不复用现有门派招式。
- “天外惊鸿”于 2026-09-08 撤下：技能和任务链不进入运行包，旧美术只作未采用素材留档。

## 6. 橙色绝学演出合同

1. 施放后先进入独立 `CanvasLayer 100`：全屏压暗，暂停普通目标特效，中央显示“传世绝学”与动态招式名。
2. 招式名后方播放该武学自己的聚气四帧特效，标题约 0.8 秒后淡出；文字必须由 Godot 动态绘制，不能烤进图片。
3. 单体绝学随后恢复到目标区域播放专属命中特效；全体伤害绝学禁止逐个目标重复小特效，必须播放一次覆盖整片战场的全屏图集，再统一结算所有目标。
4. 全屏图集使用黑底加色混合或透明 RGBA；禁止让素材自己的天空、地面和 UI 覆盖战斗背景。
5. 演出层位于战斗 HUD 和系统面板之上、对话层之下；演出结束必须彻底释放蒙版、标题和临时贴图。

分辨率补充：普通目标特效可继续使用2×2紧凑图集；全屏绝学必须按“单帧至少1600×900”验收，当前采用四张1672×941独立帧。禁止把1536×1024母图切成768×512小格后再拉伸到1080P。

图标补充：每门武学必须填写正式 `icon_path`。掌/剑/刀/棍/针/短刃/身法/心法不得互相借用语义；普通攻击根据当前武器动态选择图标。类型语义覆盖是最低线，后续再逐步升级到一招一图。

首个原型为“盘龙十七式”：标题聚气后进入金青掌劲流星雨，第三帧形成镇岳冲击与多点地裂，第四帧保留全场水纹余波。视觉只参考高端武侠 MMO 的威力层次，不使用经典作品的原作龙形或镜头构图。
