## 0. 一句话定位

> 单机武侠 RPG。**林西村出身的浪子剑客冷孤云**，因武林大派离奇血案而出闯江湖，在 5 大门派之一磨砺武功，结识同道与红颜，最终揭开"武林之谜"恢复江湖安宁。
> 玩法参考《风云天下会》：45° 视角回合制 + 三属性体系 + 武功修炼解锁 + 6 槽装备。

## 1. 时代背景

### 1.1 时代设定 【AI 补充】

- **大乾朝中期**，天子御极已三十年，朝廷与江湖井水不犯河水
- 漕运 / 盐运富庶，民间太平，**江湖近二十年来**未起大风波
- "近二十年武林安定"是一个**关键设定**——本作开篇之所以震动，就因为太久没死过大派弟子了

> 不取"末年动荡"是因为——故事开篇要让玩家先体验"安宁江湖"，再目睹它被打破，才有冲击力。

### 1.2 江湖与朝廷的关系 【AI 补充】

- **武林自治**：朝廷默许各派内部裁决，不干预
- **互不渗透**：江湖人不应试做官，朝廷不招安武林高手
- 这条设定让玩家全程在"江湖"内活动，不需要应付官府线
- 例外：**洛阳府衙** 在第四章会有戏份（洛阳奇案）

主角可加入的是 **武当 / 华山 / 古峰 / 凌月 / 茗雾 共 5 派**。少林因戒律不开放（这是武侠传统，跟金庸古龙一致）。

### 2.2 各派详细设定

#### 武当派
- **掌门** 【AI 补充】：玄真道长（六十出头，修道五十年）
- **大弟子（被杀者）** 【AI 补充】：陆青云（三十二岁，剑法已入化境，章节开篇被烈云盟所杀，是剧情触发点）
- **核心武功**：太极剑法（剑法）/ 玄武心经（内功）
- **门派性格**：清静无为、以柔克刚，但近年被江湖风波波及而开始关注外事
- **入派任务（玩家选武当后）**：陆青云之死的真相调查
- **建筑特征**：道观 + 八卦坛 + 紫霄宫

#### 华山派
- **掌门** 【AI 补充】：霍长空（五十岁，性烈如火，为大弟子之死震怒）
- **大弟子（被杀者）** 【AI 补充】：顾凌雪（女，二十六岁，华山年轻一辈第一剑）
- **核心武功**：华山剑法（剑法）/ 紫霞神功（内功）
- **门派内部矛盾** 【AI 补充】：华山内部有"剑学派" vs "气学派"长期纷争（不抄《笑傲江湖》原典，路数稍改：剑学派主张招式精妙，气学派主张内力为本）。这个矛盾会成为玩家选华山的支线主题
- **建筑特征**：山门 + 思过崖 + 论剑台

#### 少林寺（不可加入）
- **方丈** 【AI 补充】：无尘大师
- **大弟子（被杀者）** 【AI 补充】：圆觉禅师（二十八岁，少林新一代外功第一）
- **核心武功**：罗汉拳 / 般若掌（外功） + 易筋经 / 金刚不坏（内功）
- **门派性格**：佛门戒律严格，主角虽不能入门但**可结交少林俗家弟子**作为同伴
- **建筑特征**：山门 + 藏经阁 + 罗汉堂

#### 古峰派
- **掌门** 【AI 补充】：古疆雷（五十五岁，山野出身的豪侠）
- **大弟子（被杀者）** 【AI 补充】：雷彻（三十岁，刀法刚猛）
- **核心武功**：开山十八刀（刀法）/ 金刚力（内功）
- **门派性格**：豪爽粗犷、重情重义、不拘礼数。**最适合冷孤云的"放荡不羁"性格**
- **建筑特征**：石寨 + 演武场 + 烧酒坊
- **据点**：古月峰 【用户已定地名】

#### 凌月派
- **掌门** 【AI 补充】：凌霜女侠（女，四十五岁，江湖人称"霜女"）
- **大弟子（被杀者）** 【AI 补充】：白晚晴（女，二十五岁，凌月轻身第一）
- **核心武功**：踏月凌波（轻功 + 剑法）/ 寒霜针（暗器）/ 月华引（内功）
- **门派性格**：飘逸清冷、神秘自持、女子居多但收男弟子（避免性别隔离）
- **建筑特征**：竹楼 + 月谭 + 暗器堂
- **据点**：凌月山 【AI 补充地名】

#### 茗雾山庄（**伪装的真反派 / 武林血案幕后黑手**）【用户更新 2026-04-27】
- **表面**：隐士派、茶禅一味、行事低调、与世无争
- **实际**：千年传承的邪派伪装——5 派大弟子血案皆出自茗雾山庄之手
- **庄主** 【AI 补充】：苏雾笙（四十多岁，文人气质骗过江湖二十年；真名 **苏渊**）
- **大弟子** 【用户更新·诈死设定】：薛影（二十七岁，身法第一）—— **未真死**。庄主公开宣称弟子身亡以博江湖同情，实际薛影改头换面以"暗影"身份逐一暗杀其他派大弟子。第七章揭穿
- **核心武功**：茗雾步（身法）/ 隐影诀（内功 + 暗杀）/ **隐影夺命**（绝杀技，专攻人脉门要害）
- **门派性格**：表面温文尔雅、内核冷酷算计、千年蛰伏只为复仇与"集齐天书"
- **建筑特征**：表面山庄 + 茶园；地下密窟藏密谋
- **据点**：茗雾山 【AI 补充地名】
- **章节中的伪装期**：章一-五被江湖视为"也是受害者"（自家大弟子也死了）；章六起逐渐露出马脚；章八决战
- **玩家入派分支特殊处理** 【用户更新】：选茗雾的玩家在中后期会逐渐察觉异常，章八决战时面对的是**自己的师傅**（苏雾笙），整段体验是"师门变反派"的悲剧弧

#### 烈云盟（**误以为是反派，实为江湖中立邪功正心一脉**）【用户更新 2026-04-27】
- **表面**：修被江湖禁忌的武功——吸星大法 / 暗器 / 用毒，故被各派污名化为"邪派"
- **实际**：戒律严明、不伤无辜、二十年来无伤民记录（**类似《倚天屠龙记》的明教**）
- **盟主** 【AI 补充·身份调整】：云上君（真名 **戚云上**，五十出头；忍辱负重多年想还烈云盟清白）
- **盟内三长老** 【AI 补充·替代原 3 分舵主】：
  - **赤焰长老**：火攻 / 用毒，章六登场（先与主角误会交手，后澄清）
  - **冥光长老**：刺客出身，章七登场（提供关键证据揭穿茗雾）
  - **沧澜长老**：内功高手，章八并肩助主角对抗茗雾
- **核心武功**：噬魂掌 / 吸星诀 / 烈云心法（修武功偏邪但用意不邪）
- **背景**：千年前烈云盟祖辈是正派一支，因"修禁忌之功"被逐出门墙；与茗雾山庄前身**有死仇**（详见 §3）
- **行动逻辑**：长期被各派污蔑、近年弟子也被茗雾山庄陷害嫁祸、亟欲洗刷冤名

## 3. 武林之谜（核心悬念）【用户更新 2026-04-27】

> **三层真相，逐章揭开**。这是本作最核心的剧情骨架。

### 3.1 表层（玩家章一-四相信的）：烈云盟血洗各派

- 5 大派的大弟子接连身亡，江湖一致怀疑是**烈云盟**所为
- 烈云盟修禁忌武功（吸星 / 暗器 / 用毒），多年被各派排挤，"嫌疑最大"
- 主角下山时，整个江湖都是"烈云盟该死"的舆论

### 3.2 中层（章五-七逐渐揭开）：烈云盟是被冤枉的"明教"

主角调查中发现：

- 烈云盟修武功偏邪，但戒律严明，二十年来无伤民记录
- 真正的凶手是茗雾山庄"已死"的大弟子 **薛影**——他**诈死**后改头换面，逐一暗杀其他派大弟子
- 茗雾山庄假扮"也是受害者"，暗中获得各派信任，甚至加入"正派联盟"
- 烈云盟早已察觉但因身份被排斥，无法发声

### 3.3 深层（章八揭晓）：茗雾山庄的千年宿怨

- 千年前江湖宗师 **渊冥子** 留下天书三卷，由各派分护
- 茗雾山庄前身曾在千年前与正派 + **烈云盟祖辈** 联手对抗外敌后，因"独占天书"野心被联手剿灭
- 茗雾家族中一支隐姓埋名、开茗雾山庄假扮隐士、蛰伏千年等待复仇
- 苏雾笙就是当代家主，要在他这一代完成 **"集齐三卷天书 + 报千年血仇"** 的双重目标
- 这就是为什么茗雾山庄首要**抹黑烈云盟**——当年烈云盟祖辈是参与剿灭茗雾家族的力量之一

### 3.4 天书三卷（保留 v0.1 设定 + 补充）

| 卷 | 内容 | 现存何处 |
|---|---|---|
| **《青冥录》** | 剑道总诀 | 武当藏经阁（章四残页线索）|
| **《赤渊纂》** | 拳脚刚猛 | 少林藏经阁（章七揭示） |
| **《玄霜诀》** | 内功心法 | **冷孤云家族秘藏**（章六由刑樊天交付）|

### 3.5 主角的位置

- 冷孤云是**渊冥子后人**（章六揭示）—— 血脉里携带天书最终封印的钥匙
- 茗雾山庄要他不仅是为了报复（渊冥子=千年前镇压茗雾前身的关键人物之一），也是为了开启天书最后一卷的封印
- 这就是为什么茗雾庄主要威胁刑樊天："交出冷孤云"

### 3.6 主角的多重身份冲突

- **生而注定**：渊冥子血脉、武林秘辛中心人物
- **心之所向**：放荡不羁、携酒仗剑走天涯（拒绝任何派系束缚）
- 这一矛盾贯穿章六到章八，并在结局中以"4 路多结局"具象化：选择跟谁、是否接掌天书、是否回归江湖——全是这个矛盾的不同解

  1. 古峰派遭袭，主角与流行追月驰援（袭击者**伪装成烈云盟**）
  2. 跟古疆雷并肩作战
  3. 战中遇见浪荡公子**令狐封**（首次登场，言行有点奇怪）
  4. 章末战：vs 伪装为烈云盟的茗雾刺客（薛影手下）
  5. **战后异象**：尸体身上同时找到烈云盟令 + 一枚极淡的茗雾山庄暗器（玩家初见，未必反应过来）
  6. **戚云笙首次"暗助"** 【用户新增】：主角伤重昏迷于山涧，醒来时发现伤口已被人以毒功封住毒素，身边一缕烈云盟独有的暗香——施救者已悄然离去（玩家此时只闻其香未见其人）
- **章末**：救下古峰派，但古疆雷重伤，临终交代另一卷天书线索；主角第一次心生疑问"凶手真是烈云盟么？为什么烈云盟还有人救我？"

### 第六章 · 师承之谜（≈ 18 分钟）【用户更新 师徒误会章 + 新增戚云笙留物】
- **场景**：林西村（回村）→ 刑樊天住所 → 竹林追击 → 村外古道
- **关键事件**：
  1. 主角回村探望刑樊天
  2. 撞见刑樊天被**茗雾山庄派来的人**（不是烈云盟）围困——玩家此时第一次看到茗雾山庄独有的"隐影诀"招式
  3. 主角援手击退，刑樊天却拒绝交代来由，只说"江湖事不必你管"
  4. 主角逼问 → 刑樊天**透露自己是茗雾山庄当年大弟子**【用户更新】，但拒绝多说
  5. 主角误以为师傅就是幕后推手 → 二人争执，主角愤而离去
  6. 主角带走临行前刑樊天硬塞给他的家传秘笈 **《玄霜诀》**（永久内力 +30，开新武功）
  7. **戚云笙第二次现身** 【用户新增】：主角离村途中在古道客栈停留，发现房中桌上一枚她留下的**烈云盟玉佩 + 一封手书**：抬头是"放剑山中人"，内容只有一句："**真凶不在江湖之表，请君上烈云盟一行**"。主角追出去时只见远山一抹红衣已绝尘而去
- **章末**：主角离开林西村，独自踏上调查路；带着戚云笙的玉佩朝烈云盟分舵而去；刑樊天望着他的背影低声："等你看清真相再回来"

### 第七章 · 烈云盟真相（≈ 18 分钟）【用户更新 核心反转章 + 戚云笙正式登场】
- **场景**：荒野古道 → 烈云盟分舵 → 烈云盟密谈厅 → 茗雾山庄外围
- **关键事件**：
  1. 主角追查活口口供 + 戚云笙留信线索 → 锁定烈云盟分舵
  2. 入分舵被赤焰、冥光长老拦下短暂交手——**戚云笙现身阻止**：「都退下，他是我请来的客人」
  3. 主角与戚云笙正式相识：
     - 她坦承前两次暗助和留信是她所为
     - 她解释烈云盟二十年来一直在被栽赃、为何不敢公开为自己辩
     - 她的言谈、武功、性格在主角心中留下深刻印象——这是 ending C 触发的种子
  4. 盟主云上君亲自现身献出关键证据：
     - 章四古寺栽赃道具的真正出处
     - 薛影"诈死"的证人证词
     - 千年前茗雾家族被剿灭的旧档（解释茗雾的复仇动机）
  5. 主角恍然——**真凶是茗雾山庄**
  6. 联军筹备：5 派 + 烈云盟 + 少林俗家
  7. 流行追月、悦无姮、赵思颖相继归队
  8. **三女主同框关键场景** 【新增】：聚义厅议事时悦无姮 / 赵思颖 / 戚云笙三人首次同框，玩家可观察主角与三人对话的微妙差异——也是玩家做"心向哪位"判断的重要参考
  9. 令狐封被识破是**茗雾山庄外门弟子**，但他坦承是被茗雾家挟持，倒戈帮主角
- **章末**：联军兵分两路扑向茗雾山庄

  5. 章末战 #2：vs 苏雾笙（最终 boss）—— **戚云笙率烈云盟"圣姑亲卫"在外殿牵制薛影残党**【新增】

#### 第八章 · 多结局抉择（4 路）【用户新增 2026-04-27】

> 玩家在前 7 章累积的"心向选择"（与 3 女主对话时选的关键回应数）+ 章八临结尾的明确分支选项 → 触发不同结局。

| 结局 | 触发 | 标题 | 收束情节 |
|---|---|---|---|
| **A · 江湖侠侣** | 心向悦无姮累积最高 + 章末选"剑出双锋" | 「双剑天涯」 | 主角与悦无姮持双剑游历江湖，路见不平拔刀相助，洒脱自由 |
| **B · 红尘归隐** | 心向赵思颖累积最高 + 章末选"挂剑安身" | 「医侠仙侣」 | 主角与赵思颖在洛阳郊外开医馆，世人忘了他江湖名号，但偶有少侠慕名拜访 |
| **C · 邪正不分**（**最契合主角内心**）| 心向戚云笙累积最高 + 章末选"携酒共行" | 「烈云西北望」 | 戚云笙放弃圣姑身份，与主角携酒走天涯；江湖人传说"烈云盟少了个圣姑，江湖多了对浪侠"，**完美呼应主角"携酒仗剑走天涯"的人生目标** |

**心向累积怎么算**（建议）：
- 每章与某女主有 1-2 次关键对话选项（如"调侃她 / 关心她 / 保持距离"），选"关心她"+1 心向
- 章七聚义厅同框时，主角主动找谁说话 +2
- 章末抉择前的最后一次对话（每个女主一次）+3
- 累积分高者触发对应结局；若分数接近平局，则可能触发独行 D 或玩家手动选

**额外抉择**（不影响主结局，但影响尾声）：
- 是否接掌天书三卷（接掌 / 焚毁 / 三派分护）
- 是否原谅令狐封（原谅 / 让他归隐 / 他重伤死了无须选）
- 是否让烈云盟正式入正派联盟（入 / 不入 / 由戚云笙未来决定）

- **章末**：江湖恢复安宁，根据 A/B/C/D 不同结局演出对应尾声 CG / 文字
