## 0. 一句话定位

> 单机武侠 RPG。**林西村出身的浪子剑客冷孤云**，因武林大派离奇血案而出闯江湖，在 5 大门派之一磨砺武功，结识同道与红颜，最终揭开"武林之谜"恢复江湖安宁。
> 玩法参考《风云天下会》：45° 视角回合制 + 三属性体系 + 武功修炼解锁 + 6 槽装备。

## 1. 时代背景

### 1.1 时代设定 【AI 补充】

- **大乾朝中期**，天子御极已三十年，朝廷与江湖井水不犯河水
- 漕运 / 盐运富庶，民间太平，**江湖近二十年来**未起大风波
- "近二十年武林安定"是一个**关键设定**——本作开篇之所以震动，就因为太久没死过大派弟子了

> 不取"末年动荡"是因为——故事开篇要让玩家先体验"安宁江湖"，再目睹它被打破，才有冲击力。

### 1.2 江湖与朝廷的关系 【AI 补充】

- **武林自治**：朝廷默许各派内部裁决，不干预
- **互不渗透**：江湖人不应试做官，朝廷不招安武林高手
- 这条设定让玩家全程在"江湖"内活动，不需要应付官府线
- 例外：**洛阳府衙** 在第四章会有戏份（洛阳奇案）

主角可加入的是 **武当 / 华山 / 古峰 / 凌月 / 茗雾 共 5 派**。少林因戒律不开放（这是武侠传统，跟金庸古龙一致）。

### 2.2 各派详细设定

#### 武当派
- **掌门** 【AI 补充】：玄真道长（六十出头，修道五十年）
- **大弟子（被杀者）** 【AI 补充】：陆青云（三十二岁，剑法已入化境，章节开篇被烈云盟所杀，是剧情触发点）
- **核心武功**：太极剑法（剑法）/ 玄武心经（内功）
- **门派性格**：清静无为、以柔克刚，但近年被江湖风波波及而开始关注外事
- **入派任务（玩家选武当后）**：陆青云之死的真相调查
- **建筑特征**：道观 + 八卦坛 + 紫霄宫

#### 华山派
- **掌门** 【AI 补充】：霍长空（五十岁，性烈如火，为大弟子之死震怒）
- **大弟子（被杀者）** 【AI 补充】：顾凌雪（女，二十六岁，华山年轻一辈第一剑）
- **核心武功**：华山剑法（剑法）/ 紫霞神功（内功）
- **门派内部矛盾** 【AI 补充】：华山内部有"剑学派" vs "气学派"长期纷争（不抄《笑傲江湖》原典，路数稍改：剑学派主张招式精妙，气学派主张内力为本）。这个矛盾会成为玩家选华山的支线主题
- **建筑特征**：山门 + 思过崖 + 论剑台

#### 少林寺（不可加入）
- **方丈** 【AI 补充】：无尘大师
- **大弟子（被杀者）** 【AI 补充】：圆觉禅师（二十八岁，少林新一代外功第一）
- **核心武功**：罗汉拳 / 般若掌（外功） + 易筋经 / 金刚不坏（内功）
- **门派性格**：佛门戒律严格，主角虽不能入门但**可结交少林俗家弟子**作为同伴
- **建筑特征**：山门 + 藏经阁 + 罗汉堂

#### 古峰派
- **掌门** 【AI 补充】：古疆雷（五十五岁，山野出身的豪侠）
- **大弟子（被杀者）** 【AI 补充】：雷彻（三十岁，刀法刚猛）
- **核心武功**：开山十八刀（刀法）/ 金刚力（内功）
- **门派性格**：豪爽粗犷、重情重义、不拘礼数。**最适合冷孤云的"放荡不羁"性格**
- **建筑特征**：石寨 + 演武场 + 烧酒坊
- **据点**：古月峰 【用户已定地名】

#### 凌月派
- **掌门** 【AI 补充】：凌霜女侠（女，四十五岁，江湖人称"霜女"）
- **大弟子（被杀者）** 【AI 补充】：白晚晴（女，二十五岁，凌月轻身第一）
- **核心武功**：踏月凌波（轻功 + 剑法）/ 寒霜针（暗器）/ 月华引（内功）
- **门派性格**：飘逸清冷、神秘自持、女子居多但收男弟子（避免性别隔离）
- **建筑特征**：竹楼 + 月谭 + 暗器堂
- **据点**：凌月山 【AI 补充地名】

#### 茗雾山庄（**伪装的真反派 / 武林血案幕后黑手**）【用户更新 2026-04-27】
- **表面**：隐士派、茶禅一味、行事低调、与世无争
- **实际**：千年传承的邪派伪装——5 派大弟子血案皆出自茗雾山庄之手
- **庄主** 【AI 补充】：苏雾笙（四十多岁，文人气质骗过江湖二十年；真名 **苏渊**）
- **大弟子** 【用户更新·诈死设定】：薛影（二十七岁，身法第一）—— **未真死**。庄主公开宣称弟子身亡以博江湖同情，实际薛影改头换面以"暗影"身份逐一暗杀其他派大弟子。第七章揭穿
- **核心武功**：茗雾步（身法）/ 隐影诀（内功 + 暗杀）/ **隐影夺命**（绝杀技，专攻人脉门要害）
- **门派性格**：表面温文尔雅、内核冷酷算计、千年蛰伏只为复仇与"集齐天书"
- **建筑特征**：表面山庄 + 茶园；地下密窟藏密谋
- **据点**：茗雾山 【AI 补充地名】
- **章节中的伪装期**：章一-五被江湖视为"也是受害者"（自家大弟子也死了）；章六起逐渐露出马脚；章八决战
- **玩家入派分支特殊处理** 【用户更新】：选茗雾的玩家在中后期会逐渐察觉异常，章八决战时面对的是**自己的师傅**（苏雾笙），整段体验是"师门变反派"的悲剧弧

#### 烈云盟（**误以为是反派，实为江湖中立邪功正心一脉**）【用户更新 2026-04-27】
- **表面**：修被江湖禁忌的武功——吸星大法 / 暗器 / 用毒，故被各派污名化为"邪派"
- **实际**：戒律严明、不伤无辜、二十年来无伤民记录（**类似《倚天屠龙记》的明教**）
- **盟主** 【AI 补充·身份调整】：云上君（真名 **戚云上**，五十出头；忍辱负重多年想还烈云盟清白）
- **盟内三长老** 【AI 补充·替代原 3 分舵主】：
  - **赤焰长老**：火攻 / 用毒，章六登场（先与主角误会交手，后澄清）
  - **冥光长老**：刺客出身，章七登场（提供关键证据揭穿茗雾）
  - **沧澜长老**：内功高手，章八并肩助主角对抗茗雾
- **核心武功**：噬魂掌 / 吸星诀 / 烈云心法（修武功偏邪但用意不邪）
- **背景**：千年前烈云盟祖辈是正派一支，因"修禁忌之功"被逐出门墙；与茗雾山庄前身**有死仇**（详见 §3）
- **行动逻辑**：长期被各派污蔑、近年弟子也被茗雾山庄陷害嫁祸、亟欲洗刷冤名

## 3. 武林之谜（核心悬念）【用户更新 2026-04-27】

> **三层真相，逐章揭开**。这是本作最核心的剧情骨架。

### 3.1 表层（玩家章一-四相信的）：烈云盟血洗各派

- 5 大派的大弟子接连身亡，江湖一致怀疑是**烈云盟**所为
- 烈云盟修禁忌武功（吸星 / 暗器 / 用毒），多年被各派排挤，"嫌疑最大"
- 主角下山时，整个江湖都是"烈云盟该死"的舆论

### 3.2 中层（章五-七逐渐揭开）：烈云盟是被冤枉的"明教"

主角调查中发现：

- 烈云盟修武功偏邪，但戒律严明，二十年来无伤民记录
- 真正的凶手是茗雾山庄"已死"的大弟子 **薛影**——他**诈死**后改头换面，逐一暗杀其他派大弟子
- 茗雾山庄假扮"也是受害者"，暗中获得各派信任，甚至加入"正派联盟"
- 烈云盟早已察觉但因身份被排斥，无法发声

### 3.3 深层（章八揭晓）：茗雾山庄的千年宿怨

- 千年前江湖宗师 **渊冥子** 留下天书三卷，由各派分护
- 茗雾山庄前身曾在千年前与正派 + **烈云盟祖辈** 联手对抗外敌后，因"独占天书"野心被联手剿灭
- 茗雾家族中一支隐姓埋名、开茗雾山庄假扮隐士、蛰伏千年等待复仇
- 苏雾笙就是当代家主，要在他这一代完成 **"集齐三卷天书 + 报千年血仇"** 的双重目标
- 这就是为什么茗雾山庄首要**抹黑烈云盟**——当年烈云盟祖辈是参与剿灭茗雾家族的力量之一

### 3.4 天书三卷（保留 v0.1 设定 + 补充）

| 卷 | 内容 | 现存何处 |
|---|---|---|
| **《青冥录》** | 剑道总诀 | 武当藏经阁（章四残页线索）|
| **《赤渊纂》** | 拳脚刚猛 | 少林藏经阁（章七揭示） |
| **《玄霜诀》** | 内功心法 | **冷孤云家族秘藏**（章六由刑樊天交付）|

### 3.5 主角的位置

- 冷孤云是**渊冥子后人**（章六揭示）—— 血脉里携带天书最终封印的钥匙
- 茗雾山庄要他不仅是为了报复（渊冥子=千年前镇压茗雾前身的关键人物之一），也是为了开启天书最后一卷的封印
- 这就是为什么茗雾庄主要威胁刑樊天："交出冷孤云"

### 3.6 主角的多重身份冲突

- **生而注定**：渊冥子血脉、武林秘辛中心人物
- **心之所向**：放荡不羁、携酒仗剑走天涯（拒绝任何派系束缚）
- 这一矛盾贯穿章六到章八，并在结局中以"4 路多结局"具象化：选择跟谁、是否接掌天书、是否回归江湖——全是这个矛盾的不同解

**外形描述（AI 出图 prompt 参考）【部分已锁定】**

- **脸型与五官**：剑眉入鬓，星目狭长，眼神中自带三分慵懒七分锐利；鼻梁挺直如削，薄唇微抿，嘴角天生微微上扬，带一抹玩世不恭的笑意。下颌线条利落，不怒自威时不显凶戾，笑起来像个吊儿郎当的邻家少年。【锁定】
- **发型**：黑色长发及肩，上半束于脑后，用**暗色布带**简单扎成低马尾；额前几缕碎发随意散落。**禁止**：头巾、额带、红色发绳、顶髻布条。【锁定】
- **身形**：修长精瘦，肩宽腰窄，不壮硕但有习武之人的肌肉线条；站姿随意懒散，常倚墙/倚树而立，一只脚微屈踩着身后的墙或树干。
- **服饰**：
  - 外层：冷灰色粗布长袍，交领右衽，袍角及膝，略有做旧褪色但不破烂【锁定】
  - 内衬：白色交领内衫，领口微敞，露出锁骨一线【锁定】
  - 腰带：深灰近黑色布质腰带，紧束腰间，右侧挂剑【锁定】
  - 下装：同色系深灰收口长裤
  - 靴子：深色短靴，牛皮底，走路悄无声息【锁定】
- **配饰**：
  - 腰间佩剑：林西铁剑，无鞘饰，剑柄缠暗青色布条
  - 左侧腰间挂一**青灰色酒葫芦**，葫芦上有一道旧裂痕补过的痕迹【锁定】
- **色彩总谱**：冷灰 + 白 + 深灰 + 青灰（酒葫芦），整体灰冷色调，只有酒葫芦的青色是唯一的跳色。
- **标志神态**：半眯眼似笑非笑、歪头斜靠、喝酒时仰头露出喉结、拔剑瞬间眼神由懒散变锐利。

**性格与行为**

- **放荡不羁**：不守规矩、不拜高堂、不愿被任何门派束缚。说话带三分调笑，对长辈也敢直来直去。
- **行侠仗义**：嘴上说着"不关我事"，脚下已经迈进是非之地。看不得以强凌弱，尤其见不得妇孺被欺。
- **嗜酒**：腰间酒葫芦从不离身，高兴了喝、烦闷了喝、打架前也要先灌一口。但从不误正事——再醉也能拔剑。
- **爱凑热闹**：集市吵架、码头斗殴、茶馆说书——哪儿人多往哪儿钻。一半是好奇，一半是"看有没有不平事"。

- **标志神态**：初见主角时从面纱上方投来的审视目光（眼睛在说"你是谁"）、确认主角可信后摘下面纱时的微微一笑（整张脸突然变暖）、听到父亲提起"烈云盟大业"时眼神瞬间暗下去、单独跟主角说话时偶尔流露出少女的好奇和狡黠（这才是真正的她）。

**性格与行为**

- **冷艳伪装下的柔软内心**：江湖传言她"用毒高手心狠手辣"——她听惯了，不解释，反而故意保持距离以保护自己。但盟内谁受了伤她会亲自熬药，哪个弟子受了委屈她会暗中出手。她的冷酷是铠甲，不是本性。
- **心思敏锐**：看人极准。第一次暗中观察主角（章五），就从主角替古峰派拼命的方式判断出"此人内心赤子、可交"——比主角自己还早知道他会站哪边。
- **偶尔泼辣狡黠**：对敌人冷若冰霜，对信任的人偶尔俏皮——比如留信调戏主角"放剑山中人"（明知主角是"仗剑"不是"放剑"，故意写的），比如章七正式见面时第一句话是"那封信你是不是看了三遍"。
- **自小被误解的孤独**：七岁丧母、随父在烈云盟长大，从小到大出门就被骂"毒妇之女"。她的"冷"是后天学会的生存技能——不靠近就不会被伤。这也是为什么她和主角"镜像契合"：两人都"被外界误解"，都向往"远离江湖纠葛"。
- **对感情的矛盾**：跟主角在一起是最"对"的——两人灵魂太像了。但她始终在退：因为跟主角在一起意味着她必须放弃"圣姑"身份和父亲的期望，而她不确认自己值不值得主角"为她放弃江湖"。章七结尾那段对白是全剧最虐的——"你走你的天涯，我守我的烈云。见或不见，都是我选。"
- **习惯动作**：听人说话时微微侧头（审视感）、确认信任后左手不自觉转右腕的黑玉镯、被逗到时嘴角先动眼再笑（戒备→放松的身体语言）、做重大决定前会摸一下发髻上的红玉簪（跟母亲说话）。

**剧情定位**：三女主中与主角内心最契合的一位。结局 C 被设计为"最符合主角人生目标"的结局——她放弃圣姑身份跟主角携酒走天涯，是两个人各自的"逃离"合为"同行"。她的存在让整个故事"邪派 = 反派"的二元对立彻底瓦解。

  - 右手食指戴一枚素银戒指（少林俗家弟子信物，从不提，也不摘）
  - 腰间挂一个牛皮水囊（不是酒葫芦——他不喝酒，这是跟主角的关键差异）

- **潇洒不羁但有底线**：跟冷孤云一样"不守规矩"，但他比冷孤云多活了八年、更清楚哪些规矩是可以打破的、哪些是不能碰的。他的不羁是有选择的——绝不对弱者拔剑、绝不趁人之危、绝不在对方没拔剑时出手。

  - 内衬：白色丝绸交领衫

**性格与行为**

- **表面的浪荡、内心的深渊**：跟主角一起喝酒、逛青楼（他付钱）、斗嘴——表面上看起来比冷孤云还快乐。但主角喝醉了睡过去之后，他一个人坐在窗边，不喝酒不说话，就那么坐着——直到天亮。这是全剧最孤独的角色。
- **身不由己的"镜像"**：令狐封想成为冷孤云那样的人——自由、坦荡、不被任何人束缚。但他不能。家族被茗雾握有把柄，他每一次"监视"主角都是在给自己家族的人欠一条命。他的"不羁"是偷来的——每偷一点就觉得罪孽深一点。
- **对主角的真正感情**：起初是任务，但主角那种"不为什么就对你好"的信任——让他第一次觉得自己"还是个活人"。他是真心把主角当兄弟的，这也是为什么章七被揭穿时他不跑——他想跑，但他的脚不肯动。
- **章八的选择不是"洗白"**：他在决战中的倒戈不是因为"正义觉醒"——他早就知道茗雾是错的。他倒戈是因为主角在知道他身份后仍然说了一句："你要是还愿意，喝完这杯再决定。"——这是主角给他的第一次"真正的选择"。
- **习惯动作**：笑的时候先用折扇遮一下嘴再露出脸（习惯性伪装）、紧张时右手反复摩挲腰间玉佩（在跟祖母说话）、被说到痛处时笑容会停一瞬然后变得更大、真正动怒时啪一声收起折扇（这是他唯一不伪装的情绪）。

**剧情定位**：全剧最复杂的角色。他不是反派，但他帮反派做事；他不是坏人，但他的手不干净；他不是主角的朋友，但他比主角任何一个朋友都更在意主角。结局未定（由玩家在章八选择是否原谅），但无论哪个选择——他的戏都会让玩家记住很久。

### 4.8 最终 Boss：苏雾笙 / 苏渊 【AI 补充】

**基础信息**

| 字段 | 设定 |
|---|---|
| 姓名 | 苏雾笙（化名）/ 真名 苏渊 |
| 年龄 | 48 岁 |
| 身高 | 约七尺六寸（~178 cm），身形颀长 |
| 表面身份 | 茗雾山庄庄主，江湖公认的隐士雅人 |
| 真实身份 | 茗雾家族当代家主，千年复仇计划的执行者 |
| 武功 | 茗雾步（身法）+ 隐影诀（极高境界）+ 隐影夺命（绝杀技）+ 天书残卷武功 |
| 登场 | 章三武林大会首次亮相（伪装期）；章六起逐渐露馅；章八决战 |

**外形描述（AI 出图 prompt 参考）**

- **脸型与五官**：长脸偏瘦，轮廓清癯儒雅——第一眼任何人都会觉得"这是个读书人不是武夫"。眉形纤细微弯（文人眉），眼睛细长，目光温和含笑——这种温和是练出来的，练了二十年。鼻梁高直，嘴唇薄而线条优雅。整张脸上没有任何江湖气的痕迹——没有伤疤、没有横肉、没有杀气。这才是最可怕的：因为真正的杀意已经被修炼成了一种"气质"。中年后留三缕清须（颌下一缕，两鬓各一缕），更添名士风范。
- **发型**：黑发间有稀疏灰丝，整齐束于头顶，以一根青玉簪固定。从不散发，从不凌乱——他的外表就是他最好的伪装。
- **身形**：颀长清瘦，肩膀不宽但极稳。站姿如松，举手投足全是文人的从容——倒茶、展卷、拂袖，每一个动作都优雅到让人觉得"这个人不可能杀人"。但他的手腕和手指有异于常人的灵活性——茗雾步和暗杀术需要的就是这种"看似文弱实则致命"的肢体控制力。
- **服饰**：
  - 外层：藏青色（近乎墨色的深青）绸质长袍，交领右衽，袍身绣有极低调的同色竹叶暗纹——只有在特定光线角度下才能看出。袖口宽大飘逸，拂袖时带起一阵微风（这阵风能让对手看不清他的手腕动作——二十年暗杀功夫已融入日常举止）
  - 内衬：暗灰色交领衫
  - 腰带：同色系墨青色绸带，束得端正
  - 下装：深灰色宽腿长裤
  - 鞋：黑色布鞋，底极薄——茗雾步需要脚底的每一寸触感
- **配饰**：
  - 手中常持一把**紫砂茶壶**（不是道具，是真爱喝茶——但壶嘴的设计恰好能在紧急时喷出一道细如针的茶水，力道足以击穿喉管）
  - 腰间挂一枚**古玉佩**——正面是茗雾山庄的山形徽记，背面是苏家千年族谱的微雕（肉眼几乎看不清）
  - 右手无名指上一枚**黑色石戒**（茗雾家主信物，相传是千年前渊冥子封印茗雾前身时崩落的封印碎石化成）
- **色彩总谱**：藏青 + 墨青 + 深灰 + 黑。全身沉稳至极，没有任何鲜艳色——甚至连"反派标志性的红黑配色"都不用。他是最危险的反派类型：看起来不像反派。
- **标志神态**：公开场合永远是温和微笑（嘴角精确的弧度，从不露出牙齿）、听各派争论时低着头安静品茶（实则用茶香掩盖自己在嗅每个人的"气息"）、章六被主角初次质疑时微笑不变但眼神深处划过一道极冷的光、章八决战前撕下伪装的那一刻——微笑不变但整张脸的肌肉角度全部变了（同样的笑，从温润君子变成了千年猎食者）。

**性格与行为**

- **千年宿怨的当代执行者**：苏雾笙不是为个人欲望作恶——他是在为千年前的家族血仇"还债"。这种"家族使命"让他对自己的行为毫无道德负担——在他看来，他不是在杀人，是在"讨回公道"。这种"正义感"让他比任何贪婪型反派都危险。
- **极致的伪装者**：二十年如一日的表面温文尔雅。不是"冷漠"而是"温和"——会跟各派掌门讨论茶道、会给受伤的弟子亲手敷药、会在武林大会上为受害者默哀落泪。他的伪装不是空洞的表演——他自己都快信了。
- **冷静到冷酷的算计**：没有情绪波动。被他杀了大弟子的掌门在他面前痛斥凶手时，他能安静地听完、然后温和地说一句"天道昭昭，凶手必不得善终"——说的就是他自己。
- **唯一的裂缝**：刑樊天。这个"当年的师弟 / 师兄"（用户拍板后定）是他唯一的不冷静。一提到刑樊天的名字，苏雾笙会沉默一瞬——不是因为愧疚，是因为"一个本该站在我这边的人背叛了家族"。这丝裂缝在章八被刑樊天利用——某种程度上，苏雾笙输在自己唯一的执念上。
- **习惯动作**：说话前先啜一口茶（争取思考时间）、听人说话时右手食指在壶盖上画圈、真正动杀意时会把茶壶缓缓放下（动作越慢杀意越重）、与人交谈时目光从对方眉心移到胸口——不是在观察表情，是在计算"下一秒如果出剑，从哪个点刺进去最快"。

**剧情定位**：最终 Boss，但不是一个"怪物"——是一个"人"。他的千年宿怨是真的、他的伪装是极致的、他的结局由刑樊天亲手了结——这是"师弟杀死师兄"的清门仪式。选茗雾派的玩家将面对"挥剑斩师门"的沉重体验。

**外形描述（AI 出图 prompt 参考）**

- **脸型与五官**：精瘦三角脸，颧骨高耸，下巴尖而有力。眼睛是他最显著的特征：小而深陷，瞳仁极黑，看人时头微低眼珠往上翻——不是在看你的脸，是在看你的脖子和脉门。鼻梁鹰钩形（不是夸张的弯钩，但仔细看有明显的钩曲）。嘴唇极薄，几乎没有唇色（常年在地下活动的苍白）。整张脸骨骼感极强——像是用刀削出来的。

- **服饰**：
  - 全身紧身黑衣（暗杀装束），布料哑光——在月光下也不反光
  - 头戴同色面罩（仅露眼睛）
  - 手戴黑色薄皮手套（指节处有细微的硬质凸起——不是武器，是封住自己脉门以防被反击）
  - 黑布束腿，软底黑靴（靴底是特制的，走在瓦片上完全无声）

  - 腰带间绑有一排暗器套：细如牛毛的**透骨针**×12
  - 靴侧藏有一柄**短匕**（刃长仅三寸，淬毒）
  - **无佩剑**——薛影的武器就是他自己的身体（隐影诀的至高境界：手刀、指刺、膝撞，全攻脉门）
- **色彩总谱**：全黑。没有第二颜色。他的存在本身就是"暗影"两个字。
- **标志神态**：（仅露出眼睛时）那种头微低、眼珠上翻盯着你的"猎食者凝视"、出手前眼睛有一瞬会微微眯一下（然后你已经中招了）、章八被主角击败摘下面罩时——那张脸的苍白和瘦削让人倒吸一口凉气。

**性格与行为**

- **没有个人情感的杀戮机器**：薛影不是"坏人"——他是被茗雾家族从婴儿时期就开始训练的"工具"。他暗杀大弟子们没有任何快感和愧疚——对他来说这就是"任务"，像砍柴挑水一样。这让他比任何怀着仇恨的杀手更可怕——因为他杀人时心跳不会加速。
- **对苏雾笙的绝对服从**：他从婴儿起就被灌输"你的命是庄主给的"，从没质疑过。即使是"诈死"抛弃自己的身份、即使是独自背负五条人命的追杀——全是"庄主吩咐我做"。
- **章八的最后一刻**：被主角击败后，濒死的薛影说了唯一一句不是"任务"的话——"我现在可以见到我娘吗"（他娘在他三岁时被茗雾处死，因为"太过心软不适合培养工具"）。这是他一生中唯一的自我意识——在死前。
- **习惯动作**：安静地站着时一动不动（不是正常人的微动，是真的完全静止——像一个影子）、出手后必在对手倒地前已退回原位。

**剧情定位**：章八第一场 Boss 战的对手。他不是最终 Boss，但他的存在解释了"茗雾山庄把人不当人"的本质——某种程度上，他是茗雾家族千年罪恶的具象化。

**性格与行为**

- **忍辱负重二十年**：被各派污蔑为"邪派"二十余年，从不主动辩解——因为知道没有证据的辩解只会让污名更重。把所有委屈咽下去，把盟内弟子的安全放在第一位。
- **父亲的两难**：对女儿戚云笙的保护欲和"让她做自己"的尊重一直在冲突。章七看到女儿在主角面前摘下面纱微笑时——他知道女儿可能要走了，但他不说。只在章八结尾对主角说一句话："她选了你。我这做爹的，不拦。"

- **习惯动作**：说话前先摸一下手腕的木珠、站着时重心永远落在双脚正中间（山一样的稳定）、真正愤怒时右手握拳——然后松开（他练了二十年控制自己的愤怒）、女儿在身边时声音会自动放轻三度。

**剧情定位**：章七起的关键盟友、戚云笙的父亲、整个"烈云盟洗冤"线的核心人物。他的存在让玩家理解"这个被骂了二十年的邪派盟主到底是什么样的人"。

### 5.8 美术总基调（项目级约定）【用户约定 2026-04-27 · 所有立绘 / 场景 / 图标 / UI 都要遵守】

> 参照 90 年代港式武侠漫画（如《风云》、《天子传奇》、《神兵玄奇》等同时代作品的视觉风格）。
> 此约定写入 `prompts/templates/_shared.yaml#style_anchor`，对全部 prompt 生效。

#### 默认基调 = 鲜明光亮

- **明亮通透**：避免整体灰暗、雾蒙蒙
- **色彩饱和鲜艳**：港漫的标志性厚涂浓色，不要清新水彩淡色
- **光影对比鲜明**：阳光下高光/阴影分明，体现立体感
- **暖色调与冷色调对比**：避免单一灰调

#### 允许暗调的特例场景

只有以下类型的场景**可以**使用暗调：

| 场景类型 | 暗调氛围说明 |
|---|---|
| 洞穴 / 地下密窟 | 火把照明，明暗对比强烈但不灰暗（如茗雾山地下密窟）|
| 密林深处 | 阳光被树冠遮挡，绿光斑驳，紧张感来自光影而非低饱和 |
| 墓地 / 古迹 | 月光 / 烛光，冷色调但保持饱和度 |
| 夜战 / 夜行 | 月光蓝调 + 角色身上反光，仍要鲜明 |

#### 严禁倾向

- ❌ 整体灰暗、压抑
- ❌ 雾蒙蒙、低饱和、黯淡无光
- ❌ "苍凉"、"萧瑟"等会引导出图低饱和的形容词
- ❌ 末日感、废土感

#### 应用原则

新增 task 写 `background_desc` / `time_of_day` / `key_elements` 时：
- **默认**：写"阳光、明亮、色彩鲜艳"
- **特例场景**：明确标注"密林深处"或"洞穴"或"夜战"等触发暗调的语义词

## 6. 主线大纲（8 章）【用户更新 2026-04-27 大幅重写】

- 每章与某女主有 1-2 次关键对话选项（如"调侃她 / 关心她 / 保持距离"），选"关心她"+1 心向
- 章七聚义厅同框时，主角主动找谁说话 +2
- 章末抉择前的最后一次对话（每个女主一次）+3
- 累积分高者触发对应结局；若分数接近平局，则可能触发独行 D 或玩家手动选

**额外抉择**（不影响主结局，但影响尾声）：
- 是否接掌天书三卷（接掌 / 焚毁 / 三派分护）
- 是否原谅令狐封（原谅 / 让他归隐 / 他重伤死了无须选）
- 是否让烈云盟正式入正派联盟（入 / 不入 / 由戚云笙未来决定）

- **章末**：江湖恢复安宁，根据 A/B/C/D 不同结局演出对应尾声 CG / 文字
