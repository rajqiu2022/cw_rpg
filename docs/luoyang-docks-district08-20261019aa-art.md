# 洛阳 08 区·漕运码头首批艺术布局合同（aa）

状态：`ART_LAYOUT_SOURCE_READY_NO_RUNTIME_NO_ENGINE`。这份文档只定义第一个可执行小原子：撤掉西侧两栋无门、无房间、无任务身份的重复楼，保留索具铺，并把腾出的空间明确为仓前装卸场。它不是“08 区完成”，没有实机、碰撞或正式发布信用。

## 1. 为什么先撤两栋

当前有效前身已在 20261017p 撤掉北部重复的 `harbour_main_warehouse`，剩 27 个视觉对象。西侧下半区仍有三栋大楼互相压叠：

- `harbour_small_cargo_store`：脚点 `[500,1130]`，1099.88×549.94；与保留的北仓使用同一张仓房图，且没有独立门、室内或交互。
- `south_canal_front`：脚点 `[560,1600]`，1029.12×686.08；是通用三开间沿街楼，没有独立门、室内或交互，正是总规里要避免的“一楼三门冒充三建筑”。
- `harbour_rope_shop`：脚点 `[720,1420]`，652.8×435.2；保留，作为西侧索具交易的小尺度前景建筑。

因此第一原子是 `remove2 / retain1`：只删前两栋，索具铺原脚点、缩放、深度脚线和 solid 全不动。当前有效对象数应由 27 变为 25；p 阶段已经撤掉的 `harbour_main_warehouse` 不得回流。

精确数值、纹理 SHA、alpha 包络和 solid 见 [layout_spec.json](../game/build/luoyang_docks_district08_20261019aa_art01/layout_spec.json)。

## 2. 新空间不是空广场

撤楼后的层级是：北仓是北侧地标，索具铺是西侧中景，东侧货棚、牌示、木栈板、货箱、埠务所和两艘船构成作业侧。空出的西侧中段定义为“仓前装卸场”，用途是让货运路线、行人路线和建筑脚线分开，而不是再塞一栋大楼。

第一原子保留现有低物件：

- 货棚 `harbour_loading_shelter` `[1610,1010]`；
- 牌示 `dock_notice` `[1400,1500]`；
- 木装卸板 `dry_loading_wharf` `[2150,1640]`；
- 现有 6 个 district 货箱与 3 个原码头货箱；
- 埠务所 `[1720,1790]`、写实货船 `[2703,1271]`、篷船 `[2653,1824]`。

同区后续必须再做一个有界低物件原子，才能宣称装卸场视觉成立。首选只加两个现成货箱：脚点 `[1000,1160]` 与 `[1030,1530]`，world solid 已在 JSON 中按原 donor 几何平移给出；每处只一只箱，作为边缘标点，不排成障碍墙。两处都必须再过 full-alpha、875/17、路线段和 NPC 扫掠域检查。木手车与粮袋虽已在库内，但目前只有室内尺度/原图包络，尚无批准的室外渲染尺度和码头 solid，本批明确暂缓，不能直接拖进 Field。

## 3. 动线与保护点

西侧货场和东侧货运脊之间保留约 128px 的可读通道，实际以现有 875/17 角色体和 Physics 结果为准，不用这条美术宽度替代验证。以下全部原位：

- 北仓门 `[754,610]`，泥样 `[940,690]` / 站位 `[940,750]`；
- 府衙出口 `[260,790]`，南市出口 `[260,1740]`，渡船出口 `[2140,1840]`；
- 仓场伙计 `[1050,970]`，索具商 `[1050,1410]`，头领/老卒/漕工任务点；
- 巡游带 `[590,1240]±100` 与 `[900,1930]±140`；
- 现有 quay road、loop、两出口路线、泥样路线、牌示路线、渡船路线和 work-chief 路线。

`harbour_life_docks_store_attendant` 不移动，只把视觉语义收拢为“北仓场院伙计”；这不是改 NPC 身份或任务。

## 4. 地面与影子结论

只读查看 3072×2048 `floor.png`：目标两栋包络内没有发现与楼体一致的矩形屋顶/门脸烘影；可见的是既有道路明暗、树影和水岸阴影。因此第一原子不改 floor，也不重烘整城。这个结论只是源图目检，删楼后的实际 GPU 图仍必须覆盖两块腾空区域。

若 GPU 后才暴露出某栋专属残影，应停止发布并做同源局部补片；禁止扫色擦除、禁止整城重烘，也不触碰旧船影修复区域。

## 5. 验收与信用边界

CPU 候选至少验证：27→25、仅两 ID 消失、p 撤仓保持、其余对象/门户/任务/NPC 精确保持、walk 只单调恢复两段 solid、全部原路线和 875/17 检查仍成立。

后续实际 1920×1080 图必须确认：三楼叠穿消失、索具铺仍可读、北仓门/泥样/双城门/渡口/埠务所都清楚可达、腾空地面没有楼体残影。只有 remove2 的图通过，仍只能记为“间距与层级修正”；两处低物件装卸场跟进并目检后，才可记为 08 区首批视觉丰富化。独特索具铺门脸、湿石/车辙地面层和室外手车/绳索/袋堆仍是明确素材缺口。
