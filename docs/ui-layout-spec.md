## 5. 血条蒙版机制

HP/MP 进度条使用 **clip_contents 右侧裁切**：

```
HP 50% 时：
  生命 [████████░░░░░░░░] 750/1500
       ↑ fill始终100% ↑ clip.size.x = bar_w × 0.5
         右侧50%被clip裁切
```

- `_hp_clip` / `_mp_clip`: `Control` with `clip_contents = true`
- `_hp_fill` / `_mp_fill`: `TextureRect` child, always at 100% size `(BAR_W, BAR_H)`
- 更新进度：`_hp_clip.size.x = BAR_W * hp_ratio`

## 6. 资产生成规范

### 6.1 命名约定
```
hud_{模块}_{功能}_{状态}.png
例: hud_player_panel.png
    hud_btn_inventory_normal.png
    hud_btn_inventory_hover.png
    hud_btn_inventory_pressed.png
```

### 6.3 图片生成参数
- 模型: `gpt-image-2` via ALAPI
- 质量: `medium`
- 尺寸: 使用 gpt-image-2 支持的标准尺寸 (`1024×1024`, `1536×1024`, `1024×1536`)
- 背景: `transparent` (按钮/图标) 或 `opaque` (面板/背景)

## 7. 代码规范

### 7.1 HUD 入口文件
- **场景:** `game/scenes/ui/field_primary_hud.tscn` — 空 Control + 脚本
- **脚本:** `game/scripts/ui/field_primary_hud.gd` — `class_name FieldPrimaryHud`
- **调用方:** `field_walkable_controller.gd` 在 `_init_formal_hud()` 中实例化

### 7.2 添加新 UI 元素
1. 在 `FieldPrimaryHud` 中添加 `var` 声明
2. 在对应的 `_build_xxx()` 方法中创建节点
3. 使用 `_add_texture()` / `_add_label()` / `_make_bar_clip()` 辅助方法
4. 在 `set_player_stats()` 等公开方法中更新数据

### 7.3 UI 更新入口
```
GameState.player / gold 变化
   ↓ EventBus.gold_changed / player_changed
field_walkable_controller._refresh_gold()
   ↓
_primary_hud.set_player_stats(player, gold)
   ↓
更新所有 Label + clip.size
```
