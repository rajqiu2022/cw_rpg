# 原生物件阴影捕获诊断 v12

状态：**最小阴影能力验收通过，整图仍未放行**。此文记录v11空投射影的定位与后续修复依据；最小实验通过不能代替整张地图的脚底、导航和实机验收。正式v12地图和v13 staging保持不变。

## 诊断范围

只使用已有模型与本机Godot，建立平面接收面加一个立方体或已有CC0 Boulder01的最小场景。相机、灯光方向及环境亮度保持与地形管线一致。对照标准材质与本地地表Shader，以及普通可见物件、仅投影模式、相机排除物件三种捕获方式。

每种配置保存真实ON／OFF原图、物件本体alpha和差分统计。普通可见模式须让本体在两幅图中都保持可见，只改变是否投影；其余模式明确记录实体是否进入相机，不能把本体消失造成的差分当成地面阴影。捕获等待实际渲染帧完成。

## 接入条件

- 至少一组标准材质与本地地表材质的真实地面投射影非空，原始ON／OFF区别可独立重算，且没有本体污染。
- 失败对照保留配置和原图，证实问题处于具体捕获路径，而不是据空图推断整个兼容渲染器无阴影。
- 根因明确后再批准新的整图捕获；不修改v11失败证据，不解除其启动保护。若能生成稳定新版，另按完整脚底、逐物件Y遮挡、同源导航、入口和存档隔离验收。
- 冻结旧v9／v10及v11源与PNG／JSON／EXR输出、正式文件，共124份SHA基线。不进行新下载、生图或付费调用。
