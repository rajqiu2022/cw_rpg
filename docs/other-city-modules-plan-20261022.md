# 其他城镇模块素材 · 第一批

change-id: other-city-modules-20261022

依据洛阳最新总规的模块化方向，为已存在的汴州、金陵、襄州、清河、雁门制作可分件复用的首批素材。每处先有辨识度明确的建筑入口，再配既有NPC、敌人和任务物件；不把整城概念画当可行走地图。本批是素材候选制作，不是五城改造或游戏接入交付。

## 范围与依据

| 地点 | 既有功能与首件建筑 | 角色 | 周边敌人 / 物件 |
|---|---|---|---|
| 汴州 | 中原坊市与邮驿；独立驿馆门脸 | 汴州驿丞静态精灵＋同人立绘 | 驿道劫匪；既有行粮袋 |
| 金陵 | 江南桥市与绸铺；独立绸铺门脸 | 金陵水巡静态精灵＋同人立绘 | 芦荡私枭 |
| 襄州 | 江防与校场；营房门脸 | 襄州守备静态精灵＋同人立绘 | 矿场力士；既有铁矿石 |
| 清河 | 行旅街与补给；补给铺门脸 | 行旅货郎静态精灵＋同人立绘 | 本批不新增敌人设定 |
| 雁门 | 关外雪径；石木门楼 | 现有场景无城镇NPC，本批不虚构 | 关外刀匪；既有失物药包 |
| 通用 | 缉捕木榜亭 | 无新增身份 | 现有可选雪岭山狼视觉储备，未新增遭遇 |

第一批固定22张：5建筑、4静态NPC、4同人立绘、4人形敌人、1山狼、4任务/采集物件。任务名称、对白、奖励、掉落和遭遇均沿既有数据，不由美术任务改动。精确设计来源及其SHA见 [manifest](../assets/raw/other_city_modules_20261022/manifest.json)。

## 制作规则

- 建筑采用平行俯视、低屋顶、清楚的门槛和成人门洞；门口不放货架、树或人物。门内有暗部深度，不透草。不绑定未经测量的世界尺寸。
- 地面、街墙、树木、家具优先从[现有复用索引](resource-reuse-index.md)选取。各城保留用途与材质差异，后续按路网与NPC落脚布置，避免叠楼和空石广场。
- NPC按同一原图派生立绘，记录参考路径和SHA。探索待机、对话立绘、战斗待机各自独立，单张静态图不称行走或攻击动画。
- 内置imagegen逐件调用，保留原始PNG与逐件meta，真实透明背景。模型、服务商和费用未由工具披露时留空，不冒报模型。
- 透明留白按全部alpha大于0的像素检查，不能只用高阈值忽略边缘。原图留白失败如实保留，不删除弱alpha、不借用洛阳历史处理许可。

## 接入前待办

1. 完整alpha与透明留白合格，复核实际合成边缘、建筑门洞和NPC俯角；当前原图存在留白不足，未授运行就绪。
2. 依据各城现有地图确定门脸尺寸、脚锚、独立室内入口、连续街道和NPC位置；真实碰撞、导航与往返须独立验证。
3. 单独制作并验收NPC步态、敌人攻击/受击/倒地动画。不能复制同一静态帧冒动画。
4. 通过媒体检查后才把明确采用的派生图导入game，并按届时来源闭包接线。本批不运行Godot、不改正式地图/NPC/任务/敌人/物品数据。
