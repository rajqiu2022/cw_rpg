# 通缉榜UI与城市实体榜亭交互修正（2026-09-27）

## 目标

修复正式通缉榜底图与运行时文字、按钮错位，并把中大型城市的榜单入口统一到场景中的实体木榜亭。玩家应靠近榜亭直接查榜、揭榜，城市守备或向导只负责指路。

## 实施

### 榜单界面

- 复核用户截图后再次按1792×1024底图的真实内框校准：声望与说明两行下移并完整落入青色信息牌，底部“合上榜册”下移并居中于蓝色牌匾，不再压住装饰边框。
- 朱红揭榜牌的动态文字由24px提升到32px，使“揭榜／追捕中／已归案”与大尺寸牌面保持一致的视觉重量。
- 第二张榜文的左侧“黑”字印记、中间案情和右侧“揭榜”使用同一组约23px下移锚点，同步对准下层纸榜；第一张保持原位。该值来自1792×1024实机图中两块朱红牌与文字中心差的像素测量，偏移直接落在三个动态区域，避免被PanelContainer自动布局重置。

- `game/scripts/ui/bounty_board.gd`改用底图安全区：
  - 顶部标题、江湖声望、追捕说明各占一行；
  - 两张榜文分别固定为圆形犯人印记、案情文字、朱红揭榜牌三列；
  - 正常状态不再额外绘制大块按钮底板，直接使用底图的朱红牌和青黑牌匾；
  - 关闭按钮回收到下方牌匾。
- 保留文字、等级、线报、奖励、状态的实时数据渲染，不把任何中文烘焙进图片。
- 1792×1024实机图：`game/screenshots/bounty_board_v2.png`。

### 城市实体榜亭

- 汴州：热区移到坊市东侧木榜亭，并连接右侧主街可行走站位。
- 襄州：热区对准校场南侧木榜亭及其前方石路。
- 金陵：热区移到东桥头木榜亭，并连接广场东侧可行走站位。
- 洛阳：城门西侧榜亭在完成案情线索后继续作为重复通缉榜入口。
- 四城榜亭均声明`activation=interact`与`clickable=true`；点击仍要求玩家已进入榜亭交互范围。
- 汴州驿丞、襄州守备、金陵水巡删除代开榜单选项，改为说明实体榜亭位置。
