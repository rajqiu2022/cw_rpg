| 维度 | 分 | 备注 |
|---|---|---|
| 风格内一致性 | 5.0 | （基线） |
| 跟主角风格契合 | 4.5 | 港漫厚涂 + 墨线 + 暖色调，跟 v2 主角同世界观 |

### 1.2 神秘商人 — `images/神秘商人.png`

| 维度 | 分 | 备注 |
|---|---|---|
| 风格内一致性 | 5.0 | 跟客栈老板**笔触完全同源**，墨线粗细 / 厚涂层次 / 暖色基调一致 |
| 跟主角风格契合 | 4.5 | — |
| 角色辨识度 | 5.0 | 客栈老板=壮实和善白润 / 商人=瘦削阴鸷蜡黄，气质对比强烈，绝不会认错 |
| 武侠氛围 | 5.0 | 主街市集 + 红灯笼一串 + 摊位灯光，背景按情境自动调亮，不是套模板 |
| 可游戏化 | 4.5 | 眼神和斗笠剪影戏剧张力强 |

**关键观察**：这是验证里最关键的一张——**同画师笔下两个完全不同气质的人**。结果在第 2 张就拿到强信号：风格不会跑。"三缕长须" 画成了"山羊胡 + 短颊须"，但反而更符合"行脚商人有故事"的气质。

### 1.3 哭泣女子 — `images/哭泣女子.png`（关键非萌系测试）

| 维度 | 分 | 备注 |
|---|---|---|
| 风格内一致性 | 5.0 | 跟前 2 张笔触完全同源 |
| 跟主角风格契合 | 4.5 | — |
| 角色辨识度 | 4.5 | "求助的可怜女子"立得住，跟前两人零混淆 |
| 武侠氛围 | 5.0 | 街角石墙 + 远处店铺红灯笼 + 湿润青石板地面（prompt 没要求 ChatGPT 自加） |
| 可游戏化 | 4.5 | — |
| **非萌系考验** | **5.0** | **本次验证最担心的点**——AI 画女性最容易跑偏到日漫水汪汪眼 / 韩漫网红脸 / 迪士尼大眼。结果完全没发生：眼眶含泪、泪痕、眉头紧蹙、嘴角下压、双手交握、略低头，是真实的悲伤张力，是港漫女角不是动漫女角 |

**关键观察**：这张过等于解决了"AI 能不能画武侠风格的女性角色"这个最大不确定性。

### 1.4 守城兵丁 — `images/守城兵丁.png`（关键金属甲测试）

| 维度 | 分 | 备注 |
|---|---|---|
| 风格内一致性 | 5.0 | 跟前 3 张同源 |
| 跟主角风格契合 | 4.5 | — |
| 角色辨识度 | 5.0 | "有阅历的老兵"立得住，方脸刚毅、眉宇有戏 |
| 武侠氛围 | 5.0 | 城门洞 + 远处城楼飘红旗 + 夕阳暖光（prompt 没要求 ChatGPT 自加） |
| 可游戏化 | 4.5 | — |
| **金属质感考验** | **5.0** | 札甲、铁盔、刀柄铜环全部**厚涂 + 墨线**，每片甲片独立的高光阴影、铆钉粗墨笔点出，绝无 3D 渲染感。AI 画武侠最容易翻车的题材没翻 |

**关键观察**：很多 AI 一画铠甲就掉入"游戏 3D 模型贴图感"。这套 prompt 把它锚在港漫体系里没跑偏，**这条工艺路线能撑起后面几百张资产**。

### 1.5 赵无忌 — `images/赵无忌全身立绘.png`（终极考点：全身 + 反派 + 冷调）

| 维度 | 分 | 备注 |
|---|---|---|
| 风格内一致性 | 5.0 | 跟前 4 张同源（关键：不同色温下笔触仍统一） |
| **比例保持考验** | **5.0** | 全身（1024×1536）厚涂笔触没变稀疏，斗篷褶皱、长袍纹理、远景地砖都用粗笔触厚涂 |
| **气场考验** | **5.0** | 半侧身回头 + 阴影中轮廓 + 斜射光柱 + 斗篷红内衬翻出，**完爆前 4 个 NPC**，港漫反派出场标准镜头 |
| **冷暖反差考验** | **5.0** | 前 4 张全暖色，这张主体是深蓝灰 + 深棕，唯一的红是斗篷内衬翻出的暗红——**AI 能听懂"boss 例外可以略冷"**，不是惯性继续暖 |
| 武侠氛围 | 5.0 | 阴森废宅 + 远处小灯笼 + 斜射光柱 + 地面破裂纹路 |

**关键观察**：这张同时通过 4 个独立考验（全身比例 / 反派气场 / 冷调切换 / 细节叙事）。冷暖切换这条尤其重要——证明 AI 不是"无脑套暖暗调"，而是按 prompt 主动调色温。

## 2. 5 张横向对比 — 同画师笔下 5 个完全不同的人

| 角色 | 阶级身份 | 气质 | 五官 | 色温 | 笔触特征 |
|---|---|---|---|---|---|
| 客栈老板 | 市井商人 | 壮实和善 | 国字脸 + 络腮胡 + 笑意 | 暖（红灯笼） | 粗墨眉、皮肤红润 |
| 神秘商人 | 江湖行客 | 瘦削阴鸷 | 长脸尖下巴 + 山羊胡 | 暖（市集灯） | 凹颊明暗、皮肤蜡黄 |
| 哭泣女子 | 民间妇人 | 纤瘦凄楚 | 鹅蛋脸 + 柳叶眉 + 泪痕 | 暖（街角灯） | 柔笔触、皮肤白皙 |
| 守城兵丁 | 军伍小卒 | 魁梧刚毅 | 方脸 + 浓眉 + 胡茬 | 暖（夕阳） | 札甲厚涂、铁盔反光墨线 |
| 赵无忌 | 江湖反派 | 凌厉压迫 | 长脸 + 凤眼 + 长发 | **冷**（废宅斜光） | 斗篷暗纹、长袍褶皱厚涂 |

**5 种社会身份、5 种气质、5 个五官比例、2 种色温、0 张撞脸——但墨线粗细 / 厚涂层次 / 衣纹处理完全统一。**

这是验证最想看到的结果：**AI 能保持"同一画师笔下的风格统一"，同时演绎出"完全不同的人物气质"**。

## 3. 三个超出预期的 ChatGPT 自主加分项

GPT Image 2 在执行 prompt 时表现出**情境理解**而非简单套模板，连续 5 张都自动加了 prompt 没要求的环境叙事：

| # | 角色 | ChatGPT 自加细节 | 加分原因 |
|---|---|---|---|
| 1 | 客栈老板 | 背景挂"客栈"汉字招牌 | 中文场景理解 + 环境叙事 |
| 2 | 神秘商人 | 主街市集多盏红灯笼 | 按"市集"主动加灯笼密度 |
| 3 | 哭泣女子 | 远处店铺红灯笼 + 湿润青石板地面 | 凄凉感叙事 |
| 4 | 守城兵丁 | 远处城楼飘红旗 + 夕阳暖光 | 戎装语境主动加军伍符号 |
| 5 | 赵无忌 | 斜射光柱 + 远处小灯笼 + 地面破裂纹路 | dramatic 反派出场镜头 |

**判断**：这个特性对 L2 批量生产**非常重要**——意味着 prompt 不需要写得"满"，骨架描述够，ChatGPT 会自动补环境叙事，且不会跑偏。

## 4. 几个写在 prompt 体系里的小偏差（不阻塞 L2）

| 偏差 | 出现位置 | 影响 | 应对 |
|---|---|---|---|
| "鬓角微白" 看不到 | 客栈老板（被软帽遮挡） | 0 | 接受 |
| "三缕长须" → 山羊胡 | 神秘商人 | 0（反而更对气质） | 接受 |
| "褐色布包袱" 看不太清 | 神秘商人 | 0 | 接受 |
| "黑鞘弯刀" → 直刀 | 赵无忌 | 0 | 接受（直刀也很对）|
| "双手负于身后" → 扶刀 | 赵无忌 | 0（反而更威严） | 接受 |
| 札甲外罩"浅红色战袄" → 披风式系法 | 守城兵丁 | 0（更英气） | 接受 |

**结论**：偏差全部是"细节级"，无一处影响"该角色是谁、什么气质"的核心识别。L2 阶段如要严格还原可加微调追问，但这些偏差**不构成 L1 不通过的理由**。

## 5. 通过判定 — 进入 L2 阶段

### 5.1 已确证可以做的（不再需要重复验证）

- ✓ 港漫厚涂风格在不同人物气质间统一
- ✓ 主角 + 不同 NPC 的世界观契合
- ✓ 角色辨识度 5/5（5 个不同社会身份 + 不同气质，零撞脸）
- ✓ 武侠氛围（不掉到动漫 / 西幻 / 仙侠）
- ✓ 金属铠甲的厚涂质感（不掉 3D CG）
- ✓ 女性角色非萌系（不掉日漫 / 韩漫 / 迪士尼）
- ✓ 全身立绘比例下笔触保持
- ✓ 冷暖色温按 prompt 主动切换（不无脑套暖色）
- ✓ ChatGPT 自动加情境叙事（prompt 不需要写满）

### 5.2 还需要 L2 跑批才能验的

- ⏳ **可重复性**（L1 验报告 §3 第 6 项 ≥ 3.5）：同 prompt 在新对话或 API 跑两次，输出是不是仍然一致
- ⏳ **API 通道下的风格保持**：ChatGPT 网页是上下文式 prompt 注入；API 模式每次请求是独立 context，需要把"前置 prompt"塞进 system / user 第一条
- ⏳ **大批量下的稳定性**（DMXAPI 4 类失败模式工程化处理）

### 5.3 L2 阶段下一步（按 ADR-001 §6.4 容错工程清单）

**短期（接下来 1-2 天）**：

1. **重构 [`scripts/gen_assets.py`](../scripts/gen_assets.py)** 加 ADR-001 §6.4 容错能力：
   - 跑批前 [`scripts/ping_dmx.py`](../scripts/ping_dmx.py) 探活
   - `--concurrency 1-2` 默认（避免 IP 风控）
   - 4 类失败差异化重试：IP 风控等 30 分 / Azure moderation 不重试 / 503 退避 5-30 分 / 200 空响应 3 次内 retry
   - 失败任务自动降级到 DMXAPI `gpt-image-1.5`
   - OpenAI 官方 `gpt-image-2`（≈2026-05 GA）作为最终 fallback
   - 失败任务持久化到 `logs/failed.log`，下次跑批可只重试失败

2. **建立 prompt 库**（`prompts/v2/`）：
   - `prompts/v2/_prefix.txt` — 前置 prompt（这次用的那段）
   - `prompts/v2/npc/<id>.txt` — 每张 NPC 的 prompt
   - `prompts/v2/items/<id>.txt` — 物品/装备图标 prompt
   - `prompts/v2/backgrounds/<id>.txt` — 场景背景 prompt
   - 跑批时：`gen_assets.py` 自动拼 `_prefix.txt + npc/inn_keeper.txt` 作为完整 prompt

3. **跑 stage 2 验证（20 张）**：
   - UI 元素 6 张（主菜单 / 战斗 HUD / 任务面板 / 商店 / 背包 / 对话框）
   - 物品图标 6 张（铁剑 / 麻衣 / 小还丹 / 大还丹 / 凝气丹 / 地图）
   - 怪物 3 张（thug_lone / bandit_mountain / boss_zhao_wuji 战斗版）
   - 场景背景 3 张（官道 / 主街 / 废宅）
   - 重做 2 张（同 prompt 重出第 1 张和第 5 张，验可重复性）

**中期（M5–M7 期间）**：

- 按章节分批跑，每跑完一章评一次。出现风格漂的角色单独追加 LoRA（≈¥30）
