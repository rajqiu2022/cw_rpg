# 精确可行走蒙版与场景拓扑合同 v1

## 目标

复杂密林、洞穴、水道和迷宫不再依赖少量大多边形猜测道路。底图、通行蒙版、阻挡物、交互物和出入口使用同一归一化坐标系，并由自动探针验收。

## 五层数据

1. **底图**：只负责环境视觉，不决定碰撞。
2. **通行蒙版**：与底图同宽高；白色/不透明像素可走，黑色/透明像素不可走。
3. **局部阻挡**：箱柜、石柱、矿车等小型实体继续用 `blockers`，避免为每个活动物件重画蒙版。
4. **交互物**：任务期出现的信件、货筒、包裹、血迹和狼必须有可见实体；靠近描边增强，交互后按旗标消失。
5. **出入口**：每条 A→B 必须有 B→A；双方出生点都必须通过通行蒙版与阻挡物探针。

## 运行规则

- `WalkableMapLayout.walkable_mask_path` 存在时，运行时优先逐像素采样蒙版；`walkable_regions` 只作为拓扑文档和旧图兜底。
- 角色以脚底原点采样，不以整张精灵图中心采样。
- 蒙版只决定大尺度空间；`blockers` 仍用于局部物体碰撞。
- 任务交互不可把“无形感叹号”直接绑定战斗。正确链路是：可见物/敌人 → 前置对白 → 战斗 → 战后对白/线索物。
- 拾取必须走 `Inventory.add_item()`，由 `item_picked_up` 统一显示“获得 XXX ×N”。

## 制作流程

1. 先在与底图同尺寸的 SVG/PNG 上画白色通行走廊。
2. 将主要道路、支路、踏脚石和返回环路分别标出，禁止大面积一块白色覆盖环境。
3. 放置入口、出口、交互和玩家出生点。
4. 添加 `walkable_probes`、`blocked_probes` 和双向出口测试。
5. 运行专项测试，再做1080P实机截图与真实键盘走线。
