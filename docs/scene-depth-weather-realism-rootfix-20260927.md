# 场景落点、天气、纵深与写实地图根治（2026-09-27）

- 室内返回不再记录角色触发出口时的随机移动采样，而是记录出口资源声明的精确门外锚点；所有118条双向路线继续可逆。
- 所有场景出生点增加“完整脚底净空”检查。点位即使落在可走蒙版内，只要脚底椭圆碰到桌、屋顶、围栏或其他 blocker，就在局部安全环内修复，因此旧存档错误落点也不会继续站在物件上。
- 雨滴UV改为向屏幕下方运动；天气增加场景作用域，林西村外触发的剧情雨不会带回村内，作用域进入存档。

- 武当、华山六张门派运行图升级为写实手绘v5。山门使用与新版底图匹配的alpha前景蒙版；庭院碑、灯、香炉、兵器架等分别登记碰撞和脚底Y遮挡。
- 洛阳南市重画为较疏的等比例街区，导航收在宽主街与支路；洛阳古寺石供桌、主像与侧边实体补齐碰撞/遮挡，出生点移回空旷地面。
- 江湖大地图升级v12：1536×1024写实开阔母图、2304×1536运行图、4608×3072桌面图和移动/桌面各15块流式切片同源；20条道路、2块开放区、16个入口由同一结构源生成视觉强化和导航蒙版。
- 后期场景不再复用被否决的`bgm_linxi_village_v6.wav`；世界、门派、城市、渡口按场景类别回接v4曲目。曲目路由和可播放性已验证，最终审美仍需人工逐首试听。

## 根治合同

1. 门户返回位置以“源门户锚点”为真值，不以角色进入触发区时的位置为真值。
2. 出生点必须通过完整脚底净空检查；中心点可走不等于人物可安全站立。
3. 烘焙物件的层级和碰撞分离维护：blocker负责脚底，y-sort occluder负责前后；门楼另用同画布alpha蒙版处理像素级重叠。
4. 可玩地图必须使用固定尺度的2.5D局部构图。ImageGen只生成无人物/文字/UI的clean plate，运行图使用确定性Lanczos，不经过动漫超分模型。
5. 大地图底图、道路强化、导航蒙版、入口与流式切片必须由同一版本路源同时构建。
