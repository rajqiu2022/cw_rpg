# 纯 RPG 剧情与战斗重设计 v1.0

> 生效：2026-07-25。本文覆盖 `design-chapters-1-4-hybrid.md` 与
> `design-chapters-2-4-production.md` 的场景形态约定；世界观、角色和八章真相节奏仍以
> `world-bible.md` 为准。

## 1. 产品方向

游戏采用 2.5D 武侠回合制 RPG：可操控角色探索场景、与可见 NPC 对话、拾取宝箱、接取任务、接触可见敌人进入战斗。剧情通过场景内对话、镜头聚焦和可控短事件完成，不再使用独立 AVG 页面或文字热点推进主线。

核心循环：

```text
抵达地图 -> 交谈 / 调查 / 战斗 -> 获得线索、装备或武学 -> 打开下一地图 -> 精英或 Boss -> 章节结算
```

规则：

- 每章 2-3 张紧凑探索地图。每张地图只保留一条主路、1-3 名叙事 NPC、1-2 个支线入口、1-3 组可见敌人和一个明确出口。
- 对话只发生在 NPC、调查物和战斗前后，不在无角色可控的 AVG 场景中连续播完主线。
- 主线敌人必须在地图中具名可见。胜利后转换为倒地、撤离或消失状态，不能无说明刷新。
- 宝箱、采集物和机关都是独立交互物，不用背景中的伪按钮或文字热点。
- 每章 2 条主线任务、2-3 条推荐支线；未接取任务不显示在任务页签中。

## 2. 后续剧情地图

### 第二章：竹尾风波

主题：第一次主动介入江湖事件，并与悦无姮形成可战斗的援护关系。

| 地图 | 主线 | 探索内容 | 战斗 |
|---|---|---|---|
| 竹尾晨市 | 询问守卫、药铺、货郎，任意两条线索拼出北林方向 | 药铺、棋摊、擂台支线、补给 | 流氓勒索者（可选） |
| 北林旧道 | 追踪血迹，找回凌月令牌 | 药草、猎人、废亭宝箱 | 野狼、蒙面斥候 |
| 密林伏击地 | 与悦无姮并肩救出失踪弟子，取得伪造令牌 | 断枝、箭簇、被救弟子 | 蒙面斥候精英（章末） |
| 凌月山门 | 交付证据，获邀前往武林大会 | 悦无姮闲谈、凌月药师支线 | 无 |

主线不再用“调查板”切场景：线索计数达到 2 后，北林出口的守卫 NPC 直接让路。悦无姮在密林中是地图角色，战斗时提供一次援护攻击或净化，不做完整双角色队伍，先避免队伍 UI 失控。

### 第三章：入派抉择

主题：玩家用战斗风格和选择定义江湖身份。

| 地图 | 主线 | 探索内容 | 战斗 |
|---|---|---|---|
| 武林大会 | 查看死者名册、与五派代表交谈、完成资格报名 | 令狐封初遇、擂台支线、商队求助 | 资格考校对手 |
| 考校场 | 通过考校，选择门派 | 木人桩、兵器架、观战 NPC | 门派考官 |
| 门派驻地（仅所选一张） | 完成入派试炼并领悟第一套招式 | 机关、同门、专属宝箱 | 门派试炼精英 |

五派保留现有剧情差异，但每派都遵循“一个可走驻地 + 一个调查目标 + 一场特色战”。选择门派后，其余四派传送口关闭并显示后续回访文案，不将未选任务塞入日志。

### 第四章：洛阳奇遇

主题：从传闻走向证据，第一次确认烈云盟案件存在人为栽赃。

| 地图 | 主线 | 探索内容 | 战斗 |
|---|---|---|---|
| 洛阳府衙 | 接案、查三份卷宗、离衙遇袭 | 衙役、证物柜、悬赏告示 | 灭口刺客 |
| 思颖医馆 | 解毒、识别毒粉来源 | 药柜机关、老卒求医支线 | 无 |
| 洛阳街市 | 找货商、纸坊、茶摊，锁定古寺 | 流行追月比武、纸贵支线、商店 | 流行追月切磋（必定非致死） |
| 城外古寺 | 破解伪造密信，生擒活口 | 香炉机关、地窖宝箱 | 古寺伏击者、假烈云首领 |

## 3. 战斗目标

战斗参考传统回合制 RPG 的清晰阵位与指令感：角色站在战场上，对手同样有完整可见形象；玩家选择招式后看到角色前冲、挥击、命中特效、受击和回位。第一期维持 1v1，第二章的悦无姮只作为一次援护事件，待单位层稳定后再开放正式双人队伍。

### 3.1 战场构图

```text
敌方状态框                         敌方战斗单位
                    特效 / 伤害数字
玩家战斗单位                         玩家状态框
                    指令盘：攻击 | 武功 | 道具 | 防御
```

- 背景使用战斗场景图；玩家位于左下、敌人位于右上，形成 45 度对峙感。
- `BattleActor` 是独立视图节点，显示透明 PNG 战斗角色，不再把大幅对话立绘直接当作战斗单位。
- 每个 EnemyDef 必须有 `battle_actor_path`，没有正式资源时允许使用清晰剪影兜底，但不得显示空白或复用玩家图。
- 角色从探索地图进入战斗时保留敌人 ID、名字和阵营，胜利后返回原地图并更新该敌人状态。

### 3.2 动作合同

| 动作 | 时长 | 表现 |
|---|---:|---|
| 入场 | 0.35s | 两方从各自侧边滑入、落地缩放回弹 |
| 待机 | 循环 | 轻微呼吸、衣摆上下浮动 |
| 普攻 | 0.45s | 攻击者前冲约 18% 阵距，命中后回位 |
| 武功 | 0.65-0.95s | 起手停顿、前冲或原地结印、技能图集、命中闪白 |
| 受击 | 0.24s | 后退、红色闪烁、伤害数字弹出 |
| 防御 | 0.35s | 后退半步、护体色罩 |
| 胜负 | 0.7s | 胜者收势；败者下沉淡出，Boss 可改为撤退 |

敌方也必须使用同一动作合同和技能特效。不能再发生“玩家招式有特效、敌人只扣血”的不对称表现。

### 3.3 指令与回合

- 固定一级指令：`攻击`、`武功`、`道具`、`防御`。`逃跑`仅普通遭遇战放在二级菜单，Boss 和剧情战不显示。
- 点击“武功”打开已习得招式列表，只显示当前门派与通用招式；按内力不足、冷却、目标类型正确禁用。
- 速度决定首回合和每回合先后。速度相同则玩家优先。
- 招式、普通攻击、道具、防御均结算一次行动；状态在角色回合开始时结算。
- 敌方从 EnemyDef.skill_ids 选择招式，按生命比例、内力、异常状态和 aggression 决策；敌方施放招式时使用敌方技能名和独立动画 ID。

### 3.4 数值与难度

| 战斗类型 | 目标回合 | 失败容忍 | 关键机制 |
|---|---:|---|---|
| 教学 / 普通 | 3-5 | 可逃跑，掉少量耐久/不丢任务物 | 认识攻击、防御、道具 |
| 精英 | 5-7 | 不可逃跑，失败回到战前并保留已获线索 | 异常、破防、招式组合 |
| Boss | 8-10 | 不可逃跑，三次失败后隐藏式降伤 10% | 两种阶段技能、明确预警 |

保留既定的“低血量伤害衰减”、暴击、防御、命中和异常；每个精英/Boss 至少带一个可读机制，不能只提高 HP。高等级敌人通过第二招、状态和节奏提升难度，不靠无意义血量翻倍。

## 4. 代码与数据合同

### 4.1 新增/调整数据

`EnemyDef` 新增：

```text
battle_actor_path: String
battle_actor_scale: float
battle_animation_id: StringName
defeat_mode: StringName       # defeat / retreat / kneel
```

`Skill` 新增：

```text
cast_animation_id: StringName # 前冲、结印、投射
impact_animation_id: StringName
cast_distance: float
status_chance: float
```

每张自由探索地图新增显式敌人实体数据：敌人 ID、位置、可见战斗形象、首战动作、胜利 flag、战败返回点。主线敌人不可用隐形触发区代替。

### 4.2 视图分层

- `BattleController`：回合、伤害、AI、状态、奖励和路由，只处理数据。
- `BattleView`：舞台布局、BattleActor、镜头、伤害数字、指令面板和状态框。
- `BattleActor`：入场/待机/攻击/受击/胜负 Tween，不参与伤害计算。
- `BattleVfxPlayer`：只播放特效，可指定施法者与受击者位置。

这能保证后续更换角色图、改阵位和加入同伴时不改伤害公式或任务逻辑。

## 5. 迁移顺序与验收

1. 建立 BattleActor/BattleView，先给第一章散兵和主角接入完整动作与正式战斗单位。
2. 把第一章山道敌人改为场景可见敌人，胜负状态回写地图，验证返回和任务完成。
3. 将第二章四张场景从 `hotspots` 迁移为 WalkableMapLayout V2，并完成悦无姮援护精英战。
4. 扩展第三、四章地图和敌人；完成五派试炼、古寺双战。
5. 以同一合同生产第五至八章地图、敌人和 Boss，不再混入 AVG 页面。

验收必须包括：

- 每一张主线地图从出生点到 NPC、宝箱、敌人、出口均可达；建筑屋顶和山体不可走。
- 每场战斗截图可见玩家与敌方单位、双方状态框、指令盘和命中特效。
- 玩家、敌人各执行一次普攻、招式、受击与胜负动作；敌方招式不可只写日志。
- 普通战、精英战、Boss 战分别满足目标回合数；Boss 三次失败保护不改变任务状态。
- 回原地图后，击败敌人、宝箱、NPC 与任务状态正确更新。
