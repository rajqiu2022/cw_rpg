# 移动热路径与战斗反馈修正（2026-09-12）

## 本轮结果

- 林西村南坊的11名NPC不再常驻五次纹理采样的呼吸描边Shader；只有进入交互范围时才临时挂载，离开范围立即释放。
- 主角方向与动作状态不变时，不再每个物理帧重复解析纹理路径、重设材质/缩放；巡逻NPC也不再逐帧查询资源文件是否存在。
- 玩家移动回调中的遮挡多边形检测按8像素采样，返回落点写入按12像素采样；无任何遮挡区的南坊不再做空的逐帧遮挡更新。
- `I`键在普通Field和可行走Field两套输入控制器中均被消费但不打开旧背包/装备界面。`Inventory`数据和对话调用能力保留，便于后续重新启用正式入口。
- 暴击飘字改为96号双行“暴击！/伤害”，增加粗描边、缩放冲击和12道金橙爆裂射线；普通伤害字号与时长不变。
- 单体/群体、我方/敌方四类未命中路径均显示76号青色“闪避”飘字，并带短促侧闪后回归阵位；未命中不触发受击、格挡、反弹或状态附加。
- 胜利结果页播放`bgm_victory.wav`的前8秒作为非循环庆祝乐句，0.3秒淡出；离开结果页播放场景BGM时会立即取消乐句，不与新音乐叠加。
