# 江湖大地图提前游历规则 v1

## 目标

世界地图从新游戏阶段即可进入。玩家可以像开放式武侠RPG一样先访城镇、认识NPC、接触支线或记录并行线索；主线章节仍按调查结果和前章完成状态推进，不能因为提前到达地图就自动跳章。

## 当前开放范围

| 地点 | 提前游历 | 主线门禁 |
|---|---|---|
| 林西村 | 开放 | 第一章按原流程从师门启动 |
| 竹尾晨市 | 开放 | `chapter1_complete` 后才自动播放第二章开场 |
| 凌月山门 | 开放 | 失踪案交还、掌门复命等主线交互仍按旗标显示 |
| 武林大会区域 | 开放 | `chapter2_complete` 后才自动播放第三章开场 |
| 洛阳府衙 | 开放 | `chapter3_complete` 后才自动播放第四章开场 |

华山、古月峰、茗雾山当前没有完整可游历场景，仍保留方向提示，不用锁定对白冒充已经开放。北林、洞窟、漕渠和古寺地道属于危险区域，继续使用剧情/调查旗标与建议敌人等级。

## 运行合同

- 城市portal本身不使用章节 `require_flag`；城市出口也始终可以返回世界地图。
- `SceneScript.on_enter_require_flag` 只控制自动主线开场，不阻止加载场景。
- 提前到达时，关键NPC使用无任务副作用的游历对白；不得接取、完成主线或写入章节开始旗标。
- 城市中的支线、商店、切磋、可读物和普通NPC可以提前存在；主线调查物、考校入口和后续地图继续用各自旗标控制。
- 玩家提前取得某条并行证词可以保留，但最终汇总节点必须要求主线已正式启动，避免提前跳过章节。
- 城镇保持安全区，不因提前访问增加随机战。
