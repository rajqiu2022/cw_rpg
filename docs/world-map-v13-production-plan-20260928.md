## 四个串行关卡

1. 美术：9 块非重复地貌；16 个可辨识独立地标或逐项说明同一地标何以可复用。城、门、渡口不烘焙进底座，文字/箭头由程序显示。贴图原始 alpha、固定投影、风格一致性逐张审查。
2. 系统：九块母 tile 组成单连续 Field，路面与导航使用同源坐标；独立物件同时登记 `sort_by_feet`、脚底碰撞、深度线、近距入口。地貌未齐时仅作 staging，绝不把空白/重复 tile 切到正式世界。
3. QA：16 个入口 ID/target_scene 保持不变；每个入口城外/岸上/山脚安全站位与返回锚点；九块、六条内部接缝的道路足底净空与禁走负例；每个独立地标的前后遮挡和碰撞实机正反例；新建、读档、任务切换回归。
4. 主控：仅当九宫视觉、16 入口及回程、导航、实机截图、Godot 严格导入全部通过后，才将正式 `world_map_jianghu` 从 v12 切到 v13。旧版保留可恢复的资源与路径；未通过项逐条记录。
