# 门派场景 v4：写实统一、山门纵深与玩家话术

## 本批目标

1. 武当守山弟子的对白只说江湖人物能够理解的入门条件，不再暴露“开放场景、触发剧情、选择门派”等设计语言。
2. 山门透明判定以角色脚底为准，只覆盖门楼横梁/屋檐下的狭窄建筑底层；外露楼梯保持人物完全不透明。
3. 将同批次中明显卡通化、塑料化或线稿化的门派底图统一到写实手绘2.5D武侠基准，同时保持既有多屏尺寸、路径结构、入口和交互数据。

## 对白调整

武当守山弟子现行说法为：

> 少侠若有意拜入武当，须先赴武林大会取得五派考校名帖，再过我派问心、试武两关。眼下火候尚欠，不妨先在前庭观摩，与同道切磋；待考校有成，再来叩山门。

这段对白给出明确行动目标和失败后的下一步，不解释系统如何开放，也不承诺或否认内部剧情触发。

## 门派美术统一

本批用Codex内置ImageGen生成七张版本化源图，未覆盖旧资源：

- 武当：山门、太极场、紫霄宫前庭，运行图均为3072×2048。
- 华山：山门、演武坪、瀑布剑台，运行图均为3072×2048。
- 凌月：山门，运行图为1536×1024。

统一约束为俯视斜角2.5D、真实石木材质、克制色彩和清晰通路；禁止卡通描边、赛璐璐阴影、塑料亮面、过饱和蓝金、重复符号和主题乐园式宫殿。武当使用灰石、深木、松色与暗朱布幡；华山使用风蚀石、炭黑瓦和暗红剑幡；凌月保留月夜蓝灰气氛，但去掉单色线稿感。

古峰雪岭与茗雾竹院经审查已符合当前写实材质基准，因此保留现行资源，避免无证据重画。完整源图、运行路径和生成约束见 `assets/raw/scene_background/sect_maps_v4/manifest.json`。
