# 大地图南桥、武当纵深层与音乐 v7（2026-09-13）

## 本轮结论

- 用户截图红框中的浅色道路位于 v10 作者坐标约 `(998,651)～(1163,766)`。底图已经画出从中央南部平原经石桥通往茗雾方向的支路，但结构化 `ROUTES` 漏记，导致画面可见、导航蒙版不可走。
- 武当旧实现只降低角色 alpha。门楼、灯柱、碑和香炉仍烘焙在底图下层，所以角色会透明地压在屋瓦或物件上；透明本身不能建立前后遮挡。
- v6 音乐用低音正弦、加法谐波和软鼓模拟乐器，小音箱上容易呈现大号/铜管感。问题属于音色源，不是单纯音量问题。

## 大地图修正

- `world_map_v10_road_source.py` 新增 `south_bridge_to_mingwu` 宽路，连接南部开阔区与既有茗雾道路。
- 新增北岸、桥面、南岸三个脚底见证点；同一来源重建运行底图、导航蒙版、4608×3072 Real-ESRGAN 桌面图及桌面/移动各15块流式切片。
- 构建验证：15条路、2块开放区、13门户同域连通、4063个中心线脚底密采样、可走面积33.93%，最窄道路58作者像素。

## 武当层级修正

- `DynamicOccluder2D` 增加两种明确语义：
  - `overlap`：供可穿越门楼使用。真正将门楼采样到前景，角色在门下用统一半透明影像显示，不再只淡化底图上方的角色。
  - `y_sort`：供灯柱、碑、香炉等烘焙物件使用。角色脚底 Y 小于物件深度线时由物件遮挡，走到物件前方时该重复前景自动隐藏。
- 武当山门改为真实前景门楼；太极场和紫霄宫前庭登记8组以上脚底纵深物件，并补齐对应阻挡。
- 紫霄宫门槛和香炉阻挡下移，角色只能到达合理的殿前观察位，不能再站进门框和香炉上。
- 本轮没有重画整张武当图。现有3072×2048底图的尺度和构图可继续使用；用同图采样前景即可得到用户建议的“底图＋独立物件＋纵坐标层级”，且不引入新生成图的建筑漂移。

## 音乐 v7

- 武当 `bgm_wudang_clouds_v7.wav`：48秒，古琴/琵琶式物理拨弦、稀疏洞箫气声、极轻木鱼点击；无铜管、锣鼓轰鸣和持续超低音。
- 胜利 `bgm_victory_v3.wav`：6.8秒，以琵琶式上行和短洞箫收束；不循环。
- 两曲44.1kHz立体声；110Hz以下能量占比分别为0.0079%与0.0019%。生成脚本使用固定随机种子，可重建、可审计，不依赖外部模型或不明版权素材。
- 外部候选调研：AudioCraft代码为MIT，但官方MusicGen权重是CC-BY-NC 4.0，不进入商业运行包；ACE-Step仓库标为Apache-2.0，可作为后续离线候选，但仍需对具体模型权重和产出条款逐项留档后再采用。
