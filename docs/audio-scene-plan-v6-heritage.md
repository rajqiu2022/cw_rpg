# 首版武侠母题回归与场景变奏

日期：2026-08-25

## 决策

当前 v5 程序合成曲停止作为运行配乐。探索与战斗恢复到项目早期获得认可的两首 CC0 完整音乐骨架，并使用 v4 已完成的 8 类探索变奏和 5 类战斗变奏：

- 探索母带：`game/art/audio/cc0/bgm_field_bards_tale_cc0.mp3`
- 战斗母带：`game/art/audio/cc0/bgm_battle_medieval_cc0.mp3`
- 来源与授权：`game/art/audio/cc0/LICENSES.md`，RandomMind，CC0 1.0

“回归首版”不等于所有场景播放同一文件。运行时仍按场景语义使用：

- 江湖行旅、村落日常、山路远行、密林疑踪、洞窟危机、街市烟火、城郭仪典、门派云境 8 类探索变奏。
- 村镇、山地、河谷、切磋、章节 Boss 5 类战斗变奏。

这些变奏都保留首版完整旋律与和声推进，再以起始段、速度、箫/低弦、木梆、堂鼓、锣和空间感作差异；禁止重新用规则琶音、正弦主旋律或宽频噪声假装武侠器乐。

## 运行路径

- `AudioManager.DEFAULT_FIELD_BGM`：`bgm_jianghu_journey_v4.wav`
- `AudioManager.DEFAULT_BATTLE_BGM`：`bgm_battle_mountain_v4.wav`
- 全部 SceneScript 与 BattleController 使用对应 `_v4.wav` 变奏。
- v2/v3/v5 文件保留作历史 A/B，不再被运行资源引用。

## 后续新增变奏规则

1. 必须能听出首版母题的 3～5 音识别片段或终止式。
2. 每首拥有独立 B 段、句序或节奏语法，不能只切同一段开头。
3. 优先使用真实录音/高质量国风音源；本地波形合成只能做低电平辅助层。
4. 探索曲保留旋律和留白，环境噪声极低；战斗曲第一拍进入节奏型。
5. 先交江湖行旅、村落日常、山地战斗三首 A/B，再扩展全套。

## 验收

- 13 个运行路径全部存在并可完整循环。
- 场景→战斗保持双播放器即时交叉淡入，切换提交小于 50ms。
- 全仓运行脚本与 SceneScript 不再引用 `_v5.wav`。
- 人工试听：15 秒内可辨认同一武侠母题家族，同时能区分至少 6/8 探索与 4/5 战斗类型。
