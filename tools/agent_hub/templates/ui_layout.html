4. 交互流程（所有面板通用）

操作行为
I / 背包按钮打开/关闭背包面板
E / 装备按钮打开/关闭装备面板（同时显示背包装备分类）
J / 任务按钮打开/关闭任务面板
K / 技能按钮打开/关闭技能面板
ESC关闭当前打开的面板
右键装备道具装备/卸下，自动切装备页签
左键道具选中查看详情（不操作）
战斗·攻击普攻（速度高者先手）
战斗·技能消耗MP释放技能
战斗·道具弹出消耗品选单，使用后回血/回蓝
战斗·防御本回合伤害减半
战斗·逃跑50%概率脱离战斗
